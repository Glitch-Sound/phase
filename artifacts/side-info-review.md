# 右情報とメニューの整理

## 変更

待ち量とACTING、QUEUEDの説明文、予測下のINFとRESの数値を削除した。
選択、ホバー、終局でもこの場所へ代替を置かない。
白い進捗円弧、現在状態のIとR、円形予測と既存の特異点の×5は維持する。

| 右側から削除した内容 | 理由 |
| --- | --- |
| PLAYERとENEMYの接頭辞 | 陣営別の状態配置と色で識別できる |
| HPラベルと現在と最大の数値 | 左の個体HPと重複し、選択リングのHP円弧も残る |
| 移動済みの歩数 | 盤面の経路で分かる。移動上限は残す |
| VITからLUKの見出し、COREとGEARとARMSの行名、15個の配分値と15本の棒 | 現在のリングとBUILDの配分情報に集約する |
| 装備型番 | 戦闘中の識別に不要でBUILDに残る |
| NORMALの突然変異行 | 変化がないことの反復を省く |
| ACTIVEとPASSIVEの反復、種別を示す短い縦線 | 全スキルの名称と効果範囲を残す |

右側には選択した現在のリングと中央名、CLASS、移動上限、全スキル、NORMAL以外の突然変異を残した。
右情報の左端は1440で盤面の右端1384から56px離す。
HELPとSETTINGS、RESTARTとQUITを2列2段で置き、下端1016を盤面へ揃えた。
BACKと閉塞時のWAITは上へ分離した。
BUILDの内容と配置、1000px角の盤面、色、戦闘式と保存形式は変更していない。
