# 戦闘画面の表示文字削除

## 変更範囲

基準はecc3012である。\
製品コードはui/main.gdの8行の削除だけであり、7つの文字描画とPATHラベル専用の長さの変数を除去した。

- PHASE PREVIEW
- PATH X / DESTINATIONの経路長と目的地座標を含む表示全体
- ROUTE / PHASE / EFFECT
- TURN ORDER
- Tと現在時刻の表示全体
- INSPECT
- INNER / MIDDLE / OUTER

手番一覧のデザイン変更は行っていない。\
一覧そのもの、経路の番号と線、移動、円形予測と同期率、詳細パネル、通知の分離、配色、配置、寸法、戦闘式を維持した。\
既存のセーブと配色設定を保存、上書きしていない。

## 自動検査

tests/battle_labels.gdの88件を追加し、4ステージと行動選択、攻撃対象、回復対象、結果の背後を検査した。\
変更前は指定7表示について56件が失敗し、変更後は88件すべてが成功した。\
保持する見出しと詳細情報、6件の手番と係数、予測リングと4輪郭、INFとRES、ユニットと経路の不変性も確認した。

検証時に、接頭辞だけを消して数値やDESTINATIONを残す誤実装を見逃すことが分かった。\
例を増やす代わりに、既存の期待値を元の表示領域も確認する形へ強めた。\
時刻9999.0と経路長37を含む表示の復活、時刻の数値だけとDESTINATIONだけの復活のいずれも16件が失敗し、終了コード1となった。\
誤実装は管理対象外のコピーへ注入し、製品コードを一時的に壊していない。

プロダクト検査scripts/check.shへbattle_labelsを追加した。\
既存の検査の期待値は変更していない。\
全体検査は1,328件、戦闘再生、4仕様とトレースを含め成功した。

## 通常のGodotでのクリック確認

埋め込み表示1438x809で変更後のゲームを起動した。\
開始時に7表示がなく、通知と同期率が分離し、手番6件と詳細を表示することを確認した。

1. 手番一覧のAをクリックし、右詳細をAへ切り替え、予測は手番1を維持した。
2. 1で(4,4)から(5,4)へ経路を追加し、終点をダブルクリックして行動選択へ進んだ。
3. 攻撃を選び、無効対象の通知とBACKを確認し、BACKで移動を保持して行動選択へ戻った。
4. 攻撃対象Aをクリックし、-11、敵HP合計189、TURN002、次の手番2を確認した。
5. 2で(4,6)から(5,6)へ経路を追加し、線と番号、終点、INF130.6%とRES94.5%を確認した。
6. 手番一覧からAを選択し、右HP89/100と手番2の予測を同時に確認した。
7. Escで経路を取り消し、(4,6)だけの別経路を選んだ。右詳細はAを再選択し、予測がINF196.6%、RES100.0%へ更新された。
8. RESTARTでBUILDへ戻し、Godotの実画面操作を終了した。
