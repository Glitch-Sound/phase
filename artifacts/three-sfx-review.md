# 選択音の除外

## 変更

db33bf8を基準に、選択音だけを再生対象から外した。\
select.oggは内容と更新時刻を変えず残し、選択専用の音声レーン、入力票とUIからの発音接続を削除した。\
素材を消去したり、音量ゼロで再生を続けたりする構成ではない。

ring_rotate、attack、healの音量はそれぞれ-18dB、-15dB、-8dBのままである。\
移動各歩の観測、実HP結果、重複防止と再生の関数本文が前版と一致することを照合した。\
回転と効果の2レーンを各1声でMasterへ出力する。\
UIの操作、戦闘、演出の時間、BGMと設定は変更していない。

## 検証

- 依頼に合わせて既存の選択と素材の期待値を先に変更した。
  変更前は選択音の再生、4音登録と選択レーンを検出して3失敗となり、実装後は33検査0失敗となった。
- 回転、停止と再開、0歩と表示省略、CPU早送り、実HP変化ゼロ、上限回復と重複防止の既存検査を維持した。
  追加のバランス期待値はない。
- macOS、Godot 4.7.2、Compatibility、CoreAudio、1920x1080の隔離実行で18検査0失敗となった。
- GodotのViewportへマウスとキーを配送し、SLOTとCLASS、取消と経路選択が無音で機能することを確認した。
  言語のポップアップだけは入力と選択シグナルの接続を直接実行した。
- 選択操作中のMasterの実ミックス信号はピーク0だった。
  回転、攻撃、回復のピークは約0.101、0.165、0.332であり、3音とも再生信号が出た。
- 計画した2歩の確定移動で回転音2回、対象HPが0になる攻撃音1回という順序を確認した。
  HELPによる停止、上限までの実回復、CPU早送りの手番更新でも選択音は混ざらなかった。

実行の記録はartifacts/runtime/three-sfxへ分離した。\
耳での聴感と好み、機器ごとの音量は未確認であり、ミックス信号の確認と区別する。\
REQ-057-S02は未確認のまま維持した。

## 保護と範囲

元の4音と通常セーブ、通常設定の計7パスについて、内容のハッシュと更新時刻、存在の有無が不変であることを確認した。\
素材の出典とライセンスの確認状況も前回から変わらない。\
検証用のゲームを通常BUILDへ戻して終了した。\
物理マウスでの手動対戦、リリース書き出しと動画の音声出力は今回実施していない。\
音声と動画の収録共有、アップロード、pushと公開は行っていない。

## 仕様との照合

5タスクと変更対象の2要件、3シナリオを照合した。\
選択は再生登録から除外し、提供原本と残る音の約束を維持しており、未実装と仕様の不整合は検出しなかった。\
聴感のシナリオは計画どおり実機確認の未確認として追跡する。\
正式仕様のPurposeの古い4音と選択の説明を現行対象へ合わせ、要件の同期では他の回転とHPのブロックを保持する。\
npm run checkと差分仕様のstrict検証は成功した。
