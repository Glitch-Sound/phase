# 攻撃の収束と回復の中心からの発散

## 変更

基準f779184とグレー版12d9b91を維持し、今回だけの独立差分とした。
攻撃は3本の時間差、速度、尺、線幅と消え方を維持し、色だけを赤系へ変えた。
回復は対象の中心近くから緑の円が時間差で外へ広がり、外側で消える形にした。
初期の小さな円を外周まで隠さず、名前の矩形だけを保護して、HPとリングは既存の前面に描く。
対象以外の外形は従来どおり避ける。

回復の開始半径は対象外形の0.12倍、終点は1.9倍、広がりは進行の1.4乗とした。
全体の尺0.42秒と3本の時間差0.06秒、線幅1.35論理pxは変えていない。
色は既存のINFとRESのリング表示色に基づき、組み込みプリセットだけ最低明度0.97とした。
既定では赤と緑であり、カスタム配色のRGBはそのまま使う。
配色設定と保存を変更していない。
軌道、粒子、自然物、発光と待ち時間は追加していない。

## 自動検査

- 既存の表示検査を拡張し、旧来の回復収束と作用種別不足が3項目で失敗することを先に確認した。
- 名前の保護は1項目の失敗を確認してから実装した。
- 表示検査は23項目すべて成功した。
- 回復を収束のままにする誤実装は2項目が拒否した。
- 攻撃のサンプル半径と透明度、調整定数の集合を変更前後で完全一致と確認した。
- 既存の期待値は変えず、バランスの固定期待値は追加していない。
- npm run checkが成功した。
- 戦闘、位相、カタログ、CPU、収集と保存、移動と予定行動は12d9b91と完全一致する。

1920x1080と1440x810で両方の作用を確認し、回復の内側の円と外側の円、文字とHP、隣接者と盤端を確認した。
内側の小さな円が番号に重なって見えたため、名前の矩形を保護して再収録した。
最初の収録試行では入力が通らなかったため素材を使用せず、各手番の実フォーカスを確認して収録した。

設定の保存は行っていない。
