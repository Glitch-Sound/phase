# PREVIEW上の余白の修正

## 対象と判断

REQ-019-S10が定めるHP、行動順、予測のまとまりの間隔を揃える修正である。
既存テストは円の上端を測り、後から追加したPREVIEW見出しを含めていなかったため、見出し上端を測るよう既存の期待値を修正した。
変更前は53px対20pxで失敗し、修正後は論理座標で53px対53pxになる。
新規シナリオ、戦闘ルール、検査コマンドの追加はない。

## 変更

game/tuning.gdのPREVIEW_VERTICAL_OFFSETを33pxとし、見出し、円と領域の上端へ適用した。
領域の下端960px、パネル説明、通知、HPとTURN、タイムライン、盤面、右情報とメニューは維持した。
円の最大包絡と線幅は予測領域内に収まり、特異点の表示も既存の位置を保つ。

## 検証

- tests/time_axis.gd: 修正前268検査中1失敗、修正後268検査中0失敗。
- npm run check: 成功。全体の既存実機確認には未完了19件があり、今回確認した範囲以外を完了へ変更していない。
- 実Godot 4.7.2、Compatibility、Apple M4で、使い捨ての3対3を合法な移動、攻撃、回復8行動によりTURN 09まで再生した。
- 1920x1080、1152x648、1920x1080への往復で6体のリング、HP、補正率、節点、PREVIEWを確認した。
- 各サイズで6体を順にホバー、クリックし、選択が対応し、戦闘状態と経路が不変であることを確認した。
- 実画素の空白行は標準サイズでHPからTURNが58px、タイムラインからPREVIEWが55px、最小サイズで34pxと33pxである。
- PREVIEWの円と見出し、左欄の上下端に重なりや欠けがないことを実画像で確認した。
- キャプチャはartifacts/runtime/preview-margin-turn09-1920.pngと、同じフレームの左欄を切り出したpreview-margin-turn09-left.pngである。
- 実行は通常BUILDへ戻して終了した。

## 限界

今回の表示調整について最小と標準の16:9を確認し、新たな全アスペクト比や全DPIの実機確認は行っていない。
通常セーブと設定は保存していない。
