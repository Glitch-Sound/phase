# 通常表示で読める合成の脈動

## 結果

基準は8f38229であり、開始時の作業ツリーは空であった。
合成の強一致だけの実際の径方向の可動範囲を広げ、通常の1920x1080の戦闘全景で比較した。
個別3輪郭とその位置、暗い不一致、グラデーション、時計と戦闘式は維持した。

従来の合成変位を強一致だけ4倍へ広げ、内外の空きへtanhで滑らかに近づける。
内側の中心線半径は64px、外側の上限は112px、描画領域はRect2(60,738,280,218)、線の外側余白は2pxとした。
これらはgame/tuning.gdへ集約し、既存の速度倍率1.8と振幅強調2.4、色と透明度は変更していない。
角度ごとの空きに収めるため、見出しと個別リング、PREVIEWの中心と他UIは動かしていない。
弱一致は新しい処理を通さず、旧版と完全一致する。

## 通常サイズの観測

前回と同じseed 128の試合を7手合法に進めたTURN 08を使った。
強一致は合法な2マス経路の着地点予測であり、確定した位置とHP、手番を変えていない。
強く一致する同じ角度220度の値を、同じ表示時刻の旧新で比較した。
下記は表示の観測値であり、固定するゲームバランスの期待値ではない。

| 最小1152x648での同じ変位 | 5.979px | 18.181px |

この視認性の最終判断は利用者が行う。

## 検査

| 検査 | 結果 |
| --- | --- |
| 先行失敗 | 新しい実変位の期待値は旧版で1項目失敗した |
| 部品 | phase_previewの169項目成功。既存の合成と動く包絡の期待値を更新し、検査件数は増やしていない |
| 全体 | npm run check成功。戦闘、CPU、移動、保存と既定検査を維持 |
| 実描画 | Godot 4.7.2、Compatibility、Apple M4、本番main.tscnから2370項目、失敗0 |
| 個別と弱一致 | 旧8f38229の個別3輪郭の全データと、強調しない角度の動く座標が完全一致 |
| 色と周期 | グラデーションのRGBと透明度、既存の時計を維持。固定角度の最大と最小の時刻も一致 |
| 収まり | 1920x1080と1152x648で強弱の全景と、最大と最小付近を実描画。内側リング、見出しと下の説明へ重ならず、見切れなし |
| 長い表示 | 3600秒と86400秒でも細かなねじれが蓄積せず、同じ描画領域に収まる |

新しい固定勝敗、手数と戦闘量の期待値は追加していない。
内側を避ける条件に加え、合成の線幅と余白を含む描画領域の条件へ検査を更新した。
期待値は検査対象の関数を呼ばず、独立した正弦波と内外の空き、調整定数から求めた。
旧版の小さい合成では失敗し、個別まで広げる変更と弱一致への一律強調を区別できる。
既存の縮尺入力と動きを抑える設定も成功した。

物理入力、自然な一戦、別OSとGPU、性能の厳密な測定、スマートフォンでの再生は未実施である。
これらを確認済みとせず、manual-checks.mdは未確認を維持する。

## OpenSpecと保護

変更はexpand-result-excursion、設計判断はD-01とD-02である。
1つのMODIFIED要件と6シナリオを、自動検査と開発時の実描画へ対応づけた。
実施した範囲でCRITICAL、WARNINGとSUGGESTIONの指摘はない。
5タスクと差分のstrict検査、同期前のstrict台帳を確認した。
正式REQ-033だけを同期し、既存の題名とPurpose、他の15要件は維持した。
アーカイブはopenspec/changes/archive/2026-11-20-expand-result-excursionである。
利用者の視認性の最終判断を開発時の観測と分ける。
実セーブと設定、既存PNGとMP4を含む15601パスを事前のハッシュ、更新時刻と不存在で保護する。
最終成果物の保存後も変更0件である。
収録と極値確認のゲームは通常BUILDへ戻して終了した。
既存成果物の置換、push、公開と投稿は行っていない。
