# 戦闘画面の囲い装飾削除

## 変更範囲

基準はe04d926である。\
TURNと現在ターン番号、左右情報と円形予測の背景と上罫線、手番通常行の背景と枠、スキル行の薄い背景を除去した。\
手番先頭の枠と背景は現在の操作対象を示すため維持した。\
パネルの下地を除くと半透明の強調色も変わるため、先頭行の中だけ元の下地を描き、合成色を完全に維持した。

中央バトルマップとその選択、ホバー、対象と経路、システムメニュー、全ボタンの状態表現を変更していない。\
手番一覧の記号、位置と入力領域、HPと5値の棒、スキル種別線、円形予測、同期率と通知の分離を維持した。\
BUILD、ACTION、RESULT、HELP、SETTINGSの部品と共通テーマは変更していない。\
以前削除した9表示は復活させていない。\
内部ターンと戦闘式、保存内容、配色に変更はない。

## 自動検査

tests/battle_labels.gdを106件から114件へ拡張した。\
維持対象からTURN文字を外し、数値を含む元の領域全体を非表示対象へ加えたのは、利用者の明示的な指示による振る舞いの変更である。\
4ステージと行動選択、攻撃対象、回復対象、結果の背後で、変更前は8件が失敗し、変更後は114件すべてが成功した。\
TURNの接頭辞を消して9999だけを元の位置へ戻す誤実装も、管理対象外のコピーで8件失敗し、終了コード1となった。

tests/battle_containers_capture.gdのGPU検査を実装前に追加した。\
12画面で左右パネル、予測、通常行、スキル行の背景と外枠の代表画素を画面背景色と完全一致で比較し、TURN2では指定外領域と盤面、メニュー、先頭行を前回画像と比較する。\
変更前は231件中217件が失敗し、最終実装では231件すべてが成功した。\
比較範囲は旧罫線が中心配置で上方1ピクセルにも描かれることを原寸画素で確認し、その実際の除去範囲を含めた。\
先頭行の合成色が変わる実装も比較が失敗し、元の色の維持後に成功した。

既存のプロダクト検査の入口と検査規則は維持し、その中の表示検査を拡張した。\
npm run checkは1,354件のheadless検査、戦闘再生、4仕様とトレースを含め成功した。\
GPU検査はGodotの実レンダラーが必要なため、次の独立したコマンドでも実行した。

```sh
godot --path . --script tests/battle_containers_capture.gd
```

制限されたheadless実行ではmacOSの証明書取得に関する既知のエンジン警告が出た。\
既存の検査規則が識別する警告だけであり、検査を弱めていない。\
最初のGPU実行はsandboxで画面初期化できず、その検査用プロセスだけを終了し、許可済みGodotの通常権限で実行した。

## 実描画と比較

Godot 4.7.2、Compatibility、Apple M4で、前回と同じTURN2、手番2、経路(4,6)から(5,6)、敵AのHP89、INF130.6%、RES94.5%を描画した。\
1920x1080の比較では667,843画素が変化し、指定領域外の差は0だった。\
盤面、システムメニュー、先頭手番行それぞれの画素差も0である。\
背景が変わると文字や線のアンチエイリアス部分も変わるため、除去領域内の全画素一致は要求しない。\
文字とリングの位置は製品差分と実画像で維持を確認した。

基準1920x1080、1440x810、最小1152x648で開始、無効移動、無効対象の9画像を描画した。\
1440で一致と不一致の円形予測も描画した。\
この11画像とTURN2の計12画像で背景検査を行った。\
開始通知と無効通知を隠さず、同期率の分離を確認した。

## 実Godotでの操作

通常の1438x809埋め込み表示で、次の操作を行った。

1. BUILDからSTARTし、TURNと囲い装飾の不在、盤面、先頭行、情報の棒と種別線の保持を確認した。
2. (4,4)から(5,4)へ経路を選び、囲いのない手番行のAをクリックした。右詳細はA、予測は手番1を維持した。
3. 終点をダブルクリックし、ACTIONのTabで攻撃へフォーカスを移し、Enterで対象選択へ進んだ。枠、背景と有効状態を区別できた。
4. 無効対象の通知とBACKを確認し、移動を保持してACTIONへ戻った。
5. 攻撃対象Aをクリックし、-11、敵HP合計189、手番2への更新を確認した。TURN文字は表示されなかった。
6. 手番2で(4,6)から(5,6)へ経路を選び、一覧からAを選んだ。HP89/100とINF130.6%、RES94.5%を同時に確認した。
7. HELPとSETTINGSを開き、説明、外枠、操作部品とTabフォーカスを確認した。Escで閉じ、経路とAの選択を維持した。
8. RESTARTでBUILDへ戻し、BUILDの枠と背景が残ることを確認して、Godotの画面操作を終了した。

SAVE、LOAD、APPLY COLORSは操作していない。\
実ユーザーセーブと設定の保存、上書き、pushと公開は行っていない。
