# BUILD装備アイコンの高さ調整

## 判断と変更

AGENTS.mdの見た目の値の調整として直接変更した。
既存シナリオと戦闘の振る舞いを変更せず、OpenSpec changeは追加していない。
BUILDの剣と盾は、いずれも可視画素の中心が対応する見出し文字より4px低かった。
共通の描画矩形をgame/tuning.gdへ置き、両方を4px上へ移した。
図柄、サイズ、配色、文字、CLASSとMUTATIONの基準線、操作領域、戦闘画面は変えていない。

## 検証

- 実Godot 4.7.2、Compatibility、Apple M4で1920x1080と1152x648を描画し、実画素を確認した。
- 標準サイズでは文字に対する可視中心差がARMSとGEARとも4pxから0pxになった。
- 最小サイズではARMSが2.5pxから0px、GEARが2pxから-0.5pxになった。
- 変更前後の全画素比較で、2つのアイコン周辺以外の差分は両サイズとも0だった。
- 両サイズでARMSとGEARのダイアログをマウスイベントで開き、取消後に使い捨て編成が不変であることを確認した。
- npm run checkが成功した。
  既存の自動テストと検査コマンドは変更していない。
- 通常BUILDへ戻して検証用Godotを終了した。
- Library添付対象はartifacts/runtime/build-icon-after-1920.pngであり、ゲーム画面だけを含む。

## 限界

今回の実描画は標準と最小の16:9に限り、追加DPIでの実機確認や物理マウスによる操作は行っていない。
実セーブと設定は保存していない。
