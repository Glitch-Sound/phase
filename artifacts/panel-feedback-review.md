# パネルと位相の手応えの検証

## 変更

RESETのLucide diamondのパスを維持し、fillを白へ変えて既存の役割色で着色する。\
盤面とHELPの同じ素材を塗りつぶしたひし形へ変え、回転の2記号と文字による確認手段を維持した。\
NOTICEへ塗りの変更を記録し、同梱LICENSEは維持した。

ユニット選択とホバー、経路終点の角枠、隣接する対象の範囲と有効対象の全周線をセル背景と同じ枠上へ移した。\
枠の色と線幅を維持し、隣接セルとの間隔と盤面端の内側を保ち、目標セルの内側の印は動かしていない。\
枠は表示だけであり、入力の座標と判定は変更していない。

予測は実際の局所的一致を使い、装備の山の最大振幅を16px、結果を22pxとし、一致が低いときは最大の35%まで抑える。\
一致を境界の色と同じ方法で補間してから平方根を表示用の強度にし、不透明度を既存下限から1へ増す。\
線幅は全周の平均一致に応じて装備0.9から1.4px、結果2から3.4pxへ増す。\
局所領域の一致の表現であり、LUKやベルカーブを含む最終戦闘倍率の比例グラフではない。

~~~mermaid
flowchart LR
  PHASE["実際の配分と角度"] --> LOCAL["局所的一致"]
  LOCAL --> BLEND["境界補間"]
  BLEND --> SIZE["広がりと不透明度"]
  LOCAL --> AVERAGE["全周平均から線幅"]
  SIZE --> DRAW["4輪郭の描画"]
  AVERAGE --> DRAW
~~~

RGBとグラデーション、内側の3リングとHP、盤面寸法と左右の位置、数値と操作、戦闘式と保存形式は維持した。\
最大の描画半径は線幅を含めて約102.5pxであり、予測の領域、行動順、盤面と通知を隠さない。\
時間揺れと発光は追加していない。

## 先行検査と誤実装

- 旧実装で記号と枠の12項目、広がりと線幅の7項目が失敗した。
- 部分一致の境界で振幅倍率が急変する段差を実画像で見つけ、連続性の3項目を先に失敗させてから境界補間で直した。
- panel_interfaceの113項目で記号とHELP、全効果の意味、四隅と通常セルの選択と終点、対象枠の全体列を確認した。
- phase_previewの140項目で低、中、高の広がりと不透明度と線幅の厳密な大小、全5色のRGB、境界のグラデーション、有限の閉曲線、更新とキャッシュ、入力と通知の分離を確認した。
- 元から成立する不透明度の大小、色とグラデーションの検査は変更せず維持した。
- 空のRESET、内側へ戻した枠、固定振幅、固定線幅、段差、白い色への置換の6変異を検出した。\
  失敗数は1、10、3、4、3、30であり、構文エラーではなかった。
- 最終コードのnpm run checkでプロダクト、既存の戦闘再生、4仕様とトレース検査が成功した。
- プロダクト検査コマンドの構成は変更していない。

## 実描画と入力

Apple M4、Godot 4.7.2、Compatibilityで最終GPU検査391項目が成功した。\
1152x648、1920x1080、2560x1440と縦長1200x1600で、実際の経路入力と取消、時間軸のホバーと選択、予測の保持を確認した。\
縦長はkeepによる1200x675の内容領域と余白を持つウィンドウであり、画像は内容領域を取得した。\
各サイズの四隅と中央、選択と終点で、枠の差分はセル境界の帯だけに収まり、ひし形の実際のインクを塗り潰さないことを画素で確認した。\
隣接する選択セルと経路終点の同時表示、隣接する回転記号と攻撃対象も比較した。

初回の拡大端検査は小数の座標を切り捨てたため、一部だけ覆われる最終画素を盤外と誤判定した。\
隣接比較のマスクにも同じ切り捨てがあり、正しい枠の48画素を対象外と誤判定していた。\
画素が実際の矩形と交差する範囲へ修正し、端の線を小さくしたり検査の対象を除いたりせず再検査した。\
隣接ケースの追加時にはGUI再生の更新待ちを補強し、誤った履歴なら先へ進まず停止するようにした。

低、中、高は角度を明示した表示fixtureであり、実進行とは分けた。\
最小と標準のDEFAULT、標準のAMBERとカスタムの配色で比較し、内側のリングとHP、4輪郭と色のつながりが残ることを目視した。\
標準DEFAULTの予測外周の明るい画素数は2486、3036、3919であり、低から高へ増加した。\
RGBの合計も約7231、8679、11349へ増加し、色を白へ置き換えずに明るさと面積を増した。\
これは外周の実画像の観測値であり、効果倍率の単位ではない。

通常の1438x809埋め込みでも、塗りつぶしたひし形と回転記号、セルの枠上の終点と攻撃対象、経路に応じた予測の変化を観測した。\
ACTIONから攻撃を実行し、敵AのHP100から90への変化と手番更新、時間軸の選択、HELPの塗りと説明、BUILDへの復帰を操作した。\
実セーブと設定を保存せず、画面操作を終了した。

## 限界と保存保護

全てのカスタム色、独立全画面の手動比較、今回の表示での自然な一戦の完走は再実施していない。\
最小表示の最終的な読みやすさはユーザーの通常の表示環境で確認する必要がある。\
GPUの描画時間はp95が8.487ms、最大15.094msだった。\
この観測はGodot側の描画処理時間であり、GPU全体のフレーム時間や他の機器の性能保証ではない。\
全体の実機台帳の未確認状態を維持する。

実セーブのSHA256は25167e282e85b12fd9f059ae72d9cb16e4d6fb55310b1d3f57295dd02a6573e2、更新日時は2026-11-15T01:12:39.637Zで不変だった。\
通常のui-settings.jsonは存在しない。\
実セーブと設定保存、pushと公開は行っていない。
