# 攻撃の白い外縁の除去

## 変更

9882aa6から、攻撃の白い外縁と高INF強調、撃破後の白い外縁だけを除去した。\
攻撃専用の定数、発動者情報と描画分岐、旧期待値も削除した。
赤い収束、緑の拡散と実HP増分の反応、HPと数値、撃破と手番、移動と雲は維持した。
戦闘計算、CPU方策、取得と保存のコードは変更していない。

## 検査

- 攻撃の白縁がない検査を先に変更し、旧実装で1項目が失敗することを確認した。
- 変更後は既存の表示検査30項目がすべて成功した。
- 不要になった攻撃の強度と発動者の検査だけを整理し、回復の実増分、上限とゼロ、幾何と消去の検査は維持した。
- 既存円の14時点と全定数、回復反応の21サンプルは変更前後で完全一致した。
- npm run check、変更と正式仕様のstrict検証、トレース検査が成功した。
- 検査コマンドと固定バランスの期待値は追加変更していない。

## 実描画

Godot 4.7.2、Compatibility、Apple M4を使い、1920x1080と1440x810で通常攻撃、高INFの撃破と回復を確認した。
前回と同じシード128、異なる6構成の全解放3対3と合法な再現操作を使用した。

| 場面 | 観測 |
| --- | --- |
| TURN07、Cの通常攻撃 | INF約38%、赤い収束だけで白い外縁なし |
| TURN08、1の攻撃 | INF200%、Aの撃破後も赤い収束だけで白い外縁なし |
| TURN09、2の回復 | 1の129から135への実増分だけが従来の時刻、幅と透明度で反応 |

最終CONFIRMから移動、着地、既存の一拍と攻撃まで追加入力なしで進み、移動中の白い経路線はない。\
右情報とPREVIEW、盤上のリング更新、雲の透過と再表示も既存どおりである。
2手の最終ユニット状態と履歴は、表示を持たない同じモデル操作と完全一致した。

## 保護と限界

基準コミットと過去の成果物は維持し、実セーブを含む29ファイルのSHA256と更新時刻が不変である。\
実UI設定は未作成のままで、隔離collectionから通常BUILDへ戻して検証用Godotを終了した。
今回の実GPU操作は合法な再現であり、対CPUの一戦を手動完走したものではない。\
CPUの既定回帰検査は成功したが、新しい状態のCPU対戦を実GPUで再撮影していない。
iPhone実機と別GPU、利用者の最終的な見た目の判断は未確認である。
push、公開とX投稿は行っていない。
