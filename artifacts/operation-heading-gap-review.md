# 作戦グループの余白の確認

## 変更

作戦目的のY座標だけを88から75へ13px寄せた。\
作戦名と目的をまとめ、その下のCLASSまでの余白を広げた。\
マップ、CLASS以下のユニット情報、文言と作戦ロジックは変更していない。

要件に定めていない寸法の調整として直接変更した。\
定義はgame/tuning.gdの1か所とし、既存のテストと仕様のシナリオは変更していない。

## 検証

- npm run checkは成功し、正式仕様9件で失敗0となった。
- Godot 4.7.2、Apple M4、Compatibilityの実ウィンドウで30件、失敗0となった。
- 英日、1920x1080と1152x648、OPERATION 01と02を確認した。
- 実際の文字ピクセル間で、標準のグループ内は4から7px、目的からCLASSまでは46から50pxとなった。
- 最小のグループ内は1から3px、目的からCLASSまでは27から30pxとなった。
- 現行の最長の目的も一行に収まり、重なりと見切れはなかった。ユニット情報の位置と下部ボタンの表示領域も維持した。
- 英日のHELP実表示には、戦闘で別のCONFIRMを押す案内はなかった。ACTは対象選択で移動と行動を実行する説明であり、HELP自体は変更していない。
- キャプチャはseed48の隔離データで、合法な1マス移動とWAIT後のTURN02である。ゲーム画面のみで、デスクトップと個人情報を含まないことを確認した。
