# HELPのアイコンと見出しの縦中心

## 変更

基準は914c856で、開始時の作業ツリーに変更はなかった。\
前回の日本語HELP画像を実際に開き、上段のROUTE、ALIGN、ACTと、PHASE欄の3種類のパネル効果の計6組を対象とした。\
アイコンの明るい画素の外接矩形の中心は、対になる文字より約5.5px低かった。

game/tuning.gdのHELP_ICON_VERTICAL_OFFSETへ調整量を一元化し、HELP内の6アイコンだけを5.5px上へ移した。\
見出しと本文、横位置、アイコンの図柄と大きさ、ボタンと設定画面は変更していない。\
シナリオを変えない表示寸法の調整として直接変更し、既存のテストは変更していない。

- npm run checkは101組、8257件、失敗0である。
- 所定の8仕様の検査とトレース検査が成功した。
- Godot 4.7.2、Compatibility、Apple M4の描画確認は63件、失敗0である。
- 英語と日本語、1920x1080と1152x648を表示し、6組の実画素から縦中心を測った。
- 修正後の差は標準で最大0.5px、最小で最大1pxであった。
- 日本語HELPの本文と見出しの画素は、旧画像と完全一致した。
  比較はアイコンの移動領域と操作状態の違う下部ボタンを除いたHELP本文領域を対象とした。
- SKILLSへのEnter操作と、HELPを閉じるEscをGodotの入力イベントで確認した。
- 通常BUILDへ戻して検証アプリを終了した。
- 実セーブと配色、説明言語の設定、旧HELP画像と直前の設定画像は、内容と更新時刻に変更がない。

調整値のために固定のゲームバランス検査や新規のプロダクト検査は追加していない。\
