# GitHub公開前のソースレビュー

## 対象と判断

基準はa212a02、調査開始時の追跡ファイルは1176個、到達可能なコミットは112個である。\
製品のgameとuiの31個のGDScriptについて、戦闘、カタログ、位相計算、CPU、保存、識別、入力、描画、各ダイアログ、言語、効果音の責務と接続を確認した。\
テストを含む152個のGDScriptには構文検査、静的解析、整形診断を実行した。\
開発用のMJS 5個、Python 2個、シェル2個には、それぞれの構文検査も実行した。

新しいシナリオやゲームの振る舞いは追加しないため、直接変更として扱った。\
バランス値、保存形式、効果音、移動と攻撃の演出、既存テストは変更していない。

## 挙動と性能の比較

旧コードを隔離して読み込み、2作戦と3シード、6体の構成で、変更前後のCPUの経路、行動、対象、評価値を比較した。\
6条件の各12手、計72判断について、選択と評価値に加え、ユニット、履歴、結果、手番の状態が完全一致した。\
これは今回の一時的な差分検証であり、固定勝敗や固定ダメージを継続テストへ追加したものではない。

同じMacのヘッドレス実行で、各条件を3回計測した中央値は、CPUの1判断が約6.9〜8.1%短縮した。\
対象判定10万回は114011µsから71815µsへ短縮した。\
特定の初期構成と環境での観測であり、全場面の速度改善率を保証しない。

## 実行した検査

- 変更前後のnpm run checkは成功した。既定のGodot検査、回帰テスト、10個のOpenSpec仕様の検証を含む
- 補助ツールは公式PyPIのgdtoolkit 4.5.0を.tool-cache内の仮想環境だけへ導入した。ゲームの依存やロックファイルは変更していない
- gdformat --check game ui testsを実行した。変更前は149個、変更後は148個が汎用整形との差異として残る
- gdlint game ui testsを実行した。変更前1932件、変更後1922件であり、全件成功ではない。大半は既存の長行や宣言順の指摘である
- 編集した2関数と小さいライセンス部品へ実際にgdformatを適用した。ASTの同一性検証を有効のまま使った
- ui/license_dialog.gd単独のgdformat --checkとgdlintは成功した
- node scripts/lint.mjs、MJSのnode --check、Pythonのast.parse、シェルのsh -nは成功した
- Web Demoを既存プリセットから再書き出しし、node tests/web_licenses.mjsと、生成PCKに対するtests/licenses.gdの14項目が成功した
- PCK内の7つのライセンス原文、使用中の5音、PHASE画像を確認した。未使用のselect.oggとring_rotate.oggと関連インポートは含まれない
- git diff --checkを実行した

全体のスタイルを通すために149ファイルを一括整形したり、診断ルールを無効にしたりしていない。\
汎用スタイルの全面解消は今回の完了項目ではない。\
既定検査は、過去の実機記録に未確認または不合格が31件残ることも通知している。\
今回の部分的な実操作を、これら全件の再確認として扱わない。

## 利用者と同じ入口での確認

再生成したHTML一式をループバックHTTPで開き、MacのBraveで実行した。\
日本語BUILD、初回解放一覧、HELPの3項目、SETTINGSからのLICENSES、GodotとLucide原文の閲覧を確認した。\
SAVEとLOADは非活性のままで、SAVEのクリックで保存画面や状態変更は発生しなかった。

対CPU戦闘を開始し、TURN 01のユニットのダブルクリックからWAITを選択、TURN 02のCPUの経路予告と移動、TURN 03の手動2マス経路と行動選択、確定移動、TURN 04への更新を確認した。\
移動途中のリングと左右の情報更新、確定後の白い経路非表示を実描画で確認した。\
今回のブラウザ確認では撃破や回復を含む終局までは再プレイしていない。\
最後は再読み込み後の日本語BUILDへ戻して操作を終了した。

実セーブと設定の保護対象17ファイルを、既存の基準ハッシュと照合して一致した。\
ブラウザの試験データはWeb Demoの一時メモリだけを使った。

## 公開前の棚卸し

調査開始時の112コミットから、2MB以下の2176個の一意なGit blobを確認した。\
秘密鍵、代表的なAPIトークン、認証情報付きURL、秘密値らしい代入の7系統のパターンに一致はなかった。\
追跡された秘密ファイル名、セーブや設定の実データらしいパスも検出しなかった。\
実値を検査ログやこの報告へ出していない。

これは既知パターンの検査であり、未知形式の秘密、全バイナリ、到達不能なGitオブジェクトを含む完全監査ではない。\
63個のバイナリと、2MBを超えるフォントおよび検証PNGは秘密文字列の検査対象から外れた。\
現在の59個のPNGでは文字メタデータとEXIFのチャンクを検出しなかったが、全画像の画素内の個人情報までは再確認していない。

| 公開前に判断する事項 | 現状 |
| --- | --- |
| 自作ソースのライセンス | ルートにLICENSEはない。本人が許諾範囲を決める必要があり、独断でMIT等を設定していない |
| コミットの著者情報 | 調査対象に1種類のメールアドレスがあり、GitHubのnoreply形式ではない。実値は報告しない |
| ローカルパス | 55個の過去blob版にホームパスがある。現在のREADMEの実行例は整理したが、履歴と過去の検証記録は変更しない |
| 過去の検証資料 | artifactsに207個の追跡ファイルがある。ソース公開へ含める範囲を本人が確認する必要がある |
| 音源 | CC0は本人確認済み。元サイト、取得元文書との独立照合は未完了であり、原音のソース配布についても証跡の有無を区別する |
| その他の同梱素材 | Godot、Lucide、Notoの原文と出典を各assets配下に保持している。ゲーム同梱だけでなくソース再配布でも原文を残す |
| 開発用生成物 | OpenSpecスキルのMIT表記に対応する原文をdocs/licensesへ加えた。PHASEの自作コードや全テンプレートをMITにするものではない |

ライセンスの未指定とGitHub上の公開は同じ意味ではない。\
自作コードの許諾については[GitHub公式のライセンス案内](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)を参照する。\
第三者素材の条件は自作コードの許諾とは別に維持する。

## 残る技術上の注意

過去の比較用scripts/tempo-study.py、tests/tempo_study.gd、tests/decision_analysis.gdには、旧4作戦や旧2体構成を前提にする分析が残る。\
これらはnpm run checkの入口には含まれず、現在の2作戦と6体の分析ツールとしては未対応である。\
構文は検査したが、長時間の旧研究を再実行して過去の成果物を書き換えていない。\
現行製品の起動や戦闘の不具合と混同せず、再利用時に調査条件を作り直す必要がある。

履歴の改変、リモートへのpush、GitHubやゲームの公開、素材のアップロードは行っていない。\
既存のテストが書き直す2つの追跡JSONは今回の変更から外し、過去の成果物を保つ。
