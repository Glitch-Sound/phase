# 承認済みロゴの適用

## 元の表示

独立したタイトルメニューはなく、起動後はBUILDを表示する。\
以前のWebアイコンと起動画像は、黒に白系の閉じた同心円3本を置いた128px画像で、文字はない。\
戦闘左上のPHASEは画像ではなく白系の文字描画である。

## 変更

本人へ提示され承認された676x184のSVG原稿を、assets/branding/phase-lockup.svgへそのまま保持した。\
3本の円弧は欠けの角度が異なり、白系、淡い青緑、青緑の順である。\
5文字はすべてパスであり、追加フォント、外部画像と通信は必要ない。\
リング単体のphase-mark.svgは、横長原稿の円弧群を変えずに184x184へ取り出したものとした。\
輪郭群と3色が同一であることをXMLの要素比較でも確認した。

横長版をGodotの起動スプラッシュ、Webの読み込み画面、BUILDのヘッダーへ適用した。\
BUILDは従来の見出し領域の1箇所を160px幅のロゴへ置換し、UNITとトグル、STARTの位置と操作を変えていない。\
画像はマウス入力を透過し、ボタンの領域へ重ならない。\
戦闘HUDの文字PHASEは追記の指示どおり変更していない。\
ブラウザの小さいアイコンとApple用アイコンはリング単体を使う。\
既存のassets/phase.svgとphase.pngは削除や上書きをせず原本として残した。

ロゴのPNGはGodotのSVG読み込みで出力した。\
透明境界のRGBが自動で補正されることを検出したため、ロゴ4素材だけのインポート設定でfix_alpha_borderを無効にし、原稿からの出力の形と色を保持した。\
通常のテクスチャやフォントの設定を変更していない。

既存のPHASE図案を承認図案に置き換え、配布内容と保存の条件は変わらないため、シナリオを増やさない直接変更として扱った。\
既存のREQ-064-S01の配布検査について、承認された新しい起動画像とアイコンへの完全一致を先に期待値へ反映し、未実装で失敗することを確認してから適用した。\
ゲームロジック、シナリオ、保存形式、音、戦闘HUD、MITの対象2ファイルは維持した。

## 検証

- Web Demoを既存のプリセットで再生成した
- 実HTMLの読み込み画像はindex.pngへ解決し、起動画像は横長PNG、faviconはリングPNGとバイト単位で完全一致した
- 全9権利文書、使用中5音、未使用2音除外、デモの保存禁止と起動シェルの検査を成功させた
- GodotのGPU描画で英日、1920x1080と1152x648のBUILDを撮影し、4画像の実ピクセルを確認した
- QAでTextureRectが原寸へ拡張する問題を検出し、縮尺の設定順を修正して、UNIT領域との非重複を再確認した
- npm run checkとgit diff --checkを実行した

確認画像はartifacts/runtime/branding/build-ja-1920x1080.png、build-en-1920x1080.png、build-ja-1152x648.png、build-en-1152x648.pngである。\
検証は一時メモリだけを使い、通常セーブと設定は保存しない。

新ロゴ反映後の追加のブラウザ手操作は、Macロックで接続できず未確認である。\
ロックを迂回せず、読み込み画面の実際の持続時間、クリックとfaviconのブラウザ実表示は再確認を残す。\
Godotの実GPU描画と、実際のWeb出力内容の確認とは区別する。
