# 局所リング反応の試作

## 変更と復旧点

2d59dcbから、今回の局所反応だけを独立した差分とした。\
f779184、12d9b91、2d59dcbと過去の動画、画像は維持した。

赤い攻撃と緑の回復の円は、形、色、時間差、速度、線幅と寿命を変えていない。\
変更前後の全調整定数と14時点の幾何サンプルは完全一致した。
戦闘、位相計算、カタログ、CPU方策、収集と保存、移動と予定行動のコードは変更していない。

攻撃は最初の収束終了時(表示開始から0.30秒)に、装備リングのすぐ外側の縁だけを白くし、0.12秒で1回減衰する。\
通常は幅1.35論理pxと透明度0.70、最終INF160%以上は幅1.85と透明度0.98とした。
発動者を手番更新前の番号から受け取り、次のユニットのINFを使わない。
撃破後は記録した位置へ白い外縁だけを描き、名前と本体、HPを復活させない。

回復は既存の広がり式から最初の円がHP半径へ達する時刻を逆算し、実際の増分区間だけへ0.18秒の淡い縁を出す。\
表示は幅3.4論理pxと透明度0.55で、白いHPの芯より下へ描く。
確定HPと実回復量から範囲を求め、上限を超えた分とゼロ増分を除く。
元の円と同じ0.42秒以内で終え、HP、数字、撃破と手番の時点、移動と雲、右情報を待たせない。
素材、粒子、軌道、追加の待機と全面の閃光は追加していない。

## 自動検査

- 既存の表示検査に追加し、未実装で4項目の失敗を確認した。
- 実装後は34項目すべて成功した。
- 全HPを光らせる誤実装は増分範囲と幾何の2項目、接触前に光らせる誤実装は時刻の1項目で失敗した。
- 既存の検査の期待値と検査スクリプトは変えず、固定ダメージと勝敗の期待値は追加していない。
- npm run checkが成功し、正式仕様と変更のstrict検証、トレース検査も成功した。

## 範囲と限界

今回の実GPU操作は合法な再現であり、対CPUの一戦を手動で完走したものではない。\
CPUの既定回帰検査は成功したが、今回の反応をCPU対戦で再撮影してはいない。
終局では既存RESULTを即時に開くため、局所反応は背面で終わる。\
ユーザーへ見せるためにRESULTを遅らせる変更はしていない。
増分が小さい回復の反応は短い円弧に限られ、全景より拡大比較の方が読み取りやすい。
iPhone実機、別GPUと外部サービスの再圧縮、利用者の最終判断は未確認である。

実セーブ、旧動画と過去の比較画像を含む27ファイルはSHA256と更新時刻が不変で、実UI設定は未作成のままである。\
隔離データから通常collectionへ戻し、通常BUILDを確認して検証用Godotを終了した。
push、公開とX投稿は行っていない。
