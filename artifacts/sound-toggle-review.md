# 効果音切替の検証

## 変更

SETTINGSの既存操作行へSE ONとSE OFFを追加した。\
REDUCED MOTIONの領域を分け、言語と色、下端の操作の配置を維持した。\
切替そのものはマウスとキーのどちらでも無音である。

未指定と不明な値はONとし、明示操作だけを既存設定パスに.audio.jsonを付けた音専用ファイルへ保存する。\
通常の保存先はartifacts/runtime/ui-settings.json.audio.jsonになる。\
保存に失敗した場合は以前の状態とトグルへ戻し、英語または常体の日本語で説明する。\
全解放中は一時設定だけに反映し、終了すると元へ戻す。

OFFへの変更ではボタンを含む全声と撃破の予約を同じ更新で停止する。\
歩と効果の消費済み識別を保持するため、ONへ戻しても過去の音を再発火しない。\
ON時の素材、音量と発音の時点、戦闘と表示の時計は変更していない。

## 自動検証

- 実装前はSFX61件中3件が失敗した。既存の無効フラグの要求抑制は元から成功した。
- 実装後はSFX76件すべてが成功した。保存、復元、不明値、書込不能、全解放の分離、GUIの無音操作と停止を含む。
- 既存の移動、攻撃、回復、撃破と通常ボタンの期待値は維持した。
- npm run checkと差分の検査が成功した。ゲームバランスの固定期待値と検査コマンドは追加していない。

## 実描画と音声信号

Godot 4.7.2、Compatibility、Apple M4、CoreAudioで、隔離した保存先を使った。\
英語と日本語の1920x1080と1152x648で、SE、REDUCED MOTIONと言語の領域と文字が収まり、画像の画素でも重なりと見切れがないことを確認した。

実GUIのマウスでOFF、キーでONへ切り替え、全声の停止と遅延予約の破棄を確認した。\
ゲームの中央音声部品から6種類の音を要求し、Masterのミックス信号を取得した。\
ONの前後は各音で信号を検出し、OFFでは全6種類のピークが0だった。\
ONへの復帰では過去の効果と撃破の信号が出ず、新しい要求だけを再生した。\
Masterのミュートと音量は不変だった。\
主検証30件と、別のGodotプロセスでOFFを復元してONへ戻す7件が成功した。

## 限界

実音声の確認はゲームのミックス信号であり、スピーカーから耳へ届く遅延と主観的な聴感は測定していない。\
戦闘の音の実配線は既存のUI検査を維持して確認し、今回の信号測定は音声部品への再生要求を使った。\
自然対戦の通しプレイと、既存の利用者向け実機確認30件は今回の完了範囲に含めない。
