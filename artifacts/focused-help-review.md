# 3点に絞ったHELPの検証

## 内容

HELPを5ステータスの表、同じユニットの移動前後のリング比較、戦闘終了時の解放の一文だけへ置き換えた。\
操作手順とWAIT、スキルとFIELDの解説、それらへのリンクと専用関数は除去した。\
BUILDと戦闘のスキル表示と説明、作用は変更していない。

| ステータス | 現行計算から確認した作用 |
| --- | --- |
| VIT | 3リングの配分から最大HPを計算する |
| INF | 攻撃と回復の威力、位相の補正へ作用する |
| RES | 被ダメージへの抵抗、位相の補正へ作用する |
| SPD | COREは手番間隔、各リングは1歩の回転量へ作用する |
| LUK | 3リングの最小値から位相の許容幅を計算する |

色は実際のring_colorsを共有し、VITなどの文字でも区別する。\
図は同じ初期ユニットを複製し、通常セル1歩の実計算を適用して共通のリング描画へ渡す。\
配分と紋章は不変で、GEARとARMSの回転とINF、RESの補正率だけが変わる例である。\
戦闘原本と乱数を変更せず、画像素材を追加していない。

解放の一文は勝敗を問わず、UNLOCK ALL以外で装備、スキル、変異がランダム解放される場合があると説明する。\
毎回の取得を保証せず、ゼロ件と全解放時の報酬なしを維持する。

## 検証

- 先行検査で説明全体の集合、3セクションとナビゲーション、色と比較図の4件が失敗した。
- 変更後のDESIGN FLOWは162件で失敗0となり、説明の原文7件と見出し3件の全体一致、CLOSEだけの操作、同じユニットの1歩の角度を検査した。
- 削除した旧HELP文面だけに依存する期待値を整理した。スキルの作用、パネルと周囲、紋章、経路と時間軸の本体検査は維持し、検査を無効にして通していない。
- Godot 4.7.2、Apple M4、Compatibilityの実描画で英日、1920x1080と1152x648の21項目、失敗0となった。表と図、文字の収まり、マウスでのCLOSEと原戦闘の不変を確認した。
- npm run checkと正式仕様9件、OpenSpecのstrict検証、トレースとgit diff --checkが成功した。プロダクトの検査コマンドは変更していない。

verifyでは変更した4要件の全シナリオを既存の確認と対応付け、3点の完全一致を強めたため旧文面やスキルリンクの残留を見逃さないことを確認した。\
設計D-01と実装の一致を確認し、CRITICALとWARNINGの指摘はない。

## 画像と限界

日本語の最終画像はartifacts/runtime/focused-help/phase-focused-help-ja-1920x1080.pngに置く。\
同じフォルダに英日と最小の補助画像、runtime-result.json、先行失敗と最終検査のログを残す。\
入力はGodot実ウィンドウのInputEventであり、OSの物理操作と利用者の最終確認とは区別する。\
検証用GodotをBUILDへ戻して終了し、実セーブと設定は保存せず、既存の実機台帳の確認を完了扱いにしていない。
