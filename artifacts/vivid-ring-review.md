# リング配色の検証

## 変更範囲

基準は33823c9である。\
CORE、GEAR、ARMSの形状、半径、間隔、線幅、アンチエイリアス、配置、HPの白色は変更しない。\
基本のプリセット6色も変更せず、組み込みプリセットと完全に一致する場合に限って、リングへ渡す5色の彩度を高める。\
他のUI、波形、数値、操作部品は元の基本色を維持する。\
色設定の既存説明1行だけを、プリセットとカスタムの違いへ置き換えた。

## プリセットとカスタム

| 配色 | リング | 保存と他UI |
| --- | --- | --- |
| DEFAULT、AMBER、ICEと6色すべて一致 | 色相とHSVのVを維持し、彩度を高める | 基本の6色を維持する |
| 6色のどれかが異なる有効なカスタム | 指定した5色のRGBをそのまま使う | 指定値を維持する |
| 保存済みの組み込み配色 | 表示だけを鮮やかにする | ファイルを書き換えない |
| 保存済みの有効なカスタム配色 | そのまま表示する | ファイルを書き換えない |

アクセントだけの変更もカスタムとして扱う。\
保存形式は6色の配列のままであり、過去の設定の移行は不要である。\
設定画面の色見本は保存する基本色を示し、リングでは組み込み配色だけ表示用の強調を使う。\
明示的なAPPLY COLORSで保存する場合も、派生したリング色を書き戻さない。\
既存の有効色、コントラスト、色の区別の検証と、不正な配色の拒否は維持した。

彩度の強調量はgame/tuning.gdのUNIT_RING_SATURATION_POWERを正とする。\
初期値2.0で、既存3プリセットの派生色すべてが判読性と区別の基準を満たした。\
共通のring_colorsを使い、盤面、TURN ORDER、右詳細、下部予測、BUILDの3リングへ同じ対応を適用する。\
変換はテーマ設定時だけに行い、フレームごとのリング描画へ変換処理を増やさない。

## 検査

- 追加テストを先に実行し、旧実装で5件の失敗を確認した。
- 新しい配色の52検査が成功した。\
  3プリセットの色相、HSVのV、彩度、区別とコントラスト、入力の不変性、カスタムRGBを検査した。
- カスタム色の読み込みと描画で、設定ファイルの全内容が変わらないことを確認した。\
  明示適用の保存では基本色を保存し、未確定経路と戦闘データを維持した。
- 強調しない変異は15件、カスタムも強調する変異は2件の失敗として検出した。\
  検証用コピーを使い、製品の実装は変更していない。
- scripts/check.shにring_paletteを追加した。\
  npm run checkは1,166検査、戦闘再生、4仕様の厳密検査が成功した。
- 実GPUの円弧検査を新しいリング色へ接続し、240件成功した。\
  HPの連続性、不足区間、6倍率、4体、PNGの全画素一致を維持した。
- 性能測定の旧描画側も同じring_colorsを受け取るようにし、比較条件を揃えた。\
  今回は色変換だけであり、性能を新しく計測したとは扱わない。

## Godotの実画面

Godot 4.7.2、Apple M4、Compatibilityの実ビューポートを撮影し、原寸の画素と表示を確認した。

| 観点 | 結果 |
| --- | --- |
| DEFAULT | VITの青みを含む銀、INFの赤、RESの緑、SPDの青、LUKの黄の分類を維持し、3リングを鮮やかにした |
| AMBERとICE | 元の色相分類を維持して強調し、色の境界とHPの白を区別できた |
| カスタム | アクセントだけを変えた配色でも、リングの5色は指定RGBのままだった |
| 背景 | 盤面の交互のセル背景、左右の暗い面、予測とBUILDの背景で確認した |
| サイズ | 1920x1080、1152x648、縦長1200x1600の1200x675描画を確認した |
| 比較 | 同じTURN2で、色リング内だけ17,447ピクセルが変化した。他UI、白いHPと中央名の変化は0だった |
| ゲーム状態 | 内部手番02、AのHP89、経路(4,6)から(5,6)、INF130.6%、RES94.5%を再現した |
| 色設定 | プリセットのリング強調とカスタム色の保持を説明する1行が、既存の領域内に収まった |

## 境界

実機確認は今回のリング配色と関連する色設定の範囲である。\
自然な一戦、OSの全画面と高DPI設定の再変更、ネイティブ手操作全体を新たに実施したとは扱わない。\
既存の拡縮、フォーカス、戦闘と保存の回帰検査は継続して成功した。\
通常のセーブとUI設定は保存せず、検証の設定保存には別のfixtureファイルを使った。\
追加アプリ、push、公開は行っていない。\
利用者による鮮やかさの最終確認は残る。
