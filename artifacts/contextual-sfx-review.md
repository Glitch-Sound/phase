# 効果音の実装と検証

## 変更

935a731を基準に、本人がassets/sfxへ置いた4つのoggを接続した。\
音源の内容と更新時刻は変更せず、取得元の推定と外部素材の追加は行っていない。\
出典とライセンスは未確認であり、assets/sfx/NOTICE.mdに記録した。

| ファイル | 長さ | 原音RMS | 再生音量 |
| --- | --- | --- | --- |
| select.ogg | 約0.059秒 | 0.062 | -18dB |
| ring_rotate.ogg | 約0.512秒 | 0.033 | -18dB |
| attack.ogg | 約0.784秒 | 0.313 | -15dB |
| heal.ogg | 約0.366秒 | 0.113 | -8dB |

ui/sfx.gdが入力の配送、歩と効果の重複除去、再生を管理する。\
選択、回転、攻撃と回復の共用という3レーンを各1声に制限し、ループとBGMはない。\
音量は原音の信号差から決めた暫定値で、game/tuning.gdの1か所で調整できる。\
既存のMaster出力へ送り、追加UIと保存を作らない。

有効なマウスとキーの選択だけに音を付け、ホバー、無効入力、フォーカスだけの移動、自動更新とCPUの選択は無音とした。\
確定移動の各歩の完了時に、1輪以上の実回転があれば1回だけ鳴らす。\
攻撃と回復は実HP変化が正の既存結果へ1回だけ接続した。\
移動と攻撃の待ち、計算、予測、パネル、雲と保存形式は変更していない。

## 自動検証

- tests/sfx.gdを先に作り、未実装時の2検査2失敗を確認した。
- 最終版は39検査0失敗であり、手動入力の寿命、無効入力、各歩、ゼロ回転、全周回転、停止と再開、早送り、0歩と表示省略、実HP変化、上限、重複、素材とレーンを確かめた。
- UI接続では実際の経路、行動と対象、移動、HP結果、構成候補とキー、取消とBUILD復帰を通した。
- 検査を誤った実装に置き換えて確認した。
  無効選択の発音は1失敗、歩の重複は7失敗、HP変化ゼロの発音は5失敗となり、誤りを検出した。
- npm run checkは成功した。
  プロダクト検査へsfxを追加し、既存のエラー検出と検査は弱めていない。

headlessの無出力Dummyでは論理的な発音要求だけを検査する。\
無出力の高速終了時にOggの非同期停止の参照が残るエンジン側の問題を避け、実出力とMovie Makerでは再生を維持する。\
実出力は下記のCoreAudioで別に検証した。\
参考は[AudioServerのドライバー仕様](https://docs.godotengine.org/en/stable/classes/class_audioserver.html#class-audioserver-method-get-driver-name)と[非同期停止後の参照残りの報告](https://github.com/godotengine/godot/issues/76745)である。

## 実行環境と実画面経路

Apple M4、Godot 4.7.2、Compatibility、CoreAudioを使用した。\
1920x1080と1152x648の独立ウィンドウで、それぞれ18検査0失敗となった。\
GodotのViewportへマウスの押下と解放、キーを配送し、実際のGUIと盤面入力を通した。\
言語のPopupMenuだけはwindow_inputと選択シグナルの接続を直接確認した。\
物理マウスによる手動プレイと、全ての設定ポップアップの実操作を確認したとは扱わない。

CoreAudioのMasterをAudioEffectCaptureで観測し、4素材とも無音でない信号があり、ピークが1未満であることを確認した。\
これはゲームのミックス出力の観測であり、マイク録音と機器の実音量の測定ではない。

- SLOTの切替、CLASS候補のキー選択と取消、有効な盤面選択を確認した。
- ホバーとTab、無効な盤面入力では選択音が出なかった。
- 隔離した既存の配置で2歩を計画し、最終確定から回転音2回、実際の撃破の攻撃音へ進む順序を確認した。
  攻撃音の発生時点で対象HPは0だった。
- HELP中は移動時計と発音が停止し、復帰後に古い歩を重複再生しなかった。
- 負傷した味方への上限までの実回復で回復音1回を確認した。
- 敵が手番を持つ隔離条件でCPU早送りを進め、手番が更新されても手動選択音が混ざらなかった。

既存fixtureを使った短い接続検証であり、自然な一戦の聴感や勝敗を評価した結果ではない。\
両サイズとも通常BUILDへ戻してGodotの検証用実行を終了した。
