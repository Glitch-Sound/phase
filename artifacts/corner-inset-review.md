# コーナーの位置調整と紹介動画

## 変更

基準はd2b129dであり、開始時の作業ツリーは空であった。
AGENTS.mdの値の調整に該当し、正式シナリオは変更しない直接変更とした。
game/tuning.gdのCELL_CORNER_ICON_INSETを、両アイコンの中心に共通する1か所の調整値とした。
100pxのマス内の左上は(14,14)、左下は(14,86)であり、同じXと上下対称のインセットを使う。
効果アイコンは従来から1px、所有紋章は2pxだけ内側へ寄せた。
空セルとユニットのあるセルで効果アイコンの座標を変えない。
既存の20pxの効果アイコンと半径6pxの所属紋章、形と不透明の設定色を維持した。

最初の16px案では、既存テストが要求するユニット基準半径全体からの余裕を満たさなかった。
テストを変更せず、14pxで両方の位置と余白を確認した。
ユニットの外側リングの実線に対し、3種類のSVGの実画素の最短距離は4.248pxである。
フォーカス、隣接とマップ端、自軍だけの所属判定、HPの共通RGBと切り上げ表示、戦闘値を変更していない。
新しい機能と戦闘ルール、検査コマンドを追加していない。

## 紹介動画

新規の隔離UNLOCK ALLデータで、seed 128の同一試合から合法な6手を進め、TURN 07と08を連続収録した。
PLAYERはAXISとPEARL、ENEMYはMONOLITHとREDである。
6体のCORE配分、GEAR、ARMS、CLASS、両MUTATIONとスキル構成はそれぞれ異なり、全構成の合法性を確認した。
元の撮影手順のsetup.gdとplans.varを再利用し、最新の本体を本番main.tscnから描画した。
既存動画の再エンコードではない。

入力はGodot InputEventによる決定的なリプレイであり、物理的な手動プレイではない。
収録時のOSウインドウフォーカスは実際に取得を確認した。
各フレームで本体の_processを1/30秒だけ進め、移動と位相変化、雲、着地の一拍、赤い収束を通常速度で保存した。
操作の余分な待ちを収録せず、確定から移動、着地と結果までを連続させた。
両手の結果と全履歴は、同じ入力を行った描画なしの戦闘モデルと完全一致した。

| 時刻 | 場面 |
| --- | --- |
| 0.0秒 | 6体が生存したTURN 07の白対赤の盤面 |
| 1.5から6.3秒 | FAST FIELD持ちの3マスの経路、行動と対象、最終確認 |
| 6.3から7.5秒 | 出発前の雲フェード、連続した移動と装備角の変化、右詳細とPREVIEWの同期、着地と攻撃 |
| 9.0から13.3秒 | 次のTURN 08で2マスの経路とINF 200%の予測、最終確認 |
| 13.3から14.2秒 | 拍を伴う移動、リング変化と着地後の一拍 |
| 14.2から16.7秒 | 赤い収束と敵の実際の撃破。対象HPは118から0となり、直後の盤面を保持 |

移動中に白い経路が残らず、両手でGEARとARMSの角度が変化し、両表示が移動ユニットと一致することをフレームごとに確認した。
移動者以外の雲を消さず、移動者の雲だけが出発前に消え、着地先で戻ることも確認した。
今回の2手は攻撃であり、緑の回復は収録せず、雲のある手を採用した。

出力は1920x1080、30fps固定、501フレーム、16.7秒、H.264 High、8bit yuv420p、faststart、音声トラックなし、3876093バイトである。
macOS内蔵AVFoundationを既存のPython手順から使用し、追加アプリを導入していない。
全501フレームの復号と時刻、形式、プレビューの動き、代表18場面の実画素を確認した。
画面の切れ、デスクトップと個人情報、追加素材と編集用オーバーレイはない。
動画プレイヤーでの物理的な再生操作、スマートフォンとX上での再生、別GPUとOSは未確認である。
