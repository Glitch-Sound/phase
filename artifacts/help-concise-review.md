# HELP本文の短文化

## 対象と判断

基準はe6ca199で、開始時の作業ツリーに変更はなかった。\
HELPの英語と日本語の本文だけを、初めて戦闘する時の操作と結果が伝わる短い説明へ改めた。\
既存の操作と効果、保存の仕様を変えない文言修正として直接変更した。

主見出し、アイコン、本文の位置と領域、文字サイズ、前回の間隔、英日切り替えと他画面は維持した。\
実際の構成は導入文、既存の各見出しの本文と末尾補足の9本文領域であり、見出しの追加と削除は行っていない。

## 内容の整理

| 箇所 | 残した内容 |
| --- | --- |
| 導入 | ENEMY CPUと両陣営操作、BUILDのOPERATIONにある勝利条件 |
| ROUTE | 上下左右の空きマスで経路を作り、途中のマスで後続を取り消す |
| ALIGN | 移動でリングと攻撃、回復、抵抗が変わり、PREVIEWで着地後を確認する |
| ACT | 終点のダブルクリック、技と対象の選択、CONFIRMによる移動と行動、方向と正確な射程 |
| MOVEMENT | 各手の最低1マス、閉塞時のその場WAIT、確定前のBACKとEsc |
| PHASE | 通常の装備回転と、COREへのSPD依存のパネル回転と開始角へのリセット |
| BUILD / ARCHIVE | CLASSとMUTATIONの違い、SAVEとLOAD、保存しないデバッグ全解放 |
| READING THE SIGNAL | ダメージと回復の符号、INFとRES、最大待ち量を基準とする白い進捗 |

重複した命名の案内、揺らぎの装飾上の周期、細かな数式と上限、特異点の条件などを主HELPから外した。\
SKILLSとFIELDSの詳細説明、パネルのホバーと構成候補の説明は変更していない。\
勝利条件を全滅だけに決めつけず、選択したOPERATIONで確認する案内とした。

本文だけを集計すると、英語は空白区切りで255語から158語、日本語は改行を除いた文字数で761字から432字へ減った。\
主本文は各1から2文とし、英語と日本語の双方で約4割を削減した。

## 検証

- 新しい短文を先に期待する既存の検査は、旧画面で失敗し、修正後に成功した。
- 旧文面を固定していた8テストファイルを依頼された短文に対応させ、回転、射程、INFとRES、相対待ち量と表示の収まりを維持した。
- 完全一致の期待値を使い、対象の翻訳関数から期待値を生成していない。
- 検査ケースとバランスに依存する固定期待値は増やしていない。
- 最終npm run checkは101組、8257件、失敗0で、8仕様とトレースも成功した。
- Godot 4.7.2、Compatibility、Apple M4で英日、1920x1080と1152x648を描画した。
- 2484件の描画確認は、各文字の実グリフの検査を含み、失敗0であった。
- 文字の収まり、日本語対訳の全行、本文領域と文字サイズ、既存のアイコンと見出し、罫線と下部ボタンの実ピクセルを確認した。
- SKILLSへのEnterと、HELPを閉じるEscをGodot入力イベントで確認し、元の編成と通常BUILDへ戻して終了した。
- 実セーブ、配色と説明言語の設定、既存画像は内容と更新時刻に変更がない。
