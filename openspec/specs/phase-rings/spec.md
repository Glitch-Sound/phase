# phase-rings Specification

## Purpose

移動による位相変換と効果量の関係を厳密かつ予測可能に保ち、プレイヤーが経路を比較して有効な戦術を組み立てられるようにする。

## Requirements

### Requirement: REQ-001 - 配分と型番

各リングは1から96の整数5値、合計100を維持し、型番へVIT、INF、RES、SPD、LUKの順の16進数を表現しなければならない(SHALL)。

#### Scenario: REQ-001-S01 - 配分境界

- **GIVEN** 1と96を含む配分と範囲外の配分
- **WHEN** 配分を検証する
- **THEN** [96,1,1,1,1]のみ有効であり、0、97、合計99、非整数は拒否される

#### Scenario: REQ-001-S02 - 型番

- **GIVEN** [20,5,25,40,10]と変異ISVLR
- **WHEN** 装備を表示する
- **THEN** 通常型番はARMS-140519280A、変異型番はARMS-140519280A-M-ISVLRとなる

### Requirement: REQ-002 - 開始HP

WHEN 戦闘を開始するとき、各ユニットは100と各リングのmax(0.25,VIT/20)の積をHPとして持たなければならない(SHALL)。

#### Scenario: REQ-002-S01 - HP係数

- **GIVEN** 各リングVITが20、またはCOREのみ1、5、10、40
- **WHEN** HPを計算する
- **THEN** 順に100、25、25、50、200となる

### Requirement: REQ-003 - 進入時回転

WHEN パネルへ進入するとき、ゲームは全ユニットのGEARをそのSPDの1.5倍だけ反時計回り、ARMSをそのSPDの1.5倍だけ時計回りへ回転し、NORMALではCOREを保持し、RESETではCOREを戦闘開始角へ戻し、CLOCKWISEとCOUNTERCLOCKWISEではCOREのSPDの1.5倍だけ指定方向へ回転し、経路順に適用して角度を次手番へ保持し、再戦では開始基準を新しく設定しなければならない(SHALL)。

#### Scenario: REQ-003-S01 - パネル効果

- **GIVEN** CORE、GEAR、ARMSのSPDが20、現在のCORE角90度、戦闘開始CORE角15度、両装備角0度
- **WHEN** 次のパネルへ1回進入する
- **THEN** GEARは330度、ARMSは30度となり、COREは次の角度となり、能力値や開始基準は変わらない

| パネル | CORE角度 |
| --- | --- |
| NORMAL | 90度 |
| RESET | 15度 |
| CLOCKWISE | 120度 |
| COUNTERCLOCKWISE | 60度 |

#### Scenario: REQ-003-S02 - リセットと経路順

- **GIVEN** CORE角40度、戦闘開始角10度、COREのSPD20
- **WHEN** 特殊パネルを連続して踏む
- **THEN** CLOCKWISEの後にRESETなら10度、RESETの後にCLOCKWISEなら40度となり、連続する回転は累積し、0度と360度の境界で循環する

#### Scenario: REQ-003-S03 - 陣営と持続と再戦

- **GIVEN** 味方と敵が特殊パネルを踏んだ戦闘
- **WHEN** 手番が交代し、その後に同じビルドで新しい戦闘を開始する
- **THEN** 交代中は変更後の角度を保持し、同じ規則が敵にも適用され、新しい戦闘では全員のCORE現在角とリセット基準が開始角0度へ戻り、前戦の角度を引き継がない

### Requirement: REQ-004 - 円環重なり

同期は回転した生のセクターの共通角度を最小幅で正規化し、0から100%で表さなければならない(SHALL)。

#### Scenario: REQ-004-S01 - 境界を跨ぐ重なり

- **GIVEN** 開始350度の幅30度と開始0度の幅30度の領域
- **WHEN** 重なりを求める
- **THEN** 共通角は20度であり、離れた領域では0度となる

### Requirement: REQ-005 - LUK補助と連続補正

同期は最小LUKの平方根に基づく許容角、三重とペアの0.70/0.20/0.10干渉、10から200%の中間値を使い、0から1へ丸めてベルカーブを適用し、設定された幅の縮小で位相差を従来より強調しつつ、完全同期の上限、非同期の正の補正、LUKの補助とRES側の広い許容を維持しなければならない(SHALL)。

#### Scenario: REQ-005-S01 - 補助と飽和

- **GIVEN** LUK5、20、80の同一配分、完全同期と離散位相
- **WHEN** 補正を求める
- **THEN** 許容角は1.5、3、6度となり、完全同期の中間値と最終補正は2、非同期も最終補正が0を超える

#### Scenario: REQ-005-S02 - 位相差と作用の一貫性

- **GIVEN** 同じ配分で低、中、高一致のINFとRES、および異なるLUK
- **WHEN** 同期補正と攻撃、回復を計算する
- **THEN** 低一致と高一致の差が従来より広がり、中間は連続して変わり、完全同期の最大値と特異点の条件と倍率を変えず、LUKによる許容とRESの広い曲線を保つ
- **AND** 同じ実値を経路予測と確定とCPU判断へ使い、設定した基本威力を使い、HP上限、回復対象と手番の規則を変えない

### Requirement: REQ-006 - 特異点

WHEN 3つの生INFセクターが完全一致しCORE:INFが10以下のときのみ、SINGULARITYは効果量へ5倍を適用しなければならない(SHALL)。

#### Scenario: REQ-006-S01 - 厳密一致

- **GIVEN** INF10の同一セクター、0.001度差、幅差、INF11
- **WHEN** 特異点を判定する
- **THEN** 同一INF10だけ成立し、LUK80でも他は不成立となる

### Requirement: REQ-007 - ダメージと回復

アクションは指定INF係数と同期補正から効果量を求め、ダメージを1+RES係数と同期の積で除し、特異点倍率の後に切り捨て、回復はRESを使わず最大HP以下にしなければならない(SHALL)。

#### Scenario: REQ-007-S01 - 効果量

- **GIVEN** 全ステータス20、完全同期の攻守
- **WHEN** ダメージと回復を計算する
- **THEN** ダメージはfloor(BASE_DAMAGE*2/3)、回復はfloor(BASE_HEAL*2)となる

#### Scenario: REQ-007-S02 - 回復上限

- **GIVEN** 最大100、現在95の隣接味方
- **WHEN** 回復を実行する
- **THEN** 現在HPは100となり戦闘不能には回復できない
