# sound-feedback Specification

## Purpose

利用者が提供した4つの効果音を、成立した手動操作、実際のリング回転とHP変化へ結び付ける。\
予測と表示だけの更新には音を付けず、戦闘と保存を変えない短い音の手掛かりを提供する。

## Requirements

### Requirement: REQ-054 - 手動選択の音

WHEN クリックまたはキーで有効な選択と操作が成立したとき、画面は選択音を1入力につき重複なく鳴らし、カーソル移動、ホバー、フォーカス移動だけ、予測、無効入力と自動操作では選択音を鳴らしてはならない(SHALL NOT)。

#### Scenario: REQ-054-S01 - 成立した手動入力だけの選択音

- **GIVEN** 経路、確認対象、構成候補と有効な操作部品
- **WHEN** マウスまたはキーで選択を試みる
- **THEN** 成立した手動選択はその入力中に1回だけ鳴り、無効対象、非活性部品、ホバーとフォーカスだけ、予測とプログラムによる変更は無音になる

### Requirement: REQ-055 - 確定移動の回転音

WHILE 確定した実移動を表示する間、画面はリングが実際に回った各歩の完了に合わせて1マス1回の回転音を鳴らし、複数輪の同時変化を重複させず、回転なし、計画中、停止中と表示のない0歩には音を付けず、表示と戦闘の時間を変えてはならない(SHALL NOT)。

#### Scenario: REQ-055-S01 - 各歩と実回転の対応

- **GIVEN** 複数歩の確定移動と、回転する輪と回転しない輪
- **WHEN** 各歩のリング表示が完了する
- **THEN** その歩で1輪以上が回れば1回だけ鳴り、全輪が変わらなければ鳴らず、計画や予測の更新では鳴らない

#### Scenario: REQ-055-S02 - 停止と表示終了の境界

- **GIVEN** 人またはCPUの移動表示、早送り、表示を省く設定または移動なし
- **WHEN** 停止、再開または退出を含む表示更新を行う
- **THEN** 表示した各歩の完了を重複させず、停止中は新しく鳴らず、表示を省く場合と0歩では音の列を作らず、退出した移動の音を再戦へ持ち越さない

### Requirement: REQ-056 - 実HP変化の音

WHEN 攻撃または回復で対象のHPが実際に減少または増加したとき、画面は既存のHPと効果表示へ対応する攻撃音または回復音を各行動1回だけ鳴らし、効果適用を待たせず、同じ結果の再表示、予測、実変化ゼロとその他の技には音を付けてはならない(SHALL NOT)。

#### Scenario: REQ-056-S01 - 攻撃と回復の実変化

- **GIVEN** 人またはCPUによる合法な攻撃と回復
- **WHEN** 実際の効果を表示する
- **THEN** HP減少には攻撃音、実回復には回復音が1回だけ鳴り、撃破とHP上限への回復も既存のタイミングで処理される

#### Scenario: REQ-056-S02 - 実変化のない結果と再表示

- **GIVEN** 予測、実HP変化ゼロ、防御と位置操作、または表示済みの結果
- **WHEN** 結果表示を更新する
- **THEN** 攻撃音と回復音は鳴らず、実際に変化した次の別行動だけを新しく鳴らす

### Requirement: REQ-057 - 提供素材と音量の管理

画面は本人提供のselect、ring_rotate、attack、healの4つのoggを原本のまま使い、選択と回転を控えめに、攻撃と回復を区別できる音量で一元管理し、同種の長い音を耳障りに重ねず、BGMと追加の音量UI、戦闘と保存の変更を追加してはならない(SHALL NOT)。

#### Scenario: REQ-057-S01 - 4音の読込と再生境界

- **GIVEN** 本人が置いた4音と通常のゲーム保存と設定
- **WHEN** 連続した選択、移動と行動を再生する
- **THEN** 4音が正常に読み込まれ、設定した音量と同時発音の上限を守り、原音と通常保存、設定を変更せずBGMを鳴らさない

#### Scenario: REQ-057-S02 - 実プレイの聴感

- **GIVEN** 音声出力が有効なGodotの戦闘
- **WHEN** 有効選択、移動、攻撃と回復を実際に聞く
- **THEN** 選択と回転は控えめで、攻撃と回復が区別でき、各音が該当する状態変化に対応して耳障りな連続音と不要な音がない
