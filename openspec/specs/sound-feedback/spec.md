# sound-feedback Specification

## Purpose

利用者が提供した素材を保持し、移動用の交互2音を確定移動へ、攻撃と回復を実HP変化へ結び付ける。\
選択と予測、表示だけの更新には音を付けず、戦闘と保存を変えない短い音の手掛かりを提供する。

## Requirements

### Requirement: REQ-054 - 手動選択の音

WHEN クリックまたはキーで選択と操作を行うとき、画面は有効な選択を含め選択音を鳴らしてはならない(SHALL NOT)。

#### Scenario: REQ-054-S01 - 成立した手動入力だけの選択音

- **GIVEN** 経路、確認対象、構成候補と有効な操作部品
- **WHEN** マウスまたはキーで選択を試みる
- **THEN** 成立した手動選択、無効対象、非活性部品、ホバーとフォーカスだけ、予測とプログラムによる変更はすべて無音になる

### Requirement: REQ-055 - 確定移動の回転音

WHILE 確定した人またはCPUの実移動を表示する間、画面は最初に位置が進むフレームでring_rotate1の再生を要求し、半マス分の間隔でring_rotate2と交互に各マス各1回鳴らし、回転量の変化がなくても適用し、出発前のフェード、計画、取消と0歩では鳴らさず、表示と戦闘の時間を延ばしてはならない(SHALL NOT)。

#### Scenario: REQ-055-S01 - 各歩と実回転の対応

- **GIVEN** 1歩または3歩の確定移動と、回転する歩と回転量の変化がない歩
- **WHEN** 通常速度で移動を表示する
- **THEN** 最初に位置が進むフレームで1音目の再生を要求し、各マスで1、2の順に各1回、合計2回または6回が半マス分の等間隔で鳴り、出発前のフェード、移動の尺と到着を変えない

#### Scenario: REQ-055-S02 - 停止と表示終了の境界

- **GIVEN** 人またはCPUの移動表示、早送り、表示を省く設定または移動なし
- **WHEN** 計画、取消、停止、再開または退出を含む表示更新を行う
- **THEN** 計画と取消、停止中は新しく鳴らず、再開と早送りでも過去の発音を重複させず、表示を省く場合と0歩では音の列を作らず、退出した移動の音を再戦へ持ち越さない

### Requirement: REQ-056 - 実HP変化の音

WHEN 攻撃または回復で対象のHPが実際に減少または増加したとき、画面は既存のHPと効果表示へ対応する攻撃音または回復音を各行動1回だけ鳴らし、効果適用を待たせず、同じ結果の再表示、予測、実変化ゼロとその他の技には音を付けてはならない(SHALL NOT)。

#### Scenario: REQ-056-S01 - 攻撃と回復の実変化

- **GIVEN** 人またはCPUによる合法な攻撃と回復
- **WHEN** 実際の効果を表示する
- **THEN** HP減少には攻撃音、実回復には回復音が1回だけ鳴り、撃破とHP上限への回復も既存のタイミングで処理される

#### Scenario: REQ-056-S02 - 実変化のない結果と再表示

- **GIVEN** 予測、実HP変化ゼロ、防御と位置操作、または表示済みの結果
- **WHEN** 結果表示を更新する
- **THEN** 攻撃音と回復音は鳴らず、実際に変化した次の別行動だけを新しく鳴らす

### Requirement: REQ-057 - 提供素材と音量の管理

画面は本人提供の原本を変更せず保持し、再生はring_rotate1、ring_rotate2、attack、healだけに限定し、移動は控えめに、攻撃と回復は既存の音量と素材、発音条件を維持して一元管理し、同種の音を耳障りに重ねず、選択音、BGMと追加の音量UI、戦闘と保存の変更を追加してはならない(SHALL NOT)。

#### Scenario: REQ-057-S01 - 4音の読込と再生境界

- **GIVEN** 本人が置いた原音と通常のゲーム保存と設定
- **WHEN** 連続した選択、移動と行動を再生する
- **THEN** 旧音の原本も保持しながら再生対象は移動用2音、攻撃と回復だけとなり、設定した音量と同時発音の上限を守り、原音と通常保存、設定を変更せず選択音とBGMを鳴らさない

#### Scenario: REQ-057-S02 - 実プレイの聴感

- **GIVEN** 音声出力が有効なGodotの戦闘
- **WHEN** 有効選択、移動、攻撃と回復を実際に聞く
- **THEN** 選択は無音で、移動は各マスの2音が等間隔で控えめに交互に鳴り、攻撃と回復は従来のまま区別でき、不要な連続音がない
