# 技術方針

## 技術スタック

Godot 4.7系、GDScript、Compatibilityレンダラーを使う。
開発専用にNode.js 22.12以上、npm、OpenSpec 1.16.0、Gitを使う。
画像は同梱したLucideのSVGアイコンだけを使い、追加の実行時ライブラリは使わない。

## アーキテクチャ

画面からモデルへ一方向に依存する。

~~~mermaid
flowchart LR
  UI["画面と入力"] --> B["戦闘"]
  UI --> C["収集と保存"]
  B --> M["位相計算"]
  B --> D["カタログ"]
  C --> D
  UI --> V["描画"]
  UI --> CPU["CPU判断"]
  UI --> PRESENT["CPU表示進行"]
  CPU --> B
  PRESENT --> B
  V --> M
~~~

## 技術上の判断基準

- 開始時のパネル配置だけは独立したシードで生成し、配置後の戦闘計算には乱数を使わない。
- CPUは公開状態の複製を既存の戦闘操作で評価し、判断の履歴と同じ入力に対して同じ選択を返す。\
  表示進行の実時間をゲーム内の手番時刻へ加えず、中断時は表示時間も蓄積しない。\
  モード、速度と停止は実行中だけ保持し、既存セーブの形式を変えない。
- 配置のシード、ドロップ乱数と保存先は独立して注入可能にする。
- COREの現在角と戦闘開始角は戦闘中の状態だけに保持し、ビルドの保存形式へ加えない。
- 確定移動の復元は行動前の同じ手番に限り、原本の辞書と履歴を戻して経路を予測へ戻す。\
  角度の逆算はせず、実行済みの効果と終局は復元しない。\
  復元情報は手番と戦闘の境界で破棄し、セーブへ加えない。
- 既存セーブを自動読込、自動上書きしない。
- OpenSpec設定とゲーム保存を作業先内に置く。
Godot自身の標準設定はmacOSのApplication Supportを使用するため、制限されたシェルでは初期化警告が出る場合がある。
- 調整定数はgame/tuning.gdに集約する。
- 1920x1080の論理座標をcanvas_itemsとkeepで拡縮し、OSのDPI倍率やroot.scaleを追加で掛けない。
- 盤面はマウスイベントの論理座標を使い、GUIの座標変換はGodotへ任せる。
- フォーカス喪失でホバーとGUIフォーカスを解除し、未確定経路を保持して復帰後に続行する。

## コードのコメント

先頭がアンダースコアでない関数を外部向けとする。
GDScriptの文書コメントに概要、引数、戻り値、副作用の意味を書く。
scripts/lint.mjsが存在と引数名と戻り値記述を検査し、Godotが構文と型を検査する。
テストとGodotコールバックはコメント検査から除く。

## テスト方針

- Godotのheadlessモードでモデルと保存境界を検証する。
- テスト関数の先頭の文書コメントにシナリオIDを書く。
- 期待値を対象の関数から生成しない。
- 見た目、操作、面白さは実画面で確認し、自動テストと区別する。
- 比較用画像で通知を消す場合も、通知が出る代表状態の可読性を別に検査する。
- scripts/check.shにプロダクト検査をまとめ、npm run checkの先頭から呼ぶ。
- 旧配置を前提に位相とUIを確かめる検査はtests専用fixtureを使い、本番モデルの複数シード再生と区別する。
- UI接続などの短い機能確認では条件をfixtureに明示し、実ステージの攻略難易度と分ける。
- 実ステージは初手の合法経路全探索、対抗目標、両陣営の攻撃と回復を含む再生で検査し、操作履歴を残す。

## 表示原則

深い黒を基調とし、走査線、発光、ランダムな装飾を使わない。\
円形予測は各装備の実SPDと役割差に基づく周期で半径だけを揺らし、表示時間で戦闘角度と値を変更しない。
色は役割を保ちつつ設定可能にし、文字の相対輝度比とステータス色の区別を配色部品で検証する。
組み込みプリセットと6色が完全一致するときはリングだけ彩度を強め、それ以外のカスタム配色は指定RGBをそのまま表示する。\
基本の6色と他UI、保存形式は維持し、表示用のリング色を保存へ書き戻さない。
符号、ステータス名、輪郭、操作ラベルを併用し、色だけに意味を依存しない。
配色は明示的な適用時に独立UI設定へ保存し、既存ファイルを退避する。
モーダルは最前面の有効な操作部品だけでTabを循環し、補助画面を閉じると以前のフォーカスへ戻る。
BUILD、行動選択、RESULTと補助画面は外枠を持たない黒い面とし、余白と文字で階層を示す。\
通常ボタンは囲わず、入力欄は下線、ホバーは灰色の面、フォーカスは白い下線で区別する。\
ユニット選択はアクセントの下線を使い、盤面のシステムメニューの既存表現は維持する。
ユニットの円弧は実描画倍率から最小物理線幅と弦誤差を求め、半径と角度を保ってアンチエイリアスを適用する。

円形の予測は実領域の局所的一致を表し、最終補正率とは区別する。\
領域、色と包絡は配分、突然変異、角度、SPDと配色が変わった場合だけ生成する。\
表示時間ではキャッシュから動く座標だけを生成し、動きを抑える設定では現在の形で停止する。
