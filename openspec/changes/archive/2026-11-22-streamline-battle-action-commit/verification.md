## 実装と検査

REQ-010はui/main.gdの行動保護、実行待ちと描画完了の境界へ接続し、ui/turn_plan.gdの既存の予測と確定を変更していない。\
REQ-010-S05はtests/decision_interface.gdで保護中の無効、押下解除、無効対象と重複、描画前の履歴不変、再戦の破棄を確認した。\
旧実装では最初の3検査が失敗し、実装後は53項目すべて成功した。\
REQ-012-S04は閉塞時と経路がある状態の無移動WAITを、画面の接続で確認した。\
REQ-012の他の条件とREQ-046の通常移動、CPUと音は既存のモデルとUIの期待値を維持した。

既存のフォーカスとスキルボタンの検査は、保護解除後へ入口を合わせ、期待値と全項目を維持した。\
比較は原本と履歴の全体、対象の有無と手番1回の増分で行い、固定ダメージや戦闘の終了手数を新たに検査していない。\
最終CONFIRMの旧文言と操作だけを新しい選択入口へ置き換え、他の確認を変更していない。

npm run check、変更のstrict検証とstrictトレース検証、git diff --checkに成功した。\
実Godotは1920x1080と1152x648で32項目成功し、実際の消去後描画が移動表示に先行した。\
任意の補助録画も6項目成功し、全102フレームを復号した。\
