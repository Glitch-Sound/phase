# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-014 - 共有ビルド

WHEN 戦闘外で編集するとき、3体のPLAYERはCLASS、合計100のCORE、開放済み装備と変異、重複しない最大3スキルを共有一覧から設定できなければならない(SHALL)。

#### Scenario: REQ-014-S01 - 構成検証

- **GIVEN** 共有装備とNORMAL、REVERSE、未設定スキル
- **WHEN** ビルドを検証する
- **THEN** 空スキルと同一装備の複数人利用を許可し、未開放装備、重複スキル、不正変異は拒否する

#### Scenario: REQ-014-S02 - BUILDの情報階層

- **GIVEN** 3体のユニットと開放済み装備、変異、スキル、2ステージ
- **WHEN** BUILDで構成を編集して出撃条件を選ぶ
- **THEN** 選択表示と編集先が一致するユニット切替、CLASS、COREの5値と総量、ARMSとGEARの型番と5値、現在と候補の比較、変異、3スキル枠、HPと移動と待ち量とINF補正、ステージと勝利条件と案内、共有一覧の数量を確認できる
- **AND** 主要な編集、構成の結果、装備の比較と出撃を余白と強弱で区別し、SAVE、LOAD、HELP、SETTINGS、QUIT、STARTの操作を維持し、指定された補助文を省いても構成と勝利条件を維持する
- **AND** 編成の選択ボタンはUNIT 1、UNIT 2、UNIT 3と表示し、選択と編集する枠を一致させ、内部キーと保存形式を変えない

### Requirement: REQ-042 - 共通の構成選択

WHEN BUILDでCLASS、ARMS、GEAR、各MUTATION、スキルまたはOPERATIONを選ぶとき、共通ダイアログは現在と候補を区別して選択種に応じた実際のリングや効果をプレビューし、確定まで構成を変更せず、取消とキーボード操作を許可し、未解放候補を非活性で見せ、装備を能力値で絞り込んでスクロール可能にし、変異を装備との全組合せへ平坦化しないようにしなければならない(SHALL)。

#### Scenario: REQ-042-S01 - 候補と確定と取消

- **GIVEN** 現在装備と異なる開放済みの候補
- **WHEN** 候補を選んで確定または取消する
- **THEN** 選択中は原本を変えず装備とCLASSの実リング、装備の5値、スキルの効果を確認でき、確定時だけ対象の値を変更し、取消とEscは選択前の構成を保つ

#### Scenario: REQ-042-S02 - 全候補と非活性と絞り込み

- **GIVEN** 一部または全解放の共有一覧
- **WHEN** 装備と変異、CLASS、スキルの候補を調べる
- **THEN** ARMSとGEAR各126、変異とCLASS各120、全16スキルの候補を別一覧で確認でき、未解放と他枠で装備済みのスキルは確定できず、装備の指定能力値の下限に合う候補だけへ絞り込め、一覧の先頭と末尾へ到達できる

#### Scenario: REQ-042-S03 - クラスと変異の違い

- **GIVEN** 同じ配置コードのCLASS、GEARまたはARMSの変異
- **WHEN** 各候補を比較する
- **THEN** CLASSは実際のCORE順と対応する5色の四角を候補ごとに示して右側の重複テキストを省き、変異も対象装備の実際の順と対応する5色の四角を候補ごとに示して冗長な順序と適用、操作の説明を省き、配分と他リングを変更しない

#### Scenario: REQ-042-S04 - スキルと作戦の内容

- **GIVEN** 3スキル枠と01、02の2作戦
- **WHEN** スキルまたは作戦を選ぶ
- **THEN** スキルは同系統のまとまりと簡潔な説明、対象位置を示し、CURRENTとCANDIDATEのリングを描かず、NONEを許可し、作戦は内容と勝利目的、開始可能領域を示し、説明内と概要図の同じ陣営と役割を同じユニット紋章で表し、03と04を候補に含めず、確定後だけ対象枠または作戦へ反映する

- **AND** メモリー上の未知の作戦値は01へ戻り、他の構成と収集は変更せず、不正な候補を確定できない

- **AND** 02を適用して対象または対象外のユニットを改名しても、説明と図、実戦は現在の編成の同じ不変IDから紋章を生成し、同名と空欄の既存規約を保ち、勝敗条件と名前の非表示を維持する

- **AND** OPERATIONの見出し、説明図と注記、紋章を含む説明と操作を日英の標準と最小表示で重ねず、説明を自然に折り返す

#### Scenario: REQ-042-S05 - モーダルの入力境界

- **GIVEN** BUILDから開いた候補一覧
- **WHEN** キーボードで候補を移動し、確定または取消して閉じる
- **THEN** 有効な候補と操作だけへフォーカスでき、背景の構成や戦闘を操作せず、現在装備と候補を識別でき、閉じた後は呼出元へフォーカスが戻る

#### Scenario: REQ-042-S06 - 指定された補助説明の整理

- **GIVEN** 英語と日本語のBUILD、CLASS、SKILL、OPERATIONとASSEMBLY
- **WHEN** 各画面を表示する
- **THEN** BUILDの再配分と装備比較、両陣営操作の補助文、CLASSとSKILLとOPERATIONの候補確定案内、ASSEMBLYの共有と同名の補助文を表示せず、空いた領域を詰めて必要な効果と操作を維持する
- **AND** ARMSとGEARの装備本体のピッカーは変更しない
