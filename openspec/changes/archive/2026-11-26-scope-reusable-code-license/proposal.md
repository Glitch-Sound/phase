# 提案

## 目的

公開ソースを再利用する人が、MITで使える汎用コードとPHASE固有の権利留保を取り違えず、ゲーム内からも適用範囲と原文を確認できるようにする。

## 変更内容

- 独立した自作の入力イベント転送とコメント検査の2ファイルだけをMITで許諾する。
- 現行のLICENSESへPHASEの適用範囲とMIT原文を加え、WebのPCKにも保持する。

## 対象外

- PHASE固有の戦闘、シナリオ、ロゴ、他の自作ファイルへのMIT許諾。
- 第三者の既存許諾やゲームの挙動の変更。
- 公開とpush、元の履歴の書き換え。

## 対象の仕様

### 新規

- なし。

### 変更

- `licenses`: 全7文書の閲覧へ限定許諾の2文書を追加し、配布時も原文と適用範囲を保つ。

## 影響

- README、対象ソースの権利表示、同梱文書、LICENSES、エクスポート、権利表示の検査。
- 個人メールと端末固有パスの文書整理は、シナリオを変更しない直接変更として併行する。

## 未決事項

- なし。
