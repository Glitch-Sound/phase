# 提案

## 目的

利用者がスキル構成と位置取りを試せるよう、隣接だけの攻撃と回復へ対象位置の選択肢を加える。
威力を同時に調整せず、4種類の位置関係を同じ計算と操作で比較できるようにする。

## 変更内容

- DAMAGEとHEALへ上下左右1、斜め1、上下左右2、斜め2マス先の単体対象を用意する。
- 自分を除く生存敵または負傷味方を対象とし、2マス先は正確な距離とする。
- 既存の上下左右1マスのIDと初期装備を維持し、新しい6種は未開放品として戦利品から取得して共有する。
- 3枠の装備、説明、対象表示、CPUの候補と反撃評価を新しい範囲へ対応させる。
- 旧セーブの開放と構成を保持し、追加品の保存と読込を維持する。

## 対象外

- 威力、回復量、位相計算と評価重み、移動ルールの調整。
- 直線全体、周囲、複数対象、自己回復、蘇生と遮蔽物の新ルール。
- 敵の初期構成の変更と新スキルの自動装備。
- 実セーブと色設定の保存、pushと公開。

## 対象の仕様

### 新規

なし。

### 変更

- tactical-battle: REQ-011へ4種類の対象位置と共通の作用を反映する。
- build-collection: REQ-026へ追加スキルの入手と旧保存の互換性を反映する。
- battle-interface: REQ-018へ新しい範囲と対象の識別を反映する。
- enemy-cpu: REQ-035へ追加した範囲の候補と反撃評価を反映する。

要件を増やさず、battle-interfaceの15要件を維持する。

## 影響

スキル一覧、戦闘の対象条件、入手と構成、説明、範囲の表示、CPU判断へ影響する。
範囲以外の作用と基本ルールの検査を維持し、勝敗と決着手数を固定期待にしない。
盤面、レイアウト、配色と既存操作は今回の追加に必要な説明以外は変えない。

## 未決事項

なし。
途中セルの占有による遮蔽は既存の単体対象条件にないため加えず、指定位置の対象だけで判定する。
表示名と検証専用の構成はdesign.mdで決める。
