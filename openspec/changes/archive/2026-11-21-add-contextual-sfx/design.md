# 設計

## 背景と制約

- 提案: [proposal.md](proposal.md)
- 前提: openspec/tech.md の アーキテクチャ、技術上の判断基準、テスト方針。
- 4音はoggで、選択約0.059秒、回転約0.512秒、攻撃約0.784秒、回復約0.366秒である。
  出典文書はなく、Vorbisのタグだけでは作者とライセンスを確定できない。
- 既存の音量UIと音声処理はない。
  攻撃と回復の実HPと表示は既存の_feedbackで結び付いている。

## 設計判断

### D-01 - 音の責務と手動入力

- 選択: ui/sfx.gdへ4素材と再生を集約し、現在の入力配送中だけ有効な手動入力票を持たせる。
  成立した経路、確認対象、ボタン、候補と設定の選択から票を1回消費する。
  ホバー、Tabのフォーカスだけ、文字入力、非活性候補と自動更新は消費しない。
- 理由: 同じ入力から複数のGUIシグナルが出ても1音とし、CPUと予測、初期値設定を鳴らさない。
- 代替案: マウスイベントすべてで鳴らす方法は無効入力を区別できず、全てのvalue_changedは自動更新にも鳴る。
- 昇格: openspec/tech.md の 技術上の判断基準、openspec/structure.md の 配置原則。

### D-02 - 表示の各歩と実HPの確定

- 選択: 移動表示の既存elapsedと各歩の回転deltaを観測し、各歩を一度だけ完了済みにする。
  1輪以上の非ゼロ回転があれば1音とし、全周の回転も実回転として扱う。
  表示を省く設定と0歩では音の列を作らない。
  _feedbackは実HP変化が正のDAMAGEとHEALだけを、戦闘と履歴番号で重複排除する。
- 理由: セル中心の拍とHP適用の既存時刻へ接続し、計算や演出の待ちを追加しない。
  停止中の時計は進めず、退出で参照を切り、復帰後に過去の音を連続再生しない。
- 代替案: モデル内部での発音は予測とCPU評価にも鳴り、専用の待ち行列は移動と音がずれる。
- 昇格: openspec/tech.md の 技術上の判断基準。

~~~mermaid
flowchart LR
  INPUT["手動入力と有効な選択"] --> SFX["効果音の管理"]
  MOVE["確定移動の歩の完了"] --> SFX
  HP["実HPの結果表示"] --> SFX
  SFX --> PLAY["選択、回転、効果の3音声レーン"]
  EXIT["退出と停止"] --> SFX
~~~

### D-03 - 原音と控えめな音量

- 選択: 本人の4ファイルを原本のまま実装の依存として管理する。
  1レーン1声のselect、ring_rotate、effectを使い、攻撃と回復はeffectを共有して重ねない。
  音量はgame/tuning.gdのSFX_VOLUME_DBにselect -18dB、ring_rotate -18dB、attack -15dB、heal -8dBを置く。
  既存のMaster出力へ従い、ループとBGM、追加の音量UI、保存は作らない。
  出力を持たないDummyドライバーでは再生要求の観測だけを行い、非同期の音声を開始しない。
  Movie MakerではDummyでも音声を出力する。
  通常の音声ドライバーでは実ミックス信号を別に検証する。
- 理由: 原音RMSは選択0.062、回転0.033、攻撃0.313、回復0.113であり、強い攻撃の信号を抑え、回復と近い信号量にする暫定値である。
  長い回転と攻撃の尾が連続しても、同じレーンで積み重ならない。
  無出力の高速テスト終了時に、エンジンの非同期停止が音声参照を残す問題を避ける。
- 代替案: 音源の書換と同一ゲインは避け、無制限の多重再生もしない。
- 昇格: openspec/structure.md の 配置原則。

手動入力票、歩の重複排除、HP結果の重複排除と再生レーンは部品で確認する。\
UI層はマウスとキー、確定移動と効果表示との代表接続を確認し、同じ判断を重複して全組合せにしない。\
聴感の最終確認はmanual-checks.mdへ未確認で残し、開発時の実再生と取得できる音声信号を別に記録する。\
無効入力と無音、0歩、ゼロ変化、停止、退出を境界と異常の観点とし、バランスの固定期待値は増やさない。

## リスクと移行

出典は未確認であり、assets/sfx/NOTICE.mdへその事実と元ファイルの保持を記録する。\
通常データと設定の移行はなく、本人が置いた音の内容と更新時刻を検証の前後で照合する。\
聴感の好みと機器差は信号量だけでは判定せず、確認できなければその旨を報告する。
