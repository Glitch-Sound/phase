# 提案

## 目的

移動による位相の変化を周囲から制御したい利用者へ、範囲と作用が見える3種類のパッシブを追加する。
同時にGUARDの自分対象へ重なる四辺の枠をなくし、既存の四隅フォーカスと八角形だけで対象と防御を読み取れるようにする。

## 変更内容

- 上下左右1マスの本人を除く両陣営へ、GEARとARMSの1歩分の回転量を減速0.5倍、停止0倍、加速1.5倍にするパッシブを追加する。
- 同種は重複せず、異種は停止優先、減速と加速が両方なら通常倍率へ相殺する。
- 各歩の着地と強制移動で同じ規則を使い、CORE、能力値と手番速度は変えず、範囲外へ持続させない。
- 範囲を薄い雲で示し、予測と確定、説明、CPU、取得と版1保存へ接続する。
- GUARDの自分対象では四辺の対象枠と重複する対象面を除き、既存のフォーカスと防御図形を維持する。

## 対象外

- 攻撃と回復の基礎威力、GUARDの効果、COREパネルと手番の計算変更。
- 周囲への直接攻撃、能力値の永続変更、雲の画像素材と追加アプリ。
- 敵の初期装備の自動変更、全品の初期開放と既存セーブへの自動追加。
- 実セーブと設定の保存、pushと公開。

## 対象の仕様

### 新規

なし。

### 変更

- phase-rings: 周囲回転の範囲と倍率、重複、各歩と強制移動を定める。
- build-collection: 新3品の収集と共有装備、旧保存を維持する。
- enemy-cpu: 周囲を含む実位相の予測と危険評価へ対応する。
- battle-interface: 雲と説明、予測の区別、GUARDの四隅へ対応する。

既存の仕様書へ追加し、要件数を各15以下に保つ。

## 影響

進入の計算はユニット単体から周囲の現在位置も参照する処理となる。
戦闘中だけの位置関係を保存へ追加せず、新しいスキルIDだけを既存の3枠へ保存する。
バランス依存の勝敗や決着手数を自動検査へ固定しない。

## 未決事項

異種重複は利用者が判断を委ねた範囲として、停止優先、減速と加速の相殺へ決めた。
雲の輪郭、濃さと予測の破線は表示の調整値であり、実画面で確認して決める。
実装を止める未決事項はない。
