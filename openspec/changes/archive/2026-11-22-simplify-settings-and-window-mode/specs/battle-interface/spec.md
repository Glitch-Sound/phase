# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-020 - システム操作

画面はHELP、SETTINGS、RESTART、QUITを備え、HELPで操作を説明し、設定でウィンドウとフルスクリーンを切り替え、戦闘中は4つをこの順の2列2段で盤面右下へ置き下端を盤面と揃え、RESTARTでBUILDへ戻り、DISPLAYの実際の選択を持続して示し、REDUCED MOTIONを表示と演出制御から除き、指定された言語と配色の補足説明を除いて設定を詰め、単独実行では確定した明示表示モードを保存と復元し、エディター埋め込みでは非対応の切替を無効として説明しなければならない(SHALL)。

#### Scenario: REQ-020-S01 - システムメニュー

- **GIVEN** 起動したゲーム
- **WHEN** 各メニューを操作する
- **THEN** HELPが開閉し、表示モードが変わり、RESTARTでBUILDに戻り、QUITで終了する
- **AND** 戦闘ではHELPとSETTINGS、RESTARTとQUITの2列2段で盤面右下へ並び、下端が盤面と揃い、BACKとWAITに重ならない
- **AND** DISPLAYは実モードに対応する1項目だけを選択表示し、ホバーとキーボードフォーカスを外しても維持し、切替と再表示で追随し、COLORの見出しは他の見出しと揃えて上へ余白を置き、日英でREDUCED MOTIONを表示しない

#### Scenario: REQ-020-S02 - 表示設定の保存境界

- **GIVEN** 単独実行と隔離した表示設定
- **WHEN** 表示モードを選ぶ
- **THEN** 実モードが選択と一致して安定した後だけ保存し、再起動で復元し、非同期復元中の古い実状態で保存値を上書きしない
- **AND** 未設定と不明な値はWINDOWEDとして扱い、明示操作前には書き込まない

#### Scenario: REQ-020-S03 - 埋め込みの制約

- **GIVEN** エディター埋め込みで実行したゲーム
- **WHEN** SETTINGSを開く
- **THEN** 表示切替は非活性で制約の説明があり、未適用のFULLSCREENを選択済みとして示さず、保存値を上書きしない

### Requirement: REQ-032 - リング配色の強調

画面は有効な配色を表示するとき、組み込みプリセットと6色すべてが一致する配色の3リングだけを同じ色相と明度で高彩度にし、それ以外のカスタム配色は指定RGBのまま使い、他UIの色、独立したアセンブリによる紋章と同一の残HP色、形状と保存内容を変更せず、色設定でこの違いを知らせなければならない(SHALL)。

#### Scenario: REQ-032-S01 - 組み込み配色

- **GIVEN** DEFAULT、AMBER、ICEのいずれかと6色が完全に一致する配色
- **WHEN** リングを表示する
- **THEN** VIT、INF、RES、SPD、LUKの色相と明度を維持して彩度を高め、CORE、GEAR、ARMSの色分類を同じに保ち、配色の判読性と区別の基準を満たす

#### Scenario: REQ-032-S02 - カスタムの保持

- **GIVEN** アクセントだけが異なる場合を含め、組み込み配色と6色が完全一致しない有効な保存済み配色
- **WHEN** 配色を読み込んで表示する
- **THEN** リングは指定した5色のRGBと完全一致し、入力配色と保存ファイルの全内容は変わらない

#### Scenario: REQ-032-S03 - 設定との接続

- **GIVEN** 未確定経路を持つゲームと色設定
- **WHEN** 組み込み配色とカスタム配色を明示的に適用する
- **THEN** リングだけが配色の種類に応じた表示になり、他UIは指定した基本色、経路と戦闘状態は元のままで、設定画面にプリセット強調とカスタム色保持の補足文を置かない

#### Scenario: REQ-032-S04 - 黒い背景での実表示

- **GIVEN** 既定と変更したプリセット、カスタム配色のゲーム
- **WHEN** 盤面、TURN ORDER、詳細、プレビュー、BUILDを表示する
- **THEN** 異なる背景と大小の記号でも3リングの色分類と設定色の残HPを区別でき、形状、線幅、配置を維持する
