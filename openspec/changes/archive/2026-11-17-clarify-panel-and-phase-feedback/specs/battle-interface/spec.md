# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-018 - 経路入力表示

画面は経路番号、ユニットのリングと重ならないノード間の線、設定したアクセント色の終点、対象範囲、有効対象、選択、ホバーをセルの枠上で強調して表示し、パネル効果は文字の略号でなく意味の異なるアイコンで示し、ホバーとHELPで意味を確認でき、HELPで最終セルのダブルクリックを知らせなければならない(SHALL)。

#### Scenario: REQ-018-S01 - 経路操作

- **GIVEN** 移動状態の戦闘画面
- **WHEN** 経路追加、取消、ダブルクリック、対象選択を操作する
- **THEN** 番号と終点が追随し、行動選択とBACKが動作する

#### Scenario: REQ-018-S02 - 経路とリングの分離

- **GIVEN** ユニットから上下左右へ進む経路と、最小、標準、拡大された表示領域
- **WHEN** 経路を表示する
- **THEN** 線の端は起点や終点にあるユニットの記号の外側にあり、線幅を含めて色リングとHP円弧や目盛りに重ならず、経路番号と終点は維持される
- **AND** 線を引ける余白がない区間や長さ0の区間では線を描かず、経路や戦闘状態は変更しない

#### Scenario: REQ-018-S03 - パネルのアイコンと確認

- **GIVEN** RESET、CLOCKWISE、COUNTERCLOCKWISEとNORMALのパネル
- **WHEN** 盤面を表示して効果を調べる
- **THEN** 特殊パネルには順に塗りつぶした単純なひし形、時計回り、反時計回りの区別できるアイコンを表示し、旧効果のアイコンとS+、L=、R-の略号は残さず、NORMALには効果アイコンを表示しない
- **AND** ホバーとHELPでCOREの戦闘開始角へのリセット、COREのSPDに基づく正逆回転と、全セルでGEARとARMSの通常回転を維持することが分かり、HELPで現在の配置シードを読める
- **AND** 最小と拡大でアイコンを区別でき、ホバーの確認は経路、対象とクリックを妨げない

#### Scenario: REQ-018-S04 - セル境界の強調

- **GIVEN** 効果記号のあるセル、隣接セルまたは盤面端のセル
- **WHEN** ユニットの選択、ホバー、経路終点または行動対象を表示する
- **THEN** 操作対象の強調枠はセルの枠上に収まり、効果記号と交差せず、隣のセルの枠と区別でき、拡縮後も切れずに操作対象へ対応する
- **AND** 目標セルの印と操作、経路と効果は変わらない

### Requirement: REQ-033 - 円形の位相予測

WHILE 経路後の位相を予測する間、画面は3リングを維持して周囲へCORE、GEAR、ARMSと最終重なりの4輪郭を共通の半径付近で重ねて表示し、実際の領域境界の色をグラデーションで接続し、実際の配分と回転に沿う色分類と形、同じステータスの一致が多いほど輪郭の広がり、明るさと明瞭さを増して局所的な重なりを表し、時間や乱数で変形させず、戦闘式と保存内容を変更せずに経路と配色へ追随しなければならない(SHALL)。

#### Scenario: REQ-033-S01 - 局所的な一致

- **GIVEN** 各ステータスが20ずつの3リング
- **WHEN** VIT領域の中央に相当する同じ角度を表示する
- **THEN** 位相の組み合わせに応じて次の重なりとなり、一致が多いほど4輪郭の広がりと結果の明るさと線の明瞭さが増し、不一致の輪郭も黒背景から区別できる

| COREの位相 | GEARの位相 | ARMSの位相 | 重なり |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 3つのVITが一致 |
| 0 | 0 | 72 | COREとGEARのVITだけが一致 |
| 0 | 72 | 144 | 同じステータスの一致がない |

#### Scenario: REQ-033-S02 - 決定的な更新

- **GIVEN** 有効な配分と突然変異、回転角、カスタム色を持つ予測
- **WHEN** 予測を表示する
- **THEN** 全周の色分類と形が実際の領域を反映して閉じ、同じ入力では同じ4輪郭になり、経路と配色の変更時に更新され、入力の状態と保存は変化しない

#### Scenario: REQ-033-S03 - 実表示の比較

- **GIVEN** 一致する位相とずれた位相、既定と変更した配色、基準と最小の画面
- **WHEN** Godotで予測を比較する
- **THEN** 低、中、高の一致の違いと内側の3リングとHP、周囲の4輪郭を区別でき、リング下のINFとRESの最終同期率は表示せず、輪郭は内側のリングと左右の情報、行動順、通知を隠さず、拡大マップと左右の情報が重ならず、経路の選択と対象への操作を続けられる

#### Scenario: REQ-033-S04 - 重なる輪郭と境界の連続色

- **GIVEN** 同じステータス配分で一致または不一致となる位相と有効な配色
- **WHEN** 円形予測を表示する
- **THEN** 4輪郭が近い半径で重なり、各色領域の中央では指定色を保ち、境界では隣接する実際の色へ連続的につながり、完全一致の輪郭は不一致より鮮明で、同期率と戦闘状態を変えない
