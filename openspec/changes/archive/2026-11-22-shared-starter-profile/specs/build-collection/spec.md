# 差分仕様

## ADDED Requirements

### Requirement: REQ-061 - 初回の共通プロフィール

WHEN 保存されたプロフィールがない状態で起動するとき、通常版とWeb版は固定初期装備と編成を維持し、既存カタログの未所持ARMSとGEARから各5種を重複なく追加抽選し、能力配分の異なる候補へ分散し、初めてBUILDを表示したときだけ追加解放品をカテゴリ別ダイアログで示さなければならない(SHALL)。

#### Scenario: REQ-061-S01 - 新規の追加装備

- **GIVEN** 新規プロフィールと既存の固定初期品
- **WHEN** 初回の起動を行う
- **THEN** 固定初期品と編成、初期スキルを保ち、カタログの数値を変えず、ARMSとGEARはそれぞれ異なる能力軸へ分散した未所持5種を追加で持つ
- **AND** 同じ抽選シードと入力から同じ結果になり、候補不足では存在する未所持品だけを追加して重複させない

#### Scenario: REQ-061-S02 - 通常版の再起動と既存保存

- **GIVEN** 初回作成した保存、または変更前から有効な既存プロフィール
- **WHEN** 通常版を再起動する
- **THEN** 保存済みの編成と名前、解放とステージを復元し、追加抽選と読込元への自動書込を行わない
- **AND** 未作成の初回だけ通常の保存方式で抽選結果を保存する

#### Scenario: REQ-061-S03 - 起動時の保存異常

- **GIVEN** 不正な既存保存または書込不能な初回保存先
- **WHEN** 起動を行う
- **THEN** エラーを報告し、既存のファイルを変更せず、不正保存へ新規結果を上書きせず、初回の書込失敗でも同じセッションで抽選を繰り返さない

#### Scenario: REQ-061-S04 - 初回の解放通知

- **GIVEN** 初回抽選の完了した新規プロフィール
- **WHEN** 初めてBUILDを表示する
- **THEN** ARMSとGEARをカテゴリ別に示すダイアログが現れ、固定品を除いた今回の追加解放だけが一覧と一致する
- **AND** 閉じるかEscで通常BUILDへ戻り、同じセッションの再訪と再戦、既存プロフィールの起動では表示せず、新規Webセッションでは再び表示する

### Requirement: REQ-062 - Webの非永続セッション

WHERE Web版である場合、ゲームと設定は通常版と同じデータ構造と初期化、編成、報酬、解放と戦闘処理を使い、入出力先だけをページ内メモリへ切り替え、ブラウザの永続ストレージへプレイデータと設定を書き込んではならず(SHALL NOT)、ページ再読み込みで新規状態にならなければならない(SHALL)。

#### Scenario: REQ-062-S01 - ページ内の継続と再読み込み

- **GIVEN** Webの新規セッションで編集、報酬取得と設定変更を行った状態
- **WHEN** 同じページで再戦とシーン切替、SAVEとLOADを行う
- **THEN** 同じセッションのプロフィールと明示保存結果、設定を維持し、通常版と同じ構成検証と戦闘を使う
- **AND** 新しいページのセッションには以前の解放と構成、設定を復元しない

#### Scenario: REQ-062-S02 - 永続ストレージの不使用

- **GIVEN** Webセッションとゲーム保存、配色、言語、効果音、表示モードの設定
- **WHEN** 保存と復元を行う
- **THEN** ファイルとブラウザの永続ストレージへ読み書きせず、Web出力の起動も永続ファイルシステムとPWAを有効化しない

#### Scenario: REQ-062-S03 - 新規装備の実表示

- **GIVEN** 新規プロフィールのBUILD
- **WHEN** 日本語の標準と最小画面でARMSとGEARを確認する
- **THEN** 初回の追加解放を選択でき、未解放と区別でき、通常の装備とプレビュー、取消を操作できる
