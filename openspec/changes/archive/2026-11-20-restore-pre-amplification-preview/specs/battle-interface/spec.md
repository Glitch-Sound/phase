# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-033 - 円形の位相予測

WHILE 経路後の位相を予測する間、画面は3リングを維持して周囲へCORE、GEAR、ARMSと最終重なりの4輪郭を共通の半径付近で重ねて表示し、実際の領域境界の色をグラデーションで接続し、実際の配分と回転に沿う色分類と形、同じステータスの一致が多いほど周期的な半径の振幅、明るさと明瞭さを増して局所的な重なりを表し、3装備の実SPDと装備ごとの差に応じた周期波で円形を保って揺らし、結果へ3波の合成を使い、強い一致区間の合成結果だけを滑らかに大きく速く揺らし、乱数を使わず、戦闘式と保存内容を変更せずに経路と配色へ追随しなければならない(SHALL)。

#### Scenario: REQ-033-S01 - 局所的な一致

- **GIVEN** 各ステータスが20ずつの3リング
- **WHEN** VIT領域の中央に相当する同じ角度を複数周期にわたって表示する
- **THEN** 位相の組み合わせに応じて次の重なりとなり、一致が多いほど4輪郭の振幅の包絡と結果の明るさと線の明瞭さが増し、不一致の輪郭も黒背景から区別できる

| COREの位相 | GEARの位相 | ARMSの位相 | 重なり |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 3つのVITが一致 |
| 0 | 0 | 72 | COREとGEARのVITだけが一致 |
| 0 | 72 | 144 | 同じステータスの一致がない |

#### Scenario: REQ-033-S02 - 決定的な更新

- **GIVEN** 有効な配分と突然変異、回転角、SPD、表示時間とカスタム色を持つ予測
- **WHEN** 予測を表示する
- **THEN** 全周の色分類と形が実際の領域を反映して閉じ、同じ入力と表示時間では同じ4輪郭になり、経路と配色の変更時に更新され、入力の状態と保存は変化しない

#### Scenario: REQ-033-S03 - 実表示の比較

- **GIVEN** 一致する位相とずれた位相、既定と変更した配色、基準と最小の画面
- **WHEN** Godotで予測を比較する
- **THEN** 低、中、高の一致の違いと内側の3リングとHP、周囲の4輪郭を区別でき、リング下のINFとRESの最終同期率は表示せず、輪郭は内側のリングと左右の情報、行動順、通知を隠さず、拡大マップと左右の情報が重ならず、経路の選択と対象への操作を続けられる

#### Scenario: REQ-033-S04 - 重なる輪郭と境界の連続色

- **GIVEN** 同じステータス配分で一致または不一致となる位相と有効な配色
- **WHEN** 円形予測を表示する
- **THEN** 4輪郭が近い半径で重なり、各色領域の中央では指定色を保ち、境界では隣接する実際の色へ連続的につながり、完全一致の輪郭は不一致より鮮明で、同期率と戦闘状態を変えない

#### Scenario: REQ-033-S05 - SPDと周期の分離

- **GIVEN** 等しいSPD、異なるSPDまたは有効範囲の端のSPDを持つ3装備
- **WHEN** 時間を進めて予測を表示する
- **THEN** 各輪郭は円形を保って異なる正の周期と位相差で連続的に揺れ、同じ装備のSPDが大きいほど基礎速度が速く、同じSPDでも3本が同周期で固定されない
- **AND** 合成線は3本の波に追随し、実位相で一致する色の箇所の振幅の包絡が大きく、実際の角度と同期率、時刻と手番、経路は時間によって変わらない
- **AND** 個別3輪郭の同じ表示時刻の座標と周期を維持し、弱い一致の合成結果も従来と同じ動きとし、強い一致区間だけをより大きい振幅と速い周期へ滑らかにつなぐ
- **AND** 強調は設定した包絡を超えず、色と一致区間の角度を時間で動かさず、長い表示時間でも輪郭に細かなねじれや不連続を増やさない

#### Scenario: REQ-033-S06 - 動きを抑える設定

- **GIVEN** 未確定経路を持つ周期的な予測
- **WHEN** 既存の動きを抑える設定を有効にして時間を進める
- **THEN** 輪郭は現在の形で停止し、再び無効にするとその表示時間から揺れを再開し、経路と戦闘状態、配色は変わらない
