# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-010 - 移動確定と予測

WHEN 最終パネルをダブルクリックするとき、選択経路どおりに移動と位相を確定し、行動選択を表示しなければならない(SHALL)。

#### Scenario: REQ-010-S01 - 予測一致

- **GIVEN** CLOCKWISE、RESET、COUNTERCLOCKWISEを順に通る有効経路
- **WHEN** 経路を確定する
- **THEN** COREを含む全3リングの確定角は経路順の予測と一致し、移動状態から行動選択状態へ移り、予測だけでは原本を変更しない

#### Scenario: REQ-010-S02 - CORE予測の取消

- **GIVEN** COREが回転またはリセットされる未確定経路
- **WHEN** 経路の後半を取り消す、または開始セルかEscで全取消する
- **THEN** 残った経路だけのCORE予測へ戻り、全取消では手番開始時のCORE角を維持し、未確定の変更を実状態へ適用しない

### Requirement: REQ-034 - 効果パネルの分散配置

WHEN 戦闘を開始するとき、ゲームは全100セルの20%を四捨五入した枚数を目標に、初期ユニット位置と両陣営の勝敗目標を除いたセルへRESET、CLOCKWISE、COUNTERCLOCKWISEをランダム配置し、候補不足なら候補数へ減らし、4つの5x5区画へ候補数に応じて偏りを抑えて分散し、隣接を許可し、同じステージとシードで再現可能にし、配置後は決定的な戦闘計算を維持しなければならない(SHALL)。

#### Scenario: REQ-034-S01 - 数量と除外

- **GIVEN** 10x10の盤面と初期ユニット位置、勝利と敗北の目標セル
- **WHEN** 効果を配置する
- **THEN** 母数は除外前の100であり、密度から算出した目標数を重複なく配置し、盤外と除外セルには置かず、端数は0.5以上を切り上げる
- **AND** 3種類の枚数差は最大1であり、各効果の回転の意味は変わらない

#### Scenario: REQ-034-S02 - 再現と固定

- **GIVEN** 同じステージ、シードと環境
- **WHEN** 戦闘を再構築する
- **THEN** 全セルと種類の対応が一致し、他の乱数の使用、経路の予測、描画、行動は配置を再抽選しない

#### Scenario: REQ-034-S03 - 分散と隣接

- **GIVEN** 全域に候補がある盤面と異なるシード
- **WHEN** 複数の配置を生成する
- **THEN** 座標と種類は変わり、各5x5区画の枚数は候補数に比例する目標の切り捨てまたは切り上げとなり、どの候補セルも選ばれ得て、隣接する効果も生成される

#### Scenario: REQ-034-S04 - 候補不足

- **GIVEN** 除外後の候補が目標数未満、または0の盤面
- **WHEN** 効果を配置する
- **THEN** 候補を超える配置や無限の再抽選をせず、候補全数、または空の配置となる

#### Scenario: REQ-034-S05 - ステージの安全性

- **GIVEN** 複数のシードで開始した4ステージ
- **WHEN** 両陣営が移動と行動を行う
- **THEN** 移動の合法性、回転式、目標の優先順位は維持され、初手の即時報酬ループを作らず、生成パネルは通行を封鎖せず、目標へ到達する経路が残る

#### Scenario: REQ-034-S06 - 開始ごとのシード

- **GIVEN** 通常起動したゲーム
- **WHEN** STARTから次の戦闘を開始する
- **THEN** 前回と異なる配置シードを選び、BUILDの編集だけでは新しい戦闘のシードを消費せず、ドロップ用の乱数状態を変更しない
