# 設計

## 背景と制約

- 提案: [proposal.md](proposal.md)
- 前提: openspec/tech.md の 技術上の判断基準、テスト方針、表示原則。
- 既存COREは0度固定で、COREのSPDは既存配列の4番目にある。保存ビルドは7項目に限定される。

## 設計判断

### D-01 - 戦闘だけの現在角と開始角

- 選択: ユニット生成時にcore_angleとinitial_core_angleを0度で初期化する。RESETは後者へ戻し、次戦は新ユニットから両方を設定し直す。COREの領域開始角へ現在角を反映する。
- 理由: 戦闘開始基準を途中の角度や前戦の状態と混同せず、保存形式と初期設定を変更しない。
- 代替案: 直前角への巻き戻しと、ビルドへ角度を追加する案は合意内容と異なるため採用しない。
- 昇格: openspec/tech.md の 技術上の判断基準。

### D-02 - 通常回転とCORE操作の合成

- 選択: 各進入でGEARとARMSの通常回転を必ず適用し、NORMALはCOREを維持、RESETは開始角、CLOCKWISEはCORE:SPDの1.5倍を加算、COUNTERCLOCKWISEは減算する。角度は360度で循環し、予測と確定は同じ経路順を使う。
- 理由: リセット前後の順序を保ち、特殊セルが通常の1歩を免除しないようにする。
- 再生記録: COREを含む3リングの確定角を履歴へ記録し、停滞検出の状態にもCORE角を含める。
- 代替案: 特殊セルでGEARやARMSを止める案と、全経路の回転を集計して最後にRESETする案は採用しない。
- 昇格: なし。

  S["手番開始の複製"] --> G["1セルのGEARとARMS通常回転"]
  G --> C["同セルのCORE操作"]
  C --> N["次のセルを経路順に処理"]
  N --> G
  N --> P["3リングの予測"]
  P --> E["確定して実状態へ保持"]
~~~

### D-03 - 共通位相とアイコン

- 選択: 共通の領域計算でCORE角を扱い、リング、同期、特異点と4輪郭を同じ入力へ接続する。予測キャッシュの署名へCORE角を加える。RESETはundo-2、時計回りはrotate-cw、反時計回りは既存rotate-ccwとする。ホバーとHELPで開始角とSPDと通常回転を説明する。
- 理由: 図と数値のずれやCOREだけ変わった場合のキャッシュ残りを防ぎ、リセットを円形の正逆回転から形で区別する。
- 代替案: 古い早送りと錠前の流用は意味を誤解させるため採用しない。
- 調整値: 既存のPANEL_ICON_SIZEとPANEL_ICON_OFFSET、配色を維持する。
- 昇格: なし。

### D-04 - 変更した契約に合わせた検査

- 選択: 既存固定配置のSHIFT、LOCK、REVERSEを順にCLOCKWISE、RESET、COUNTERCLOCKWISEへ置き換え、変更対象の期待値を実装前に独立計算で変更する。旧効果を模倣する実装を本番にもfixtureにも残さない。実盤面の複数シード再生も維持する。
- 理由: 旧効果を保存したfixtureで新ルールの不具合を隠さず、指定外の検査を弱めない。
- 代替案: 旧効果のまま検査を通す互換モードは採用しない。
- 昇格: なし。

## リスクと移行

配置数と抽選を維持しても回転の意味が変わるため、既存シードの勝敗は変わり得る。\
複数シードの実モデル再生で閉塞と目標への影響を報告する。\
旧迎撃地点(5,6)では敗北したため、取得可能なMOVEを両味方の空き枠へ入れ、初動を(6,5)へ変える検査方策を使う。\
回復を含む相互行動は回復評価1.8、初期役割の再生は1.4とし、勝利と両陣営の攻撃と回復を求める既存の期待値は維持する。\
旧方策の敗北と高回復評価の停滞も記録し、戦闘式を検査へ合わせない。\
セーブの移行はなく、既存データは読み書きしない。
