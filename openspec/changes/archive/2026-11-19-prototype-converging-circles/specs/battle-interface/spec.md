# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-021 - 効果フィードバック

WHEN 効果が実行されるとき、画面はダメージをINF色の負数、回復をRES色の正数(既定は赤と緑)、撃破をDEFEATEDとして対象付近から上昇しフェードする表示にし、効果の適用と同時に対象の中心を固定した細いグレーの同心円を短い時間差で外から内へ収束させ、HPと数値、撃破と手番を待たせず、撃破後も所定位置で短く終え、発光、粒子、軌道線、自然物と外部素材を使わない表現にしなければならない(SHALL)。

#### Scenario: REQ-021-S01 - 効果表示

- **GIVEN** 負傷と撃破と回復が起こる戦闘
- **WHEN** それぞれのスキルを使用する
- **THEN** HP変化と対応する符号、色、DEFEATEDを表示する

#### Scenario: REQ-021-S04 - 効果を待たせない収束

- **GIVEN** 合法な攻撃と回復、撃破、取消と画面退出
- **WHEN** 既存の効果を実行する
- **THEN** HP、数値と撃破、手番は従来の時点で変わり、同時に対象の発生位置へ時間差のある同心円を表示し、円を待たずに次の操作へ進める
- **AND** 対象の撃破と移動で円の中心を変えず、設定した短い表示時間で終了し、未確定の取消と攻撃回復以外には円を出さず、再戦、BUILDと補助画面、フォーカス喪失と退出、所有戦闘の変更で残さない
- **AND** 動きを抑える設定では追加の収束を省き、表示の停止や進行が戦闘計算と履歴、保存を変更しない

#### Scenario: REQ-021-S05 - 幾何的な収束の描画

- **GIVEN** 通常速度の攻撃と回復、撃破、隣接者と盤端、最小と標準サイズ
- **WHEN** 対象の収束を実描画する
- **THEN** グレーの細い同心円が同じ中心へ時間差で内側に縮む動きを明瞭に読め、既存リング、フォーカスと数値を覆わず、雲と移動、右情報と予測を維持する
- **AND** 攻撃と回復に同じ形を使い、追加の発光、粒子、軌道線と色分け、自然物と外部素材はなく、撃破後もその位置で短く終わる
