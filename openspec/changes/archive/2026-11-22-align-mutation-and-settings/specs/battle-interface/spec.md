# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-018 - 経路入力表示

画面は経路番号、ユニットのリングと重ならないノード間の線、設定したアクセント色の終点、対象範囲、有効対象、選択、ホバーをセルの枠上で強調して表示し、パネル効果は文字の略号でなく意味の異なるアイコンで示し、ホバーとHELPで意味を確認でき、HELPで最終セルのダブルクリックと経路の再選択を知らせ、戦闘中の現在手番と防御状態を盤面で色だけに頼らず識別できなければならない(SHALL)。

#### Scenario: REQ-018-S01 - 経路操作

- **GIVEN** 移動状態の戦闘画面
- **WHEN** 経路追加、取消、ダブルクリック、対象選択を操作する
- **THEN** 番号と終点が追随し、行動選択とBACKが動作する

#### Scenario: REQ-018-S02 - 経路とリングの分離

- **GIVEN** ユニットから上下左右へ進む経路と、最小、標準、拡大された表示領域
- **WHEN** 経路を表示する
- **THEN** 線の端は起点や終点にあるユニットの記号の外側にあり、線幅を含めて色リングとHP円弧や目盛りに重ならず、経路番号と終点は維持される
- **AND** 線を引ける余白がない区間や長さ0の区間では線を描かず、経路や戦闘状態は変更しない

#### Scenario: REQ-018-S03 - パネルのアイコンと確認

- **GIVEN** RESET、CLOCKWISE、COUNTERCLOCKWISEとNORMALのパネル
- **WHEN** 盤面を表示して効果を調べる
- **THEN** 特殊パネルには順に塗りのない単純なひし形、時計回り、反時計回りの区別できるアイコンを表示し、旧効果のアイコンとS+、L=、R-の略号は残さず、NORMALには効果アイコンを表示しない
- **AND** ホバーとHELPでCOREの戦闘開始角へのリセット、COREのSPDに基づく正逆回転と、全セルでGEARとARMSの通常回転を維持することが分かり、HELPで現在の配置シードを読める
- **AND** 最小と拡大でアイコンを区別でき、ホバーの確認は経路、対象とクリックを妨げない
- **AND** ホバー説明は短い英語の概要と薄い補足の2段とし、アイコンとフォーカスを隠さない

#### Scenario: REQ-018-S04 - セル境界の強調

- **GIVEN** 効果記号のあるセル、隣接セルまたは盤面端のセル
- **WHEN** ユニットの選択、ホバー、経路終点または行動対象を表示する
- **THEN** 操作対象の強調枠はセルの枠上に収まり、効果記号と交差せず、隣のセルの枠と区別でき、拡縮後も切れずに操作対象へ対応する
- **AND** 目標セルの印と操作、経路と効果は変わらない

#### Scenario: REQ-018-S05 - 盤面の現在手番

- **GIVEN** 人またはCPUの手番と、別ユニットの選択またはホバー、最小から拡大の画面と変更色
- **WHEN** 移動、行動選択、対象選択、手番交代と終局を表示する
- **THEN** 通常の手番開始時は生存する手番ユニットのセルへ移動先と同じ既存の角枠を表示し、白い三角と独自の枠は表示しない
- **AND** 経路編集中は既存の終点枠、任意の確認中は選択枠を優先し、ホバーと対象範囲の既存表現と操作を維持し、終局では手番の枠を表示しない
- **AND** 角枠はセルの枠上に収まり、リング、効果アイコンと隣接セルの識別やメニューを妨げない

#### Scenario: REQ-018-S06 - スキル範囲の識別

- **GIVEN** 4種類のDAMAGEとHEAL、移動後の行動選択と盤面端
- **WHEN** スキルを表示して対象を選ぶ
- **THEN** BUILDと情報、行動選択で作用と位置関係を区別でき、対象状態では指定範囲の盤内セルだけを示し、有効対象と効果量の符号と陣営を正しく強調する
- **AND** 無効対象だけの行動を選べず、説明とHELPは上下左右と斜め、正確な1マス先と2マス先を区別し、最小と拡大でも文字と操作が欠けず、BACKとEsc、移動、手番とCPUの操作を維持する

#### Scenario: REQ-018-S07 - 位置操作と防御の識別

- **GIVEN** 新しい4品を持つBUILDと戦闘、SWAPとPUSHの有効、無効な対象とGUARD状態
- **WHEN** 装備、行動と対象を選び、説明と予測を確認する
- **THEN** 名前と短い効果を区別でき、無効な行動は選べず、有効対象のホバーまたはCPU対象表示で強制移動先と変化後のリングを原本を変えず確認できる
- **AND** 新しい作用をダメージや回復の数値として表示せず、防御状態と対象上の発動はGUARDの文字や小さな盾の代わりに薄い多角形をリングへ重ね、HPと各リング、中央名を遮らず、解除と対象取消に追従し、GUARDの自分対象では四辺の対象枠と対象面を重ねず既存の四隅フォーカスを使う
- **AND** 防御の図形を盤面、手番一覧、詳細と予測で共通化し、スキル名と操作、HELPの説明は維持し、予測を実状態と区別して、各サイズと既存のBACK、Esc、選択、CPUの操作を維持する

#### Scenario: REQ-018-S08 - 周囲の雲と説明

- **GIVEN** SLOW FIELDとFAST FIELDの周囲パッシブ、盤面端と重複、発生源の移動経路と強制移動の予測
- **WHEN** 範囲を表示してホバー、装備とHELPで調べる
- **THEN** セルごとの十字形ではなく、生存発生源を中心に周囲へ漂う連続した控えめな雲をユニットとパネル記号より下へ描き、斜めを含む周囲8マスと本人除外、倍率と同種の重複なし、相殺を説明し、廃止したSTOP FIELDを選択、詳細、ホバーとHELPへ表示しない
- **AND** 雲は盤外と距離2以上のセルへ広がらず、移動後の予測は薄い破線の雲で現在と区別し、取消、確定と撃破へ追従し、最小から拡大でもHP、各リング、フォーカスと既存のクリックやメニューを妨げず、GUARDの八角形と区別する
- **AND** 時間経過で雲の形と位置がゆっくり変わっても効果範囲と戦闘値は変わらず、古い動きを抑える設定が残っていても通常の動きを続ける
- **AND** 確定した通常移動では移動者自身の雲だけを出発前に透過させて移動中は隠し、着地で再表示し、静止する他ユニットの雲と実際の周囲効果は変えず、0歩と取消では雲を消さない

### Requirement: REQ-020 - システム操作

画面はHELP、SETTINGS、RESTART、QUITを備え、HELPで操作を説明し、設定でウィンドウとフルスクリーンを切り替え、戦闘中は4つをこの順の2列2段で盤面右下へ置き下端を盤面と揃え、RESTARTでBUILDへ戻り、DISPLAYの実際の選択を持続して示し、REDUCED MOTIONを表示と演出制御から除かなければならない(SHALL)。

#### Scenario: REQ-020-S01 - システムメニュー

- **GIVEN** 起動したゲーム
- **WHEN** 各メニューを操作する
- **THEN** HELPが開閉し、表示モードが変わり、RESTARTでBUILDに戻り、QUITで終了する
- **AND** 戦闘ではHELPとSETTINGS、RESTARTとQUITの2列2段で盤面右下へ並び、下端が盤面と揃い、BACKとWAITに重ならない
- **AND** DISPLAYは実モードに対応する1項目だけを選択表示し、ホバーとキーボードフォーカスを外しても維持し、切替と再表示で追随し、COLORの見出しは他の見出しと揃えて上へ余白を置き、日英でREDUCED MOTIONを表示しない

### Requirement: REQ-021 - 効果フィードバック

WHEN 効果が実行されるとき、画面はダメージをINF色の負数、回復をRES色の正数(既定は赤と緑)、撃破をDEFEATEDとして対象付近から上昇しフェードする表示にし、効果の適用と同時に対象の中心を固定した細い同心円を短い時間差で、既定の赤い攻撃は従来の外から内への収束、既定の緑の回復は中心近くから外への発散として表示し、既存の配色設定を尊重し、HPと数値、撃破と手番を待たせず、撃破後も所定位置で短く終え、攻撃には通常と高INF、撃破後を含め白い外縁を加えず、最初の回復円の接触時に実際の増分円弧だけを淡くして元のアセンブリ設定色へ戻し、全面の発光と連続点滅、粒子、軌道線、自然物と外部素材を使わない表現にしなければならない(SHALL)。

#### Scenario: REQ-021-S01 - 効果表示

- **GIVEN** 負傷と撃破と回復が起こる戦闘
- **WHEN** それぞれのスキルを使用する
- **THEN** HP変化と対応する符号、色、DEFEATEDを表示する

#### Scenario: REQ-021-S04 - 効果を待たせない円

- **GIVEN** 合法な攻撃と回復、撃破、取消と画面退出
- **WHEN** 既存の効果を実行する
- **THEN** HP、数値と撃破、手番は従来の時点で変わり、同時に対象の発生位置へ時間差のある同心円を表示し、円を待たずに次の操作へ進める
- **AND** 対象の撃破と移動で円の中心を変えず、設定した短い表示時間で終了し、未確定の取消と攻撃回復以外には円を出さず、再戦、BUILDと補助画面、フォーカス喪失と退出、所有戦闘の変更で残さない
- **AND** 通常の収束と拡散を表示し、表示の進行が戦闘計算と履歴、保存を変更しない

#### Scenario: REQ-021-S05 - 攻撃と回復の円の描画

- **GIVEN** 通常速度の攻撃と回復、撃破、隣接者と盤端、最小と標準サイズ
- **WHEN** 対象の攻撃と回復の円を実描画する
- **THEN** 赤系の攻撃は従来と同じ時間差、速度、尺、線幅と消え方で内へ縮み、緑系の回復は最初から中心近くに見えて外へ広がり外側で消える動きを通常速度で明瞭に読め、既存リング、フォーカスと数値を覆わず、雲と移動、右情報と予測を維持する
- **AND** 円は暗い盤面で両方の色と方向を識別でき、文字とHPは前面に保ち、設定色を尊重し、局所反応以外の追加の発光、粒子、軌道線、自然物と外部素材はなく、撃破後もその位置で短く終わる

#### Scenario: REQ-021-S06 - 最初の接触と実回復の反応

- **GIVEN** 通常と高INFの攻撃、撃破、実回復と上限を超える回復、回復量ゼロ
- **WHEN** 既存の円の最初の1本が対象外縁またはHP円弧を横切る
- **THEN** 攻撃は通常と高INF、撃破後を含め赤い収束だけを表示し、白い外縁の反応を追加しない
- **AND** 回復は最初の円がHP円弧を横切る時刻に、実際に増えた範囲だけが淡く反応し、上限を超えた分と回復量ゼロには増分の反応がない
- **AND** 反応は1回で元へ戻り、HP、数値、撃破と手番を待たせず、生死と履歴、保存を変更せず、既存の円と退出時の消去を維持する

#### Scenario: REQ-021-S07 - 局所の縁と増分の実描画

- **GIVEN** 最小と標準、通常と高INF、撃破と盤端、上限に達する回復
- **WHEN** 攻撃と回復を通常速度で表示する
- **THEN** 攻撃に白い外縁がなく、実回復増分だけの短い反応を読め、設定色のHP円弧とユニット紋章、既存リングと近隣の識別を覆わず、撃破後にユニット本体を復活させない
- **AND** 全画面の閃光と連続点滅、素材、粒子と軌道、追加の待ちはなく、赤い収束と緑の発散、移動と雲、情報更新を維持する

### Requirement: REQ-033 - 円形の位相予測

WHILE 経路後の位相を予測する間、画面は3リングを維持して周囲へCORE、GEAR、ARMSと最終重なりの4輪郭を共通の半径付近で重ねて表示し、実際の領域境界の色をグラデーションで接続し、実際の配分と回転に沿う色分類と形、同じステータスの一致が多いほど周期的な半径の振幅、明るさと明瞭さを増して局所的な重なりを表し、3装備の実SPDと装備ごとの差に応じた周期波で円形を保って揺らし、結果へ3波の合成を使い、強い一致区間の合成結果だけを滑らかに大きく速く揺らし、乱数を使わず、戦闘式と保存内容を変更せずに経路と配色へ追随しなければならない(SHALL)。

#### Scenario: REQ-033-S01 - 局所的な一致

- **GIVEN** 各ステータスが20ずつの3リング
- **WHEN** VIT領域の中央に相当する同じ角度を複数周期にわたって表示する
- **THEN** 位相の組み合わせに応じて次の重なりとなり、一致が多いほど4輪郭の振幅の包絡と結果の明るさと線の明瞭さが増し、不一致の輪郭も黒背景から区別できる

| COREの位相 | GEARの位相 | ARMSの位相 | 重なり |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 3つのVITが一致 |
| 0 | 0 | 72 | COREとGEARのVITだけが一致 |
| 0 | 72 | 144 | 同じステータスの一致がない |

#### Scenario: REQ-033-S02 - 決定的な更新

- **GIVEN** 有効な配分と突然変異、回転角、SPD、表示時間とカスタム色を持つ予測
- **WHEN** 予測を表示する
- **THEN** 全周の色分類と形が実際の領域を反映して閉じ、同じ入力と表示時間では同じ4輪郭になり、経路と配色の変更時に更新され、入力の状態と保存は変化しない

#### Scenario: REQ-033-S03 - 実表示の比較

- **GIVEN** 一致する位相とずれた位相、既定と変更した配色、基準と最小の画面
- **WHEN** Godotで予測を比較する
- **THEN** 低、中、高の一致の違いと内側の3リングとHP、周囲の4輪郭を区別でき、リング下のINFとRESの最終同期率は表示せず、輪郭は内側のリングと左右の情報、行動順、通知を隠さず、拡大マップと左右の情報が重ならず、経路の選択と対象への操作を続けられる

#### Scenario: REQ-033-S04 - 重なる輪郭と境界の連続色

- **GIVEN** 同じステータス配分で一致または不一致となる位相と有効な配色
- **WHEN** 円形予測を表示する
- **THEN** 4輪郭が近い半径で重なり、各色領域の中央では指定色を保ち、境界では隣接する実際の色へ連続的につながり、完全一致の輪郭は不一致より鮮明で、同期率と戦闘状態を変えない

#### Scenario: REQ-033-S05 - SPDと周期の分離

- **GIVEN** 等しいSPD、異なるSPDまたは有効範囲の端のSPDを持つ3装備
- **WHEN** 時間を進めて予測を表示する
- **THEN** 各輪郭は円形を保って異なる正の周期と位相差で連続的に揺れ、同じ装備のSPDが大きいほど基礎速度が速く、同じSPDでも3本が同周期で固定されない
- **AND** 合成線は3本の波に追随し、実位相で一致する色の箇所の振幅の包絡が大きく、実際の角度と同期率、時刻と手番、経路は時間によって変わらない
- **AND** 個別3輪郭の同じ表示時刻の座標と周期を維持し、弱い一致の合成結果も従来と同じ動きとし、強い一致区間だけをより大きい振幅と速い周期へ滑らかにつなぐ
- **AND** 強調は設定した包絡を超えず、色と一致区間の角度を時間で動かさず、長い表示時間でも輪郭に細かなねじれや不連続を増やさない

#### Scenario: REQ-033-S06 - 動きを抑える設定

- **GIVEN** 未確定経路を持つ周期的な予測
- **WHEN** 古い動きを抑える設定が残った状態で時間を進める
- **THEN** 輪郭は通常どおり動き続け、SETTINGSにREDUCED MOTIONがなく、古い値の有無で演出と経路、戦闘状態、配色が変わらない
