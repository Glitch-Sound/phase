# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-021 - 効果フィードバック

WHEN 効果が実行されるとき、画面はダメージをINF色の負数、回復をRES色の正数(既定は赤と緑)、撃破をDEFEATEDとして対象付近から上昇しフェードする表示にし、効果の適用と同時に対象の中心を固定した細い同心円を短い時間差で、既定の赤い攻撃は従来の外から内への収束、既定の緑の回復は中心近くから外への発散として表示し、既存の配色設定を尊重し、HPと数値、撃破と手番を待たせず、撃破後も所定位置で短く終え、攻撃には通常と高INF、撃破後を含め白い外縁を加えず、最初の回復円の接触時に実際の増分円弧だけを淡くして元の白へ戻し、全面の発光と連続点滅、粒子、軌道線、自然物と外部素材を使わない表現にしなければならない(SHALL)。

#### Scenario: REQ-021-S01 - 効果表示

- **GIVEN** 負傷と撃破と回復が起こる戦闘
- **WHEN** それぞれのスキルを使用する
- **THEN** HP変化と対応する符号、色、DEFEATEDを表示する

#### Scenario: REQ-021-S04 - 効果を待たせない円

- **GIVEN** 合法な攻撃と回復、撃破、取消と画面退出
- **WHEN** 既存の効果を実行する
- **THEN** HP、数値と撃破、手番は従来の時点で変わり、同時に対象の発生位置へ時間差のある同心円を表示し、円を待たずに次の操作へ進める
- **AND** 対象の撃破と移動で円の中心を変えず、設定した短い表示時間で終了し、未確定の取消と攻撃回復以外には円を出さず、再戦、BUILDと補助画面、フォーカス喪失と退出、所有戦闘の変更で残さない
- **AND** 動きを抑える設定では追加の収束を省き、表示の停止や進行が戦闘計算と履歴、保存を変更しない

#### Scenario: REQ-021-S05 - 攻撃と回復の円の描画

- **GIVEN** 通常速度の攻撃と回復、撃破、隣接者と盤端、最小と標準サイズ
- **WHEN** 対象の攻撃と回復の円を実描画する
- **THEN** 赤系の攻撃は従来と同じ時間差、速度、尺、線幅と消え方で内へ縮み、緑系の回復は最初から中心近くに見えて外へ広がり外側で消える動きを通常速度で明瞭に読め、既存リング、フォーカスと数値を覆わず、雲と移動、右情報と予測を維持する
- **AND** 円は暗い盤面で両方の色と方向を識別でき、文字とHPは前面に保ち、設定色を尊重し、局所反応以外の追加の発光、粒子、軌道線、自然物と外部素材はなく、撃破後もその位置で短く終わる

#### Scenario: REQ-021-S06 - 最初の接触と実回復の反応

- **GIVEN** 通常と高INFの攻撃、撃破、実回復と上限を超える回復、回復量ゼロ
- **WHEN** 既存の円の最初の1本が対象外縁またはHP円弧を横切る
- **THEN** 攻撃は通常と高INF、撃破後を含め赤い収束だけを表示し、白い外縁の反応を追加しない
- **AND** 回復は最初の円がHP円弧を横切る時刻に、実際に増えた範囲だけが淡く反応し、上限を超えた分と回復量ゼロには増分の反応がない
- **AND** 反応は1回で元へ戻り、HP、数値、撃破と手番を待たせず、生死と履歴、保存を変更せず、既存の円と退出時の消去を維持する

#### Scenario: REQ-021-S07 - 局所の縁と増分の実描画

- **GIVEN** 最小と標準、通常と高INF、撃破と盤端、上限に達する回復
- **WHEN** 攻撃と回復を通常速度で表示する
- **THEN** 攻撃に白い外縁がなく、実回復増分だけの短い反応を読め、HP円弧の白い芯と名前、既存リングと近隣の識別を覆わず、撃破後にユニット本体を復活させない
- **AND** 全画面の閃光と連続点滅、素材、粒子と軌道、追加の待ちはなく、赤い収束と緑の発散、移動と雲、情報更新を維持する
