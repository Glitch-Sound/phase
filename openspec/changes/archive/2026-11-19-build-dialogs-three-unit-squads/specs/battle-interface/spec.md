# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-018 - 経路入力表示

画面は経路番号、ユニットのリングと重ならないノード間の線、設定したアクセント色の終点、対象範囲、有効対象、選択、ホバーをセルの枠上で強調して表示し、パネル効果は文字の略号でなく意味の異なるアイコンで示し、ホバーとHELPで意味を確認でき、HELPで最終セルのダブルクリックと経路の再選択を知らせ、戦闘中の現在手番と防御状態を盤面で色だけに頼らず識別できなければならない(SHALL)。

#### Scenario: REQ-018-S01 - 経路操作

- **GIVEN** 移動状態の戦闘画面
- **WHEN** 経路追加、取消、ダブルクリック、対象選択を操作する
- **THEN** 番号と終点が追随し、行動選択とBACKが動作する

#### Scenario: REQ-018-S02 - 経路とリングの分離

- **GIVEN** ユニットから上下左右へ進む経路と、最小、標準、拡大された表示領域
- **WHEN** 経路を表示する
- **THEN** 線の端は起点や終点にあるユニットの記号の外側にあり、線幅を含めて色リングとHP円弧や目盛りに重ならず、経路番号と終点は維持される
- **AND** 線を引ける余白がない区間や長さ0の区間では線を描かず、経路や戦闘状態は変更しない

#### Scenario: REQ-018-S03 - パネルのアイコンと確認

- **GIVEN** RESET、CLOCKWISE、COUNTERCLOCKWISEとNORMALのパネル
- **WHEN** 盤面を表示して効果を調べる
- **THEN** 特殊パネルには順に塗りのない単純なひし形、時計回り、反時計回りの区別できるアイコンを表示し、旧効果のアイコンとS+、L=、R-の略号は残さず、NORMALには効果アイコンを表示しない
- **AND** ホバーとHELPでCOREの戦闘開始角へのリセット、COREのSPDに基づく正逆回転と、全セルでGEARとARMSの通常回転を維持することが分かり、HELPで現在の配置シードを読める
- **AND** 最小と拡大でアイコンを区別でき、ホバーの確認は経路、対象とクリックを妨げない
- **AND** ホバー説明は短い英語の概要と薄い補足の2段とし、アイコンとフォーカスを隠さない

#### Scenario: REQ-018-S04 - セル境界の強調

- **GIVEN** 効果記号のあるセル、隣接セルまたは盤面端のセル
- **WHEN** ユニットの選択、ホバー、経路終点または行動対象を表示する
- **THEN** 操作対象の強調枠はセルの枠上に収まり、効果記号と交差せず、隣のセルの枠と区別でき、拡縮後も切れずに操作対象へ対応する
- **AND** 目標セルの印と操作、経路と効果は変わらない

#### Scenario: REQ-018-S05 - 盤面の現在手番

- **GIVEN** 人またはCPUの手番と、別ユニットの選択またはホバー、最小から拡大の画面と変更色
- **WHEN** 移動、行動選択、対象選択、手番交代と終局を表示する
- **THEN** 通常の手番開始時は生存する手番ユニットのセルへ移動先と同じ既存の角枠を表示し、白い三角と独自の枠は表示しない
- **AND** 経路編集中は既存の終点枠、任意の確認中は選択枠を優先し、ホバーと対象範囲の既存表現と操作を維持し、終局では手番の枠を表示しない
- **AND** 角枠はセルの枠上に収まり、リング、効果アイコンと隣接セルの識別やメニューを妨げない

#### Scenario: REQ-018-S06 - スキル範囲の識別

- **GIVEN** 4種類のDAMAGEとHEAL、移動後の行動選択と盤面端
- **WHEN** スキルを表示して対象を選ぶ
- **THEN** BUILDと情報、行動選択で作用と位置関係を区別でき、対象状態では指定範囲の盤内セルだけを示し、有効対象と効果量の符号と陣営を正しく強調する
- **AND** 無効対象だけの行動を選べず、説明とHELPは上下左右と斜め、正確な1マス先と2マス先を区別し、最小と拡大でも文字と操作が欠けず、BACKとEsc、移動、手番とCPUの操作を維持する

#### Scenario: REQ-018-S07 - 位置操作と防御の識別

- **GIVEN** 新しい4品を持つBUILDと戦闘、SWAPとPUSHの有効、無効な対象とGUARD状態
- **WHEN** 装備、行動と対象を選び、説明と予測を確認する
- **THEN** 名前と短い効果を区別でき、無効な行動は選べず、有効対象のホバーまたはCPU対象表示で強制移動先と変化後のリングを原本を変えず確認できる
- **AND** 新しい作用をダメージや回復の数値として表示せず、防御状態と対象上の発動はGUARDの文字や小さな盾の代わりに薄い多角形をリングへ重ね、HPと各リング、中央名を遮らず、解除と対象取消に追従し、GUARDの自分対象では四辺の対象枠と対象面を重ねず既存の四隅フォーカスを使う
- **AND** 防御の図形を盤面、手番一覧、詳細と予測で共通化し、スキル名と操作、HELPの説明は維持し、予測を実状態と区別して、各サイズと既存のBACK、Esc、選択、CPUの操作を維持する

#### Scenario: REQ-018-S08 - 周囲の雲と説明

- **GIVEN** 3種類の周囲パッシブ、盤面端と重複、発生源の移動経路と強制移動の予測
- **WHEN** 範囲を表示してホバー、装備とHELPで調べる
- **THEN** セルごとの十字形ではなく、生存発生源を中心に周囲へ漂う連続した控えめな雲をユニットとパネル記号より下へ描き、斜めを含む周囲8マスと本人除外、倍率と停止優先、相殺を説明する
- **AND** 雲は盤外と距離2以上のセルへ広がらず、移動後の予測は薄い破線の雲で現在と区別し、取消、確定と撃破へ追従し、最小から拡大でもHP、各リング、フォーカスと既存のクリックやメニューを妨げず、GUARDの八角形と区別する
- **AND** 時間経過で雲の形と位置がゆっくり変わっても効果範囲と戦闘値は変わらず、動きを抑える設定ではその形を停止する

### Requirement: REQ-019 - 情報と位相予測

画面は現在のターン数、HP陣営合計、行動順ごとに等間隔の独立した点と相対進捗の白い円弧を持つ縦の時間軸と左右の現在状態、選択ユニットのクラスと装備識別名と全スキル、実値に合う簡潔な英語の作用説明、PREVIEW見出しと経路後リング、周囲の円形の揺らぎ、特異点を表示し、陣営ごとのHP数値とバーを同じ段へ収め、装備を種別のアイコンと名称の横並びで示し、情報を囲う装飾を省きながら操作状態を区別し、手番の切替時だけ確認対象を行動者へ戻して予測と詳細を揃えなければならない(SHALL)。

#### Scenario: REQ-019-S01 - 情報の比較

- **GIVEN** 異なる位相になる2経路
- **WHEN** 経路を切り替えて別ユニットを調べる
- **THEN** 予測は手番ユニットを維持し、右詳細は選択ユニットへ切り替わり、円形の揺らぎが配分と位相を反映し、GとAの角度数値、横長波形と角度軸、下端のROUTEからEFFECTへの記載は表示しない

#### Scenario: REQ-019-S03 - 指定文字の非表示

- **GIVEN** 戦闘画面の移動、行動選択、攻撃対象、回復対象、結果の背後のいずれか
- **WHEN** 画面を表示する
- **THEN** 次の文字を表示せず、時間軸、経路の描画と移動、円形予測と特異点、詳細情報と通知の機能を維持し、配置は盤面優先の寸法要件に従う

| 除去する表示 | 範囲 |
| --- | --- |
| PHASE PREVIEW | 見出し |
| PATH X / DESTINATION | 経路長と目的地座標を含む表示全体 |
| ROUTE / PHASE / EFFECT | 左上の補助見出し |
| TURN ORDER | 見出し |
| T / 現在時刻 | 数値を含む表示全体 |
| INSPECT | 見出し |
| INNER / MIDDLE / OUTER | 補助見出し |
| PHASE / TACTICAL STUDY | 左上の説明文字 |
| BOTH SIDES / HUMAN | 右上の説明文字 |
| 行動順の待ち量とACTING、QUEUED | 選択とホバーを含む状態文全体。FINISHEDとDEFEATEDも同領域には表示しない |
| INFとRESの最終同期率 | 予測下の2つの数値表示。代替表示を追加しない |

#### Scenario: REQ-019-S04 - 情報の囲い装飾を省く

- **GIVEN** 戦闘画面の情報と予測が表示されている
- **WHEN** 移動、行動選択、対象選択、結果の背後を表示する
- **THEN** 左右の情報と円形予測、時間軸の全状態、スキル行を囲う外枠と薄い背景を表示せず、情報の内容、同時刻の処理順、既存の文字色とリング、陣営HPの棒を維持し、装備の種別アイコン以外の新しい装飾を加えない
- **AND** 中央バトルマップ、システムメニューと操作ボタンの通常、選択、ホバー、フォーカスの表現と機能は変わらない

#### Scenario: REQ-019-S05 - HPの1段表示

- **GIVEN** PLAYERとENEMYのHP合計
- **WHEN** 戦闘情報を表示する
- **THEN** 各陣営の名前、現在と最大のHP数値、比率のバーが同じ横の段に収まり、欠けずに読める

#### Scenario: REQ-019-S06 - 待ち量と処理順

- **GIVEN** 行動中ユニットの時刻が現在で、同時刻、近接時刻、同ユニットの再登場がある
- **WHEN** 行動順を表示する
- **THEN** 上から行動順に等間隔で1行動1点を置き、同時刻も個別の点に分かれ、各点は1体だけへ接続し、中央にユニット名を表示しない
- **AND** 同時刻は1、2、3、A、B、Cの処理順で並び、同ユニットの再登場も別の点を持ち、白い円弧は1から表示中の最大待ち量に対する残り待ち量の比を引いた相対進捗、残る灰は待ち量を表し、待ちが減るほど白が増える
- **AND** 最大待ち量が0なら全点を白一周とし、最大待ち量が変わると同じ基準で再計算し、個別周期の経過率や実時間と誤認させない
- **AND** 待ち0の白一周でも先頭の中心点で現在手番を識別し、同時刻の後続点は順番待ちとして扱い、状態文や待ち量数値の代替を追加しない

#### Scenario: REQ-019-S07 - 現在状態との対応と独立した選択

- **GIVEN** 未確定経路と左右の状態、未来の節点がある
- **WHEN** 状態か節点をホバーして選択する
- **THEN** 左の味方1と2、右の敵AとBの現在のリング、HPと補正率を該当節点へ接続し、対応状態と盤面ユニットを強調して詳細を切り替える
- **AND** 手番、経路、予測は変えず、未来のHPや位相を現在状態として捏造しない

#### Scenario: REQ-019-S08 - 予定の更新と終了

- **GIVEN** 撃破、行動後の再投入、戦闘終了のいずれかが発生する
- **WHEN** 行動順を再表示する
- **THEN** 撃破したユニットの節点を除き、行動後は新しい現在と待ち量に更新し、終了後は未来の予定を表示しない

#### Scenario: REQ-019-S09 - 右情報の整理

- **GIVEN** 通常または突然変異を持つ選択ユニット
- **WHEN** 右の情報を表示する
- **THEN** CLASS:に続く実際のクラス、現在のリングと中央名、装備中のARMSとGEARの順の種別アイコンと識別名、NORMAL以外の突然変異、移動上限、全スキルの順に表示する
- **AND** 陣営名、重複するHP数値、移動済み数、15個の配分数値と棒、NORMALとACTIVE、PASSIVEの反復を表示せず、右情報と盤面の間に余白がある
- **AND** 移動上限と各スキルには実際の上限、対象と作用に合う短い英語を薄いが読める文字で添え、独立した装備名がない場合は既存の型番を識別名に使い、右情報と盤面やメニューが重ならない
- **AND** GEARはshield、ARMSはswordを名称の前へ横並びに置き、間に余白を取り、突然変異を含む名称を省略せず、枠と背景を表示しない
- **AND** 装備のアイコンと名称は表示専用で、クリック、ホバーとキーボードフォーカスによる操作状態を持たず、選択と経路やメニューの操作を妨げない

#### Scenario: REQ-019-S10 - ターン数の表示

- **GIVEN** 正の現在ターン数、または不正な非正数
- **WHEN** 戦闘情報を表示する
- **THEN** 時間軸の上部にTURNと最低2桁の現在ターン数を表示し、3桁以上は全桁を維持し、不正な非正数はTURN --とし、HPや節点に重ならず、TURNの上にも余白を設け、HP、行動順と予測の3つのまとまりの前後の見える間隔を揃える
- **AND** 行動後は戦闘の現在ターンへ更新し、実時間や時間軸の待ち量をターン数として表示しない

#### Scenario: REQ-019-S11 - 固定幅の補正率

- **GIVEN** 各ユニットの現在のINFとRESの最終補正率
- **WHEN** 時間軸の状態を表示する
- **THEN** IとRの直後にコロンを置き、百分率の整数を各3桁分の固定領域へ右寄せし、%の位置と項目間の間隔を桁数で動かさず、2項目を短い空白で隣り合わせる
- **AND** 表示入力が0以上999以下の有限の百分率なら四捨五入して示し、負数、999を超える値と非数値は3文字の---とし、戦闘値は変更しない
- **AND** 0、一桁、二桁と三桁、選択とホバーでも文字が重ならず、INFとRESの既存の色分類と現在状態を保つ

#### Scenario: REQ-019-S12 - 全体HPの順序

- **GIVEN** 通常、空または最大の有効HPを持つ両陣営
- **WHEN** 戦闘の全体HPを表示する
- **THEN** PLAYERまたはENEMY、比例するバー、現在値と最大値の順に同じ段で表示し、文字とバーは重ならず盤面へはみ出さない

#### Scenario: REQ-019-S13 - 手番と確認対象の追従

- **GIVEN** 別ユニットや未来節点を確認している人の手番、CPUの表示過程、または同じユニットの連続手番
- **WHEN** 実際の手番が切り替わる
- **THEN** 確認対象と古いホバーを解除し、INFORMATIONは新しい手番の現在状態、PREVIEWはそのユニットの実位相と経路予測を示す
- **AND** 同じ手番の間は任意の確認を自動で上書きせず、選択とホバーは経路と予測の行動者を変えず、経路を操作すると既存どおり行動者の情報へ戻る
- **AND** CPUの結果表示中に実手番が進む場合も同じ基準で追従し、停止と補助画面では手番を進めず、RESTARTは古い確認対象を引き継がない

#### Scenario: REQ-019-S14 - 予測の見出し

- **GIVEN** 戦闘の位相予測
- **WHEN** 経路を選択または取消する
- **THEN** 左下にTURNと同じトーンのPREVIEWを表示し、リングと揺らぎ、通知と操作を妨げない

### Requirement: REQ-031 - 味方の表示名

#### Scenario: REQ-031-S01 - 表示と識別子の分離

- **GIVEN** 内部ID01、02、03、A、B、Cを持つユニット
- **WHEN** 名前を表示する
- **THEN** 表示名はそれぞれ1、2、3、A、B、Cとなり、内部IDは元のままである

#### Scenario: REQ-031-S02 - 関連画面の名前

- **GIVEN** BUILD、BATTLE、ACTION、HELPのユニット名と目標の説明
- **WHEN** 画面を切り替える
- **THEN** 味方への参照は1、2、3で統一され、ステージ番号01と02は維持される
