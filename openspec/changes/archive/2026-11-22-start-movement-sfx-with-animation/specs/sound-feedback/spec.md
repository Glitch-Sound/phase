# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-055 - 確定移動の回転音

WHILE 確定した人またはCPUの実移動を表示する間、画面は最初に位置が進むフレームでring_rotate1の再生を要求し、半マス分の間隔でring_rotate2と交互に各マス各1回鳴らし、回転量の変化がなくても適用し、出発前のフェード、計画、取消と0歩では鳴らさず、表示と戦闘の時間を延ばしてはならない(SHALL NOT)。

#### Scenario: REQ-055-S01 - 各歩と実回転の対応

- **GIVEN** 1歩または3歩の確定移動と、回転する歩と回転量の変化がない歩
- **WHEN** 通常速度で移動を表示する
- **THEN** 最初に位置が進むフレームで1音目の再生を要求し、各マスで1、2の順に各1回、合計2回または6回が半マス分の等間隔で鳴り、出発前のフェード、移動の尺と到着を変えない

#### Scenario: REQ-055-S02 - 停止と表示終了の境界

- **GIVEN** 人またはCPUの移動表示、早送り、表示を省く設定または移動なし
- **WHEN** 計画、取消、停止、再開または退出を含む表示更新を行う
- **THEN** 計画と取消、停止中は新しく鳴らず、再開と早送りでも過去の発音を重複させず、表示を省く場合と0歩では音の列を作らず、退出した移動の音を再戦へ持ち越さない
