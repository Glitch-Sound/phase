# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-011 - 能動スキル

WHEN 装備するDAMAGEまたはHEALのACTIVEを選ぶとき、移動を維持して対象選択へ進み、選んだ上下左右1、斜め1、上下左右2、斜め2マス先のいずれかにいる生存敵1体へダメージまたは自分以外の負傷味方1体へ回復を実行して手番を終了しなければならない(SHALL)。

#### Scenario: REQ-011-S01 - 対象とBACK

- **GIVEN** 移動確定後のユニットと敵味方
- **WHEN** スキル選択とBACKを実行する
- **THEN** BACKは位相と位置を保持して行動選択へ戻り、範囲外、陣営違い、全快の回復を拒否する

#### Scenario: REQ-011-S02 - 位置関係と単体作用

- **GIVEN** DAMAGEとHEALそれぞれの4種類の範囲を順に装備できる有効な戦闘
- **WHEN** 移動後に各スキルの対象を選ぶ
- **THEN** 行動者からの差が次の4セルのいずれかである対象1体だけへ、既存のDAMAGEまたはHEALと同じ計算で作用し、他のHPを変えず、作用を完了した手番を終了する
- **AND** 2マス先は1マス先や直線上全体を含まず、途中のユニットの有無で対象条件を変えない

| 範囲 | 有効な座標差 |
| --- | --- |
| 上下左右1 | (0,-1)、(1,0)、(0,1)、(-1,0) |
| 斜め1 | (-1,-1)、(1,-1)、(1,1)、(-1,1) |
| 上下左右2 | (0,-2)、(2,0)、(0,2)、(-2,0) |
| 斜め2 | (-2,-2)、(2,-2)、(2,2)、(-2,2) |

#### Scenario: REQ-011-S03 - 対象と実行の境界

- **GIVEN** 自分、異なる陣営、全快、戦闘不能、範囲外、盤面端の対象と未装備または不明なスキル
- **WHEN** 対象選択または実行を試みる
- **THEN** DAMAGEは生存敵、HEALは自分以外の負傷した生存味方だけを指定範囲内で許可し、不正な対象やスキルはHP、位相、履歴と手番を変えず拒否する
- **AND** 有効な作用はHPを0から最大値へ収め、上下左右1マスの既存ID、MOVE+1とWAIT、BACKの条件を維持する

### Requirement: REQ-012 - 待機と受動移動

各手番は1マス以上移動してからWAITまたはACTIVE1回を使用し、移動不能時だけ無移動WAITを許可し、装備した移動+1とパネル無視を常時適用しなければならない(SHALL)。

#### Scenario: REQ-012-S01 - 待機例外

- **GIVEN** 空き隣接セルのある場合と四方を塞いだ場合
- **WHEN** 無移動で待機する
- **THEN** 前者は拒否され、後者は手番が終了し、受動装備は最大移動数を1増やす

#### Scenario: REQ-012-S02 - パネル無視の移動接続

- **GIVEN** パネル無視を装備し、特殊パネルを通るユニット
- **WHEN** 経路を予測、確定してから行動前に選び直す
- **THEN** COREの特殊効果を無視した予測と確定が一致し、通常の装備回転と移動力を維持し、再選択は実状態を移動前へ戻す

### Requirement: REQ-013 - 勝敗条件

各ステージは勝利と敗北のそれぞれへELIMINATE、TARGET、REACH、OCCUPYを設定可能とし、戦闘不能、通常と強制移動の確定、手番終了の対応する時機に判定して成立直後に終了し、同時成立時は敗北を優先しなければならない(SHALL)。

#### Scenario: REQ-013-S01 - 目標の時機

- **GIVEN** 4種の目標を設定した戦闘
- **WHEN** 対応する契機を発生させる
- **THEN** ELIMINATEとTARGETは撃破時、REACHは確定時、OCCUPYは終了時にだけ結果となる

#### Scenario: REQ-013-S02 - 敗北と除外

- **GIVEN** 最後のPLAYERが戦闘不能になる戦闘
- **WHEN** ダメージを適用する
- **THEN** DEFEATとなり、死亡ユニットのセルは通行可能となる

#### Scenario: REQ-013-S03 - ステージ固有の敗北

- **GIVEN** 敵AのREACHを敗北条件とし、味方02のOCCUPYを勝利条件とした戦闘
- **WHEN** 該当するユニットが条件を満たす
- **THEN** 敵Aの移動確定でDEFEATとなり、味方01の占有では勝利せず、味方02の手番終了でだけVICTORYとなる

#### Scenario: REQ-013-S04 - 同時成立の優先

- **GIVEN** 勝利と敗北の両条件が同じ判定時機に成立する戦闘
- **WHEN** 撃破、移動確定、手番終了それぞれの判定を行う
- **THEN** いずれもDEFEATとなり、後の判定で結果は変わらない

#### Scenario: REQ-013-S05 - 強制移動の到達と優先

- **GIVEN** 行動者以外の到達役と両陣営の到達目標、または占有目標がある戦闘
- **WHEN** SWAPまたはPUSHを確定する
- **THEN** 位置と角度を全員分確定した後、強制移動した生存者全員のREACHを一度判定し、同時成立は敗北を優先する
- **AND** OCCUPYは行動者の手番終了で判定し、移動で終局した場合は追加の行動や時刻更新をせず、一度決まった結果を変えない

## ADDED Requirements

### Requirement: REQ-037 - 味方との位置交換

WHEN 移動後に装備したSWAPを実行するとき、行動者は上下左右の隣接する生存味方1体と位置を交換し、両者へ到着先への通常1歩とパネルを適用して手番を終了し、HP、既存の防御状態、相手の確定済み時刻と両者の移動数は変更してはならない(SHALL NOT)。

#### Scenario: REQ-037-S01 - 交換と位相

- **GIVEN** 隣接味方と異なる到着パネル、パネル無視の有無を持つ有効な戦闘
- **WHEN** SWAPを予測して確定する
- **THEN** 予測は原本を変えず、両者の位置と1歩分の装備角、パネル後のCORE角が確定と一致し、パネル無視は本人だけへ適用され、HPと防御状態を保持して1行動を完了する

#### Scenario: REQ-037-S02 - 交換の境界

- **GIVEN** 敵、自分、戦闘不能、斜めまたは非隣接の相手、未装備のSWAP
- **WHEN** 選択または実行を試みる
- **THEN** 不正な交換は位置、角度、HP、時刻、履歴と手番を変えず拒否し、対象選択のBACKや経路の再選択では交換を適用しない

### Requirement: REQ-038 - 敵の押し出し

WHEN 移動後に装備したPUSHを実行するとき、行動者は上下左右の隣接する生存敵1体を行動者と反対方向の盤内の空きセルへ1マス押し、対象へ到着先への通常1歩とパネルを適用して手番を終了し、ダメージ、連鎖押しと盤外移動を発生させてはならない(SHALL NOT)。

#### Scenario: REQ-038-S01 - 押す位置と位相

- **GIVEN** 隣接敵の外側に空きセルがあり、特殊パネルと防御状態を持つ戦闘
- **WHEN** PUSHを予測して確定する
- **THEN** 対象だけが外側1マスへ動き、1歩分の装備回転と本人の受動に従うCORE角が予測と一致し、HP、防御状態、対象の時刻と移動数を保持して1行動を完了する

#### Scenario: REQ-038-S02 - 押し先の境界

- **GIVEN** 押し先が盤外、生存占有、戦闘不能だけの占有である場合、または敵でない対象
- **WHEN** PUSHを試みる
- **THEN** 盤外、生存占有と敵でない対象は副作用なく拒否し、戦闘不能だけの押し先は空きとして許可し、連鎖押しをしない

### Requirement: REQ-039 - 1回の防御

WHEN 移動後に装備したGUARDを実行するとき、行動者は次に受けるDAMAGEを設定された率で軽減する防御状態を自分へ1回だけ付与して手番を終了し、防御済みへの重ね掛けは拒否し、防御状態は次の攻撃を受けた時だけ消費して新しい戦闘へ引き継いではならない(SHALL NOT)。

#### Scenario: REQ-039-S01 - 防御の付与と消費

- **GIVEN** 自分と他者、装備したGUARDと攻撃、回復
- **WHEN** 自分へGUARDを実行して次の攻撃を受ける
- **THEN** 自分だけが防御状態となりHPを変えず行動を終了し、次のDAMAGEだけを設定率で軽減して消費し、軽減後が0の攻撃でも消費する
- **AND** 他者、未装備と防御済みへの使用は副作用なく拒否し、消費後は再び付与できる

#### Scenario: REQ-039-S02 - 防御の持続と取消

- **GIVEN** 防御状態のユニットと移動、回復、WAIT、交換、押し出し
- **WHEN** 攻撃以外の操作と取消、手番交代を行い、その後に戦闘を再開する
- **THEN** 防御は攻撃以外では消費せず、移動の再選択や対象BACKで重複付与せず、手番を跨いで保持し、新しい戦闘では全員の防御が解除される
