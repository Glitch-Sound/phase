# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-016 - 保存と読込

WHEN SAVEまたはLOADを選ぶとき、3枠の名前、ユニットとアセンブリの紋章方式の版、アセンブリ名と安定した色キー、ビルド、共有開放一覧とステージを検証して保存または復元し、破損、不正、未知版、欠落は現在データを変えず報告し、名前とアセンブリを含む新規形式だけを受け付け、旧形式を移行せず、読込元を自動で書き換えず、再保存では既存保存をバックアップしなければならない(SHALL)。

#### Scenario: REQ-016-S01 - 保存往復

- **GIVEN** 編集したビルドと開放一覧
- **WHEN** 保存して別の状態へ読み込む
- **THEN** 3枠の名前、アセンブリ名と色キー、それぞれの紋章方式の版、全構成が復元され、再保存では以前の保存が別名で残る

#### Scenario: REQ-016-S02 - 不正入力

- **GIVEN** 欠落、破損JSON、未知版、不正な配分のファイル
- **WHEN** ロードする
- **THEN** エラーを返し、現在ビルドと開放一覧を変更しない
