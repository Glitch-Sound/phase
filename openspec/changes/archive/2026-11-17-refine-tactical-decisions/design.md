# 設計

## 背景と制約

openspec/tech.mdの決定性、保存境界と表示原則を使う。
現在のcommit_pathは行動前に位置と角度と移動履歴を確定し、backはTARGETからCHOICEへのみ戻る。
復元と効果の再実行を別々のUI入口へ散らさず、モデルの一つの操作へ集約する。

## 設計判断

### D-01 - 行動前だけ確定移動を復元する

- 選択: commit_pathの直前に行動者の全ユニット辞書、経路、手番、行動者番号と履歴長を保持する。\
  reselect_pathは非終局のCHOICEで同じ手番のときだけ、辞書を復元し移動履歴を除き、元の経路をMOVEへ戻す。\
  復元した経路は予測だけに使い、再確定時だけ通常のパネル処理を適用する。\
  next_actorと新規開始は復元情報を破棄し、TARGETのbackは今までの意味を保つ。\
  行動選択へBACKを追加し、Escも同じ入口へ接続する。\
  CPUの表示中は既存の入力保護を維持し、終局と報酬の確定後は復元しない。
- 理由: HP、時刻、CORE基準角と全角度の巻き戻し漏れやパネル二重適用を防ぐ。
- 代替案: 角度を逆算する方法と経路を即座に再適用する方法は、RESETの順序と開始基準を壊すため使わない。
- 昇格: openspec/tech.md の 技術上の判断基準。

~~~mermaid
stateDiagram-v2
  state "経路予測" as MOVE
  state "行動選択" as CHOICE
  state "対象選択" as TARGET
  state "次の手番" as NEXT
  state "終局" as RESULT
  MOVE --> CHOICE: 移動確定
  CHOICE --> MOVE: BACKとEscで復元
  CHOICE --> TARGET: ACTIVE
  TARGET --> CHOICE: 従来のBACK
  TARGET --> NEXT: スキル実行
  CHOICE --> NEXT: WAIT
  MOVE --> RESULT: 到達成立
  TARGET --> RESULT: 撃破成立
  CHOICE --> RESULT: 占有成立
~~~

到達でRESULTになった移動と、WAITまたはスキル実行後は戻れない。
行動選択から戻ると経路を保持するが、原本の位置と角度は移動前へ戻る。
RESTARTは復元情報を破棄する。

### D-02 - 上限を変えず補正曲線だけを狭める

- 選択: 従来のINFとRESのsigmaへ共通倍率SYNC_SIGMA_SCALE=0.90を掛け、game/tuning.gdの1か所へ定義する。\
  LUK許容角、三重とペアの干渉、中間値、入力の0から1への丸め、最終10から200%の範囲、特異点と基本威力は維持する。\
  sigmaのLUK依存とRESの広い許容を保つ。\
  旧幅0.60と0.70から通常LUK20では0.54と0.63になる。\
  配分20の完全同期は攻撃30と回復48のまま、低一致の攻撃と回復は少し下がり、低RESへの攻撃はやや増える。\
  同一ビルドと配置のモデル対戦と通常のCPU一戦を比較し、観察と主観を区別して評価する。
- 理由: 最大火力と最大回復を直接増やさず、経路の良否と攻撃時の危険に差を付ける。
- 代替案: 最大倍率の引上げ、特異点強化、回復規則とCPU評価の同時変更は原因を切り分けられないため使わない。
- 昇格: なし。

### D-03 - 盤面の行動者だけに形の印を置く

- 選択: 非終局のbattle.actorのセルの右下へ純白の小さな右向き三角を描く。\
  game/tuning.gdのUNIT_ACTOR_MARKERへ70px基準の頂点(56,57)、(56,65)、(64,61)を置き、盤面と同じ倍率を使う。\
  角度の目盛り、HPの円弧、選択とホバーの角枠は維持し、陣営の色は変更しない。\
  三角をリングと軸方向の経路から離し、セル内と既存の角枠の内側に収める。\
  CPU結果の間に次の手番が決まっている場合も、タイムラインと同じ実行中のbattle.actorに対応する。
- 理由: 囲いや背景を増やさず、色に依存しない固有の形で現在手番を見つけられる。
- 代替案: HPと混同する円弧、全セルの塗り、点滅と大きな発光は使わない。
- 昇格: なし。

## リスクと移行

補正変更はCPUの合法な選択と攻略の結果にも波及するため、旧版と同じシード、ビルドで比較する。
既存の固定された効果量と操作集合の期待値は承認済みの変更に直接関係するものだけ更新し、結果を通すために検査を弱めない。
最大威力は増やさないが低RESの防御低下は増幅するため、低、中、高の攻防とHP割合を分けて確認する。
任意の極端なビルドの一撃と全局面の停滞不在を保証せず、確認した範囲を報告する。
実データの保存先を検証用へ切り替え、実セーブと配色を保存しない。
