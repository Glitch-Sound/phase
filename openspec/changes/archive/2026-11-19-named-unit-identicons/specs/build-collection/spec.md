# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-016 - 保存と読込

WHEN SAVEまたはLOADを選ぶとき、3枠の名前、紋章方式の版とビルド、共有開放一覧とステージを検証して保存または復元し、破損、不正、未知版、欠落は現在データを変えず報告し、名前を含む新規形式だけを受け付け、旧形式を移行せず、読込元を自動で書き換えず、再保存では既存保存をバックアップしなければならない(SHALL)。

#### Scenario: REQ-016-S01 - 保存往復

- **GIVEN** 編集したビルドと開放一覧
- **WHEN** 保存して別の状態へ読み込む
- **THEN** 3枠の名前と紋章方式の版、全構成が復元され、再保存では以前の保存が別名で残る

#### Scenario: REQ-016-S02 - 不正入力

- **GIVEN** 欠落、破損JSON、未知版、不正な配分のファイル
- **WHEN** ロードする
- **THEN** エラーを返し、現在ビルドと開放一覧を変更しない

### Requirement: REQ-026 - 初期スキルの収集余地

WHEN 新規ゲームを開始するとき、上下左右1マスのDAMAGEとHEALは使用可能、MOVE+1と斜め1、上下左右2、斜め2マスのDAMAGEとHEAL、SWAP、PUSH、GUARD、パネル無視、減速と加速の周囲効果は未開放とし、戦闘後に取得すると共有して装備可能にし、有効な現行保存の開放済みスキルは維持しなければならない(SHALL)。

#### Scenario: REQ-026-S01 - 初期状態と取得

- **GIVEN** 新しいゲーム
- **WHEN** 初期構成を確認してMOVE+1を戦利品から取得する
- **THEN** 取得前は両PLAYERが移動+1を持たず、取得後は双方のビルドへ使用できる

#### Scenario: REQ-026-S02 - 既存開放状態

- **GIVEN** 3スキルを開放済みの現行セーブ
- **WHEN** 読み込む
- **THEN** 3スキルが開放された状態を維持する

#### Scenario: REQ-026-S03 - 追加スキルの取得と互換性

- **GIVEN** 初期状態、追加6種を取得した状態、または既存3種を開放済みの現行保存
- **WHEN** 取得、構成と保存の往復を行う
- **THEN** 新規状態では旧2種だけを装備し、追加6種は未開放候補として入手でき、取得後は両PLAYERが重複しない最大3枠へ装備できる
- **AND** 新旧のIDと開放、構成を保持して現行形式で往復でき、現行保存の読込だけで追加品を解放や自動装備せず、未開放と重複を拒否する

#### Scenario: REQ-026-S04 - 位置操作と防御の取得

- **GIVEN** 新規状態、追加4品の取得後、既存3種または9種を開放済みの現行保存
- **WHEN** 取得と共有装備、保存と読込を行う
- **THEN** 追加4品は未開放候補から取得して両PLAYERの既存3枠へ装備でき、未開放と重複を拒否し、旧開放と構成を保持し、読込だけで追加品を解放しない
- **AND** 戦闘中の防御状態と一時予測をビルド保存へ含めない

#### Scenario: REQ-026-S05 - 周囲パッシブの収集

- **GIVEN** 新規状態、周囲の2品を取得した状態、既存13品までの現行保存
- **WHEN** 取得、共有装備と保存の往復を行う
- **THEN** SLOW FIELDとFAST FIELDの2品は初期未開放で戦利品から取得でき、両PLAYERの既存3枠へ共有でき、未開放と重複装備を拒否し、現行形式でIDと構成を保持し、STOP FIELDを通常、全解放と未解放候補、報酬へ含めない
- **AND** 現行保存を読んでも自動開放と自動装備をせず、雲や範囲内の一時状態を保存しない
