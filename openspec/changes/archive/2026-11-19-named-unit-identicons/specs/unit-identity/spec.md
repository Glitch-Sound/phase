# 差分仕様

## Purpose

編集する名前と戦闘の不変識別子を分離し、同じ文字列から端末と起動をまたいで再構成できる小さな円形紋章を提供する。
入力と保存、表示の契約を一貫させ、同名でも戦術操作を保つ。

## ADDED Requirements

### Requirement: REQ-047 - 名前の入力規約

WHEN 名前を入力するとき、版1の規約はUnicodeを受け付け、定義済みの空白をASCII空白へまとめて前後を除き、制御と方向制御の文字を除去し、先頭32コードポイント以内へ制限して末尾空白を除き、大文字小文字とUnicode合成を変えず、空欄は枠の既定名として解決し、名前を装飾構文として解釈してはならない(SHALL NOT)。

#### Scenario: REQ-047-S01 - 正規化と境界

- **GIVEN** 日本語と結合文字、前後と連続空白、改行と制御、空欄、32文字を超える名前と装飾記号
- **WHEN** 名前を正規化して表示と保存へ渡す
- **THEN** 固定規約の同じ文字列が得られ、先頭32コードポイントを超えず、空欄は対応枠の既定名となり、装飾記号はプレーンテキストとして残る

### Requirement: REQ-048 - 版付きの円形紋章

WHEN ユニット名を表示するとき、解決した名前を版1の固定接頭辞とUTF-8でSHA-256へ渡し、固定の幾何生成規約から円内の少数の対称な形を得て、端末、時刻、乱数とフォントに依存せず再構成可能にし、紋章を識別子または唯一性の保証として使ってはならない(SHALL NOT)。

#### Scenario: REQ-048-S01 - 固定ベクトルと幾何

- **GIVEN** 英語と日本語の固定名と同じ名、同じ版
- **WHEN** ハッシュと紋章を再構成する
- **THEN** 固定ベクトルと同じハッシュと幾何パラメーターとなり、全点が円内に収まり、入力と戦闘を変更せず、別起動と異なる保存経路でも同じ結果となる

#### Scenario: REQ-048-S02 - 小さい紋章の実描画

- **GIVEN** 味方と敵、最小と基準画面、異なるHPと位相、GUARDと攻撃回復
- **WHEN** BUILDと盤面、タイムラインと詳細、予測を実描画する
- **THEN** 名前に対応する同じ紋章を識別でき、円内の余白を保ち、陣営と枠、白いHPと位相、手番と既存演出を覆わず、長い名前を盤面へ展開しない

### Requirement: REQ-049 - 名前の編集プレビュー

WHEN BUILDで編集可能なPLAYER枠を選ぶとき、コンパクトな名前欄と即時の紋章プレビューを使え、通常の明示SAVEとLOADで枠ごとの名前と方式の版を保存し、同名と一時全解放の編集を独立させ、未編集の敵には固定名を与えなければならない(SHALL)。

#### Scenario: REQ-049-S01 - 編集と取消と保存境界

- **GIVEN** 3つの編集枠、同名と長い入力、一時全解放と通常データ
- **WHEN** 入力し、EnterとTabで確定、Escで現在の編集を戻し、隔離先へ保存と別起動の読込を行う
- **THEN** 編集中は同じ枠のプレビューだけが即時に変わり、Escは編集開始時の値へ戻し、確定値だけを現行形式で復元し、通常と一時の名前を混ぜず、キー入力を盤面と別モーダルへ漏らさない

#### Scenario: REQ-049-S02 - 名前欄と長い表示の実描画

- **GIVEN** 初期名と架空の日本語、長い名前、標準と最小サイズ
- **WHEN** BUILDで入力し、戦闘とHELPへ遷移して選択する
- **THEN** 名前と紋章の対応、入力とキーボードフォーカス、取消と全文の詳細表示を確認でき、通常の編集と戦闘のクリック領域を塞がない
