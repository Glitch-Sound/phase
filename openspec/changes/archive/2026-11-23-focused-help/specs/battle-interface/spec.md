# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-018 - 経路入力表示

画面は経路番号、ユニットのリングと重ならないノード間の線、設定したアクセント色の終点、対象範囲、有効対象、選択、ホバーをセルの枠上で強調して表示し、パネル効果は文字の略号でなく意味の異なるアイコンで示し、ホバーで意味を確認でき、戦闘中の現在手番と防御状態を盤面で色だけに頼らず識別できなければならない(SHALL)。

#### Scenario: REQ-018-S01 - 経路操作

- **GIVEN** 移動状態の戦闘画面
- **WHEN** 経路追加、取消、ダブルクリック、対象選択を操作する
- **THEN** 番号と終点が追随し、行動選択とBACKが動作する

#### Scenario: REQ-018-S02 - 経路とリングの分離

- **GIVEN** ユニットから上下左右へ進む経路と、最小、標準、拡大された表示領域
- **WHEN** 経路を表示する
- **THEN** 線の端は起点や終点にあるユニットの記号の外側にあり、線幅を含めて色リングとHP円弧や目盛りに重ならず、経路番号と終点は維持される
- **AND** 線を引ける余白がない区間や長さ0の区間では線を描かず、経路や戦闘状態は変更しない

#### Scenario: REQ-018-S03 - パネルのアイコンと確認

- **GIVEN** RESET、CLOCKWISE、COUNTERCLOCKWISEとNORMALのパネル
- **WHEN** 盤面を表示して効果を調べる
- **THEN** 特殊パネルには順に塗りのない単純なひし形、時計回り、反時計回りの区別できるアイコンを表示し、旧効果のアイコンとS+、L=、R-の略号は残さず、NORMALには効果アイコンを表示しない
- **AND** ホバーでCOREの戦闘開始角へのリセット、COREのSPDに基づく正逆回転と、全セルでGEARとARMSの通常回転を維持することが分かる
- **AND** 最小と拡大でアイコンを区別でき、ホバーの確認は経路、対象とクリックを妨げない
- **AND** ホバー説明は短い英語の概要と薄い補足の2段とし、アイコンとフォーカスを隠さない

#### Scenario: REQ-018-S04 - セル境界の強調

- **GIVEN** 効果記号のあるセル、隣接セルまたは盤面端のセル
- **WHEN** ユニットの選択、ホバー、経路終点または行動対象を表示する
- **THEN** 操作対象の強調枠はセルの枠上に収まり、効果記号と交差せず、隣のセルの枠と区別でき、拡縮後も切れずに操作対象へ対応する
- **AND** 目標セルの印と操作、経路と効果は変わらない

#### Scenario: REQ-018-S05 - 盤面の現在手番

- **GIVEN** 人またはCPUの手番と、別ユニットの選択またはホバー、最小から拡大の画面と変更色
- **WHEN** 移動、行動選択、対象選択、手番交代と終局を表示する
- **THEN** 通常の手番開始時は生存する手番ユニットのセルへ移動先と同じ既存の角枠を表示し、白い三角と独自の枠は表示しない
- **AND** 経路編集中は既存の終点枠、任意の確認中は選択枠を優先し、ホバーと対象範囲の既存表現と操作を維持し、終局では手番の枠を表示しない
- **AND** 角枠はセルの枠上に収まり、リング、効果アイコンと隣接セルの識別やメニューを妨げない

#### Scenario: REQ-018-S06 - スキル範囲の識別

- **GIVEN** 4種類のDAMAGEとHEAL、移動後の行動選択と盤面端
- **WHEN** スキルを表示して対象を選ぶ
- **THEN** BUILDと情報、行動選択で作用と位置関係を区別でき、対象状態では指定範囲の盤内セルだけを示し、有効対象と効果量の符号と陣営を正しく強調する
- **AND** 無効対象だけの行動を選べず、BUILDと戦闘の説明は上下左右と斜め、正確な1マス先と2マス先を区別し、最小と拡大でも文字と操作が欠けず、BACKとEsc、移動、手番とCPUの操作を維持する

#### Scenario: REQ-018-S07 - 位置操作と防御の識別

- **GIVEN** 新しい4品を持つBUILDと戦闘、SWAPとPUSHの有効、無効な対象とGUARD状態
- **WHEN** 装備、行動と対象を選び、説明と予測を確認する
- **THEN** 名前と短い効果を区別でき、無効な行動は選べず、有効対象のホバーまたはCPU対象表示で強制移動先と変化後のリングを原本を変えず確認できる
- **AND** 新しい作用をダメージや回復の数値として表示せず、防御状態と対象上の発動はGUARDの文字や小さな盾の代わりに薄い多角形をリングへ重ね、HPと各リング、中央名を遮らず、解除と対象取消に追従し、GUARDの自分対象では四辺の対象枠と対象面を重ねず既存の四隅フォーカスを使う
- **AND** 防御の図形を盤面、手番一覧、詳細と予測で共通化し、スキル名と操作、BUILDと戦闘の説明は維持し、予測を実状態と区別して、各サイズと既存のBACK、Esc、選択、CPUの操作を維持する

#### Scenario: REQ-018-S08 - 周囲の雲と説明

- **GIVEN** SLOW FIELDとFAST FIELDの周囲パッシブ、盤面端と重複、発生源の移動経路と強制移動の予測
- **WHEN** 範囲を表示してホバーと装備で調べる
- **THEN** セルごとの十字形ではなく、生存発生源を中心に周囲へ漂う連続した控えめな雲をユニットとパネル記号より下へ描き、斜めを含む周囲8マスと本人除外、倍率と同種の重複なし、相殺を説明し、廃止したSTOP FIELDを選択、詳細、ホバーとHELPへ表示しない
- **AND** 雲は盤外と距離2以上のセルへ広がらず、移動後の予測は薄い破線の雲で現在と区別し、取消、確定と撃破へ追従し、最小から拡大でもHP、各リング、フォーカスと既存のクリックやメニューを妨げず、GUARDの八角形と区別する
- **AND** 時間経過で雲の形と位置がゆっくり変わっても効果範囲と戦闘値は変わらず、古い動きを抑える設定が残っていても通常の動きを続ける
- **AND** 確定した通常移動では移動者自身の雲だけを出発前に透過させて移動中は隠し、着地で再表示し、静止する他ユニットの雲と実際の周囲効果は変えず、0歩と取消では雲を消さない

### Requirement: REQ-020 - システム操作

画面はHELP、SETTINGS、RESTART、QUITを備え、HELPをステータスの色付き表、同一ユニットの移動前後のリング比較、戦闘後のランダム解放の一文の3点だけに絞り、操作とスキルの解説を置かず、設定でウィンドウとフルスクリーンを切り替え、戦闘中は4つをこの順の2列2段で盤面右下へ置き下端を盤面と揃え、RESTARTでBUILDへ戻り、DISPLAYの実際の選択を持続して示し、REDUCED MOTIONを表示と演出制御から除き、指定された言語と配色の補足説明を除いて設定を詰め、単独実行では確定した明示表示モードを保存と復元し、エディター埋め込みでは非対応の切替を無効として説明しなければならない(SHALL)。

#### Scenario: REQ-020-S01 - システムメニュー

- **GIVEN** 起動したゲーム
- **WHEN** 各メニューを操作する
- **THEN** HELPが開閉し、表示モードが変わり、RESTARTでBUILDに戻り、QUITで終了する
- **AND** 戦闘ではHELPとSETTINGS、RESTARTとQUITの2列2段で盤面右下へ並び、下端が盤面と揃い、BACKとWAITに重ならない
- **AND** DISPLAYは実モードに対応する1項目だけを選択表示し、ホバーとキーボードフォーカスを外しても維持し、切替と再表示で追随し、COLORの見出しは他の見出しと揃えて上へ余白を置き、日英でREDUCED MOTIONを表示しない

#### Scenario: REQ-020-S02 - 表示設定の保存境界

- **GIVEN** 単独実行と隔離した表示設定
- **WHEN** 表示モードを選ぶ
- **THEN** 実モードが選択と一致して安定した後だけ保存し、再起動で復元し、非同期復元中の古い実状態で保存値を上書きしない
- **AND** 未設定と不明な値はWINDOWEDとして扱い、明示操作前には書き込まない

#### Scenario: REQ-020-S03 - 埋め込みの制約

- **GIVEN** エディター埋め込みで実行したゲーム
- **WHEN** SETTINGSを開く
- **THEN** 表示切替は非活性で制約の説明があり、未適用のFULLSCREENを選択済みとして示さず、保存値を上書きしない

#### Scenario: REQ-020-S04 - 3点だけのHELP

- **GIVEN** 英語または日本語、既定またはカスタムのステータス色、BUILDまたは戦闘
- **WHEN** HELPを開閉する
- **THEN** VITの最大HP、INFの攻撃と回復、RESの抵抗、SPDの手番間隔と回転量、LUKの位相許容幅を実際の色とラベルの表で説明し、同じユニットの移動前後を実計算のリング図で比較し、通常戦闘は勝敗にかかわらずランダム解放があり得ることを一文で示す
- **AND** 説明はその3点だけとし、WAITと操作手順、スキルとFIELDの解説や専用画面への導線を残さず、CLOSEとEsc、英日切替、最小と標準の可読性、戻った戦闘状態を維持する

### Requirement: NREQ-002 - 静かな情報階層

BUILD、BATTLE、行動選択、RESULT、HELP、SETTINGSはGodot 4.7系の1920x1080基準と1440x810表示で深い黒の一貫したUIを表示し、走査線とランダムな装飾を用いず、操作用のLucideアイコンに意味の分かるラベルを添え、パネル効果は盤面の略号を省いてホバーで説明し、選択とフォーカスと勝敗を形または文字でも区別し、モーダル内でキーボードフォーカスを循環させ、閉じたら元の操作へ戻し、既存の戦略情報を保持しなければならない(SHALL)。

#### Scenario: NREQ-002-S01 - 全画面の実表示

- **GIVEN** 既定色と変更した配色のゲーム
- **WHEN** BUILD、BATTLE、行動選択、RESULT、HELP、SETTINGSを表示する
- **THEN** 黒基調の共通表現となり、アイコンの操作ラベル、選択とフォーカスの下線、勝敗文字、HP、装備5値、位相予測を読める

#### Scenario: NREQ-002-S02 - アイコン同梱

- **GIVEN** プロジェクトをオフラインで起動できる環境
- **WHEN** 操作部品を生成する
- **THEN** 同梱したLucideアイコンとラベルを表示し、出典とISCおよび該当するMITの権利表示を配布物に含める

#### Scenario: NREQ-002-S03 - モーダルのフォーカス

- **GIVEN** BUILD、HELP、SETTINGS、行動選択、RESULTのいずれか(フォーカス復帰後を含む)
- **WHEN** TabとShift+Tabで操作部品を移動する
- **THEN** 表示中モーダルの有効な部品だけにフォーカスが移り、補助画面を閉じると元の操作部品へ戻る

#### Scenario: NREQ-002-S06 - 囲いに頼らない階層

- **GIVEN** 既定色または変更した配色と最小、基準、拡大された画面
- **WHEN** BUILD、行動選択、RESULT、HELP、SETTINGSを表示して操作する
- **THEN** パネルを囲う枠と細かな部品の常時の囲いを使わず、黒基調の余白と文字の強弱で情報を区別し、行動選択のパネルをアクセント色で囲わない
- **AND** ボタンと入力欄の操作可能性、ホバー、選択、無効状態とキーボードフォーカスを識別でき、行動選択の背後の戦術情報を読める

### Requirement: REQ-044 - 英語のユーザー向け表示

画面は利用者が入力した名前を翻訳せずプレーンテキストとし、タイトル、見出し、スキルと装備の名称、機械的なラベルを英語に保ち、BUILD、候補選択、戦闘、行動と結果、HELPと設定、パネルと周囲効果の説明、保存の通知を選択された英語または日本語で表示し、HELPでステータス表、移動による位相の変化、戦闘後のランダム解放だけを説明し、STARTのラベルをボタン中央へ配置しなければならない(SHALL)。

#### Scenario: REQ-044-S01 - 全画面の英語と操作

- **GIVEN** 英語を選択した通常と全解放、3体の構成と戦闘、成功と不正操作
- **WHEN** 画面と各補助説明を確認する
- **THEN** 入力された名前と言語選択の表記を除く英語モードの表示に日本語を含まず、HELPから指定された3点の説明を読め、STARTのラベルが中央にあり、戻ると既存の状態と操作を維持する
