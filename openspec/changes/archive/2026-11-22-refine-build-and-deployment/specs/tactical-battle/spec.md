# 差分仕様

## ADDED Requirements

### Requirement: REQ-060 - 再現可能な初期配置

WHEN 戦闘を開始するとき、ゲームは同じシードと入力から同じ初期位置とパネルを作り、通常の新規戦闘では新しいシードを選び、各陣営を設定した小さな範囲へまとめて陣営間の距離を保ち、盤内の異なるセルへ置き、各ユニットに空き隣接先を残し、開始位置を特殊パネルから除外して目標の守備と初手での達成防止を維持し、配置後の戦闘計算に乱数を使ってはならない(SHALL NOT)。

#### Scenario: REQ-060-S01 - シードと独立性

- **GIVEN** 同じ構成とシード、異なるシード、通常の新規戦闘
- **WHEN** 戦闘を開始する
- **THEN** 同じ入力では初期位置とパネルが一致し、異なるシードと通常の新規開始には複数の配置が生じ、他の乱数と保存を変更せず、戦闘中に配置を作り直さない

#### Scenario: REQ-060-S02 - まとまりと移動先

- **GIVEN** 各ステージの両陣営3体
- **WHEN** 初期位置を決める
- **THEN** 6体は盤内で重複せず、同じ陣営は設定した範囲へ収まり、両陣営には設定した距離があり、全員に空きの上下左右の移動先があり、開始セルに特殊パネルがない

#### Scenario: REQ-060-S03 - 目標と開始条件

- **GIVEN** TARGET、REACHとOCCUPYの目標
- **WHEN** 初期配置で戦闘を開始する
- **THEN** 固有IDと目標を維持し、目標上の守備役を保ち、開始直後の終局と初手の到達による達成を防ぎ、移動力と戦闘値、手番の計算を変更しない
