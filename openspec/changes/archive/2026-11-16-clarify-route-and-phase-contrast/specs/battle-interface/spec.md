# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-018 - 経路入力表示

画面は経路番号、ユニットのリングと重ならないノード間の線、設定したアクセント色の終点、対象範囲、有効対象、選択、ホバーを表示し、HELPで最終セルのダブルクリックを知らせなければならない(SHALL)。

#### Scenario: REQ-018-S01 - 経路操作

- **GIVEN** 移動状態の戦闘画面
- **WHEN** 経路追加、取消、ダブルクリック、対象選択を操作する
- **THEN** 番号と終点が追随し、行動選択とBACKが動作する

#### Scenario: REQ-018-S02 - 経路とリングの分離

- **GIVEN** ユニットから上下左右へ進む経路と、最小、標準、拡大された表示領域
- **WHEN** 経路を表示する
- **THEN** 線の端は起点や終点にあるユニットの記号の外側にあり、線幅を含めて色リングとHP円弧や目盛りに重ならず、経路番号と終点は維持される
- **AND** 線を引ける余白がない区間や長さ0の区間では線を描かず、経路や戦闘状態は変更しない

### Requirement: REQ-030 - ユニットの円弧表示

画面はユニットを外枠のない細いCORE、GEAR、ARMSの3リング、領域間の隙間、内側の純白のHP円弧、中央の名前で表示し、HP比率、位相、設定色、選択状態を判別可能にし、盤面の記号をセル中央に収めなければならない(SHALL)。

#### Scenario: REQ-030-S01 - 共通の構造

- **GIVEN** 盤面、予定手番、詳細、予測、BUILDのユニット
- **WHEN** ユニットを表示する
- **THEN** CORE、GEAR、ARMSの順で内から外へ細い色付き円弧を表示し、各領域の境目に隙間があり、外周を囲む枠線がなく、名前が中央にある

#### Scenario: REQ-030-S02 - HPの増減と境界

- **GIVEN** 最大HPが100のユニット
- **WHEN** HPを表示する
- **THEN** 3リングの内側の純白の円弧が配色に依存せず次の比率を表し、名前と他の線の色は変わらない

| HP | 円弧の比率 |
| --- | --- |
| 0 | 0% |
| 50 | 50% |
| 89 | 89% |
| 100 | 100% |

#### Scenario: REQ-030-S03 - 実表示での判別

- **GIVEN** 味方と敵、選択と非選択、既定色と変更色、最小ウィンドウと基準画面
- **WHEN** Godotでユニットを表示する
- **THEN** 3リングの境目、白いHP円弧、中央の名前、選択状態を区別でき、ユニット記号はセル内に収まる

#### Scenario: REQ-030-S04 - セル中央への配置

- **GIVEN** 境界セルと隣接セルにいるユニット
- **WHEN** 盤面のユニットを表示する
- **THEN** 各記号の中心はセルの幾何学的な中央に一致し、色リング、HP、名前、目盛りはそのセル内に収まり、隣接セルへ重ならない

### Requirement: REQ-033 - 円形の位相予測

WHILE 経路後の位相を予測する間、画面は3リングを維持して周囲へCORE、GEAR、ARMSと最終重なりの4輪郭を共通の半径付近で重ねて表示し、実際の領域境界の色をグラデーションで接続し、実際の配分と回転に沿う色分類と形、同じステータスの一致が多いほど鮮明な色で局所的な重なりを表し、時間や乱数で変形させず、戦闘式と保存内容を変更せずに経路と配色へ追随しなければならない(SHALL)。

#### Scenario: REQ-033-S01 - 局所的な一致

- **GIVEN** 各ステータスが20ずつの3リング
- **WHEN** VIT領域の中央に相当する同じ角度を表示する
- **THEN** 位相の組み合わせに応じて次の重なりとなり、一致が多いほど結果の色が鮮明になり、不一致の輪郭も黒背景から区別できる

| COREの位相 | GEARの位相 | ARMSの位相 | 重なり |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 3つのVITが一致 |
| 0 | 0 | 72 | COREとGEARのVITだけが一致 |
| 0 | 72 | 144 | 同じステータスの一致がない |

#### Scenario: REQ-033-S02 - 決定的な更新

- **GIVEN** 有効な配分と突然変異、回転角、カスタム色を持つ予測
- **WHEN** 予測を表示する
- **THEN** 全周の色分類と形が実際の領域を反映して閉じ、同じ入力では同じ4輪郭になり、経路と配色の変更時に更新され、入力の状態と保存は変化しない

#### Scenario: REQ-033-S03 - 実表示の比較

- **GIVEN** 一致する位相とずれた位相、既定と変更した配色、基準と最小の画面
- **WHEN** Godotで予測を比較する
- **THEN** 内側の3リングとHP、周囲の4輪郭を区別でき、リング下のINFとRESの最終同期率は表示せず、拡大マップと左右の情報が重ならず、経路の選択と対象への操作を続けられる

#### Scenario: REQ-033-S04 - 重なる輪郭と境界の連続色

- **GIVEN** 同じステータス配分で一致または不一致となる位相と有効な配色
- **WHEN** 円形予測を表示する
- **THEN** 4輪郭が近い半径で重なり、各色領域の中央では指定色を保ち、境界では隣接する実際の色へ連続的につながり、完全一致の輪郭は不一致より鮮明で、同期率と戦闘状態を変えない
