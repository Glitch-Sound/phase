# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-062 - Webの非永続セッション

WHERE Web版またはdemoタグ付きのデモ版である場合、ゲームと設定は通常版と同じデータ構造と初期化、編成、報酬、解放と戦闘処理を使い、入出力先だけをページ内メモリへ切り替え、ブラウザの永続ストレージへプレイデータと設定を書き込んではならず(SHALL NOT)、ページ再読み込みで新規状態にならなければならない(SHALL)。

#### Scenario: REQ-062-S01 - ページ内の継続と再読み込み

- **GIVEN** Webの新規セッションで編集、報酬取得と設定変更を行った状態
- **WHEN** 同じページで再戦とシーン切替を行う
- **THEN** 同じセッションのプロフィールと設定を維持し、通常版と同じ構成検証と戦闘を使う
- **AND** 新しいページのセッションには以前の解放と構成、設定を復元しない

#### Scenario: REQ-062-S02 - 永続ストレージの不使用

- **GIVEN** Webセッションとゲーム保存、配色、言語、効果音、表示モードの設定
- **WHEN** 保存と復元を行う
- **THEN** ファイルとブラウザの永続ストレージへ読み書きせず、Web出力の起動も永続ファイルシステムとPWAを有効化しない

#### Scenario: REQ-062-S03 - 新規装備の実表示

- **GIVEN** 新規プロフィールのBUILD
- **WHEN** 日本語の標準と最小画面でARMSとGEARを確認する
- **THEN** 初回の追加解放を選択でき、未解放と区別でき、通常の装備とプレビュー、取消を操作できる

#### Scenario: REQ-062-S04 - 書き出し設定による保存操作の無効化

- **GIVEN** demoタグを持つWeb Demoプリセットで書き出したゲーム
- **WHEN** BUILDを開いてSAVEとLOADを操作する
- **THEN** 両ボタンは表示されたまま非活性であり、保存と読込を実行しない
- **AND** 内部から保存と読込を要求しても編成と解放、保存内容を変更せず、demoタグのない通常版では従来の保存と読込を維持する
