# 提案

## 目的

移動なしの手動WAITを盤面の現在手番ユニットからの行動選択へ統一し、独立ボタンとの二重の入口をなくす。

## 変更内容

- 戦闘画面本体のWAITボタンと専用ツールチップ、直接実行の配線を除く。
- 現在手番の人間操作ユニットだけをダブルクリックでき、両陣営手動でもその場WAITを利用できる。
- ACTIONのWAITと入力保護、BACKとEsc、移動後とCPUのWAITは維持する。

## 対象外

- 保存、戦闘式、移動とパネル、音とCPUの判断は変更しない。
- HELPは別のfocused-helpで変更済みである。

## 対象の仕様

### 新規

- なし

### 変更

- `tactical-battle`: 手動のその場WAITの入口を統一する。

## 影響

- 戦闘入力、HUDと関連する既存検査、短い開始通知とREADMEへ影響する。

## 未決事項

- なし。利用者の原文のユニット操作への統一と両陣営手動の維持に従い、陣営ではなく現在の人間操作手番で可否を判定する。
