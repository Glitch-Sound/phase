# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-010 - 移動確定と予測

WHEN 人が最終パネルまたは人が操作する現在手番のユニットをダブルクリックするとき、実状態を変更せず着地点から行動と必要な対象を予定し、現在手番ユニットの場合は移動先の有無にかかわらず0マスのWAITだけを選べるACTIONを開き、ダブルクリックだけでは確定せず、対象が必要な行動は有効な対象選択で、WAITと対象選択が不要な行動は行動ボタンで一度だけ確定を受け付け、最終CONFIRM画面を挟まず、ダイアログの消えた画面を描画してから経路と行動を実行し、BACKとEscは予定だけを戻し、実行済みの効果と終局を巻き戻してはならない(SHALL NOT)。

#### Scenario: REQ-010-S01 - 予測一致

- **GIVEN** CLOCKWISE、RESET、COUNTERCLOCKWISEを順に通る有効経路
- **WHEN** 経路と行動を最終確定する
- **THEN** COREを含む全3リングの確定角は経路順の予測と一致し、予定した行動へ連続して進み、選択と予測だけでは原本を変更しない

#### Scenario: REQ-010-S02 - CORE予測の取消

- **GIVEN** COREが回転またはリセットされる未確定経路
- **WHEN** 経路の後半を取り消す、または開始セルかEscで全取消する
- **THEN** 残った経路だけのCORE予測へ戻り、全取消では手番開始時のCORE角を維持し、未確定の変更を実状態へ適用しない

#### Scenario: REQ-010-S03 - 確定移動の選び直し

- **GIVEN** 回転とリセットを含む経路を予定し、まだ最終確定していない人の行動選択
- **WHEN** BACKまたはEscを操作して別の経路を選ぶ
- **THEN** 位置、全3角度と開始CORE角、HP、移動数を変更せず、元の経路を編集でき、手番、時刻と他ユニットは変わらず、予定した移動の履歴は作られない
- **AND** 再確定した経路だけの効果を一度適用し、対象選択のBACKは予定した行動選択へ戻る

#### Scenario: REQ-010-S04 - 再選択の境界

- **GIVEN** WAITまたはスキルを実行した後、移動で終局した場面、またはCPUの操作過程
- **WHEN** BACKまたはEscによる経路の再選択を試みる
- **THEN** 完了した効果、手番、終局と報酬を巻き戻さず、人はCPUの経路を変更できず、RESTARTは古い予定を残さずBUILDへ戻る

#### Scenario: REQ-010-S05 - 入力保護と消去後の実行

- **GIVEN** ACTIONを開いた直後、連打と押しっぱなし、対象選択と無効な対象、取消と再表示
- **WHEN** 人が行動または対象を選ぶ
- **THEN** ACTIONのボタンは設定した短い保護時間と押下の解除まで入力を受け付けず、有効な最終選択だけを1回受け付け、CONFIRM画面を追加せず、ダイアログが完全に消えた描画より前に位置と履歴を確定したり移動と行動の演出を始めたりしない
- **AND** 無効な対象とキーリピート、前のクリックの持越しは実行せず、確定前のBACKとEsc、再表示と画面退出を安全に扱い、次の手番へ同じ選択を再実行しない

#### Scenario: REQ-010-S06 - 手番ユニットからのその場行動

- **GIVEN** 移動先のある、または囲まれた人が操作する手番ユニット
- **WHEN** そのユニットを盤面でダブルクリックする
- **THEN** 実位置とリング、HP、手番を変えず、0マスのWAITとBACKだけのACTIONが開き、既存の入力保護と押下解除の後の明示WAITでだけ通常の次手へ進む
- **AND** BACKとEscで予定だけを取り消せ、非手番の味方と敵、CPU手番、モーダル中では開かず、両陣営手動では現在の手番を操作でき、単クリックと通常の移動後の行動は変わらない

### Requirement: REQ-012 - 待機と受動移動

各手番は移動先の有無にかかわらず無移動WAITで終了でき、人の移動なしWAITは盤上の現在手番ユニットのダブルクリックから行動選択のWAITを選ぶ入口に統一し、戦闘画面本体へ独立したWAITボタンを置かず、それ以外の自発的な能動行動は合法な1マス以上の移動確定後だけ許可し、その場のWAITではリングとパネルを再適用せず、移動演出と移動音を出さず、装備した移動+1とパネル無視を従来どおり適用しなければならない(SHALL)。

#### Scenario: REQ-012-S01 - 待機例外

- **GIVEN** 空き隣接セルのある場合と四方を塞いだ場合
- **WHEN** 無移動で待機する
- **THEN** 両方とも通常の待ち量で手番が1回終了し、位置とHP、リングとパネル、受動状態は変わらず、受動装備は最大移動数を1増やす

#### Scenario: REQ-012-S02 - パネル無視の移動接続

- **GIVEN** パネル無視を装備し、特殊パネルを通るユニット
- **WHEN** 経路を予測、確定してから行動前に選び直す
- **THEN** COREの特殊効果を無視した予測と確定が一致し、通常の装備回転と移動力を維持し、再選択は実状態を移動前へ戻す

#### Scenario: REQ-012-S03 - 移動前の能動拒否

- **GIVEN** 移動0マスで有効な対象だけは存在する手番と、対象選択まで進めた不正な内部状態
- **WHEN** DAMAGE、HEAL、GUARD、PUSHまたはSWAPの選択と実行を試みる
- **THEN** すべてを状態変更なく拒否し、通常の1マス以上の移動後は従来の対象条件で行動できる

#### Scenario: REQ-012-S04 - その場WAITの直接実行

- **GIVEN** 閉塞または移動先がある人の手番で、選択中の未確定経路がある場合も含む
- **WHEN** 現在手番ユニットをダブルクリックしてACTIONのWAITを選ぶ
- **THEN** 最終確認画面を挟まず1回だけ次手へ進み、元の未確定経路を実行せず、無移動では他の能動行動を選べない
- **AND** 無移動のWAITは移動演出と移動音、パネル再発動を伴わず、実ボタン押下の音は維持する
