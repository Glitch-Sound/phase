# 検証

## 対象

localized-ring-reactionsを対象とし、proposal、差分仕様、design、tasksと実装を照合した。

| 観点 | 結果 |
| --- | --- |
| 完全性 | 4/4タスク、変更1要件の全5シナリオの実装と証跡を確認した |
| 正確性 | REQ-021-S04とS06は既存の表示検査、S01、S05とS07は実GPUの通常、高INF、撃破と実増分、最小と標準の観測で確認した |
| 一貫性 | D-01の接触時刻と表示寿命、D-02の発動者と実増分、D-03の外縁とHPの芯、表示用定数の集約を確認した |

## 証跡と誤りの検出

tests/convergence.gdは未実装で4項目が失敗し、実装後は34項目すべて成功した。\
全HPを反応させる誤実装と接触前に反応する誤実装は、それぞれの検査が失敗した。\
元の円の全定数と時間別サンプルは完全一致した。\
バランスの固定期待値と検査コマンドは追加変更していない。\
npm run check、変更のstrict検証と変更対象のstrictトレース検査が成功した。\
実GPU、動画の連続復号と比較画像、実データの保護はartifacts/ring-reactions-review.mdへ記録した。

## 判定と限界

重大な問題、警告と設計逸脱はない。\
仕様、実装と検査の同期後にアーカイブできる。\
利用者の最終的な見た目の判断とiPhone実機、別GPUは未確認であり、manual-checks.mdの確認済みへ置き換えない。\
実回復ゼロは満HPが合法対象でないため表示部品で検証し、盤端も表示専用記録で確認した。\
対CPUの既定検査は成功したが、新しい反応の実GPU収録は両陣営の再現操作に限る。
