# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-044 - 英語のユーザー向け表示

画面は利用者が入力した名前を翻訳せずプレーンテキストとし、タイトル、見出し、スキルと装備の名称、機械的なラベルを英語に保ち、BUILD、候補選択、戦闘、行動と結果、HELPと設定、パネルと周囲効果の説明、保存の通知を選択された英語または日本語で表示し、HELPで操作、クラスと変異、位相、スキル、保存と全解放の意味を説明し、STARTのラベルをボタン中央へ配置しなければならない(SHALL)。

#### Scenario: REQ-044-S01 - 全画面の英語と操作

- **GIVEN** 英語を選択した通常と全解放、3体の構成と戦闘、成功と不正操作
- **WHEN** 画面と各補助説明を確認する
- **THEN** 入力された名前と言語選択の表記を除く英語モードの表示に日本語を含まず、HELPから必要な操作と効果を読め、STARTのラベルが中央にあり、戻ると既存の状態と操作を維持する
