# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-050 - アセンブリの表示規約

WHEN アセンブリの表示設定を使うとき、ゲームはユニット名と同じ固定のUnicode処理と空欄の既定名を使い、別の固定接頭辞とUTF-8、SHA-256、版付きの幾何規約からユニットとは異なる太めの紋章を安定に生成し、設定色を読みやすいパレットの安定キーで表し、既存キーと選択済みの色を維持して新規とCPUには陣営別の既定を使い、同色と同紋章を許して衝突回避のために選択した形と色を変更せず、識別と戦闘に設定を使ってはならない(SHALL NOT)。

#### Scenario: REQ-050-S01 - 安定した規約と独立性

- **GIVEN** 同じUnicode名と版、異なる保存先と色、同名の両陣営
- **WHEN** アセンブリとユニットの紋章を構成する
- **THEN** 固定ベクトルと同じアセンブリ図形が得られ、色によって形を変えず、既存ユニット紋章の版1の504形は不変であり、陣営と手番、CPUの判断へ影響しない

#### Scenario: REQ-050-S02 - パレットと明るいHP

- **GIVEN** パレットの全色と暗い盤面、異なるHP、新規とCPU、明示保存した設定
- **WHEN** 紋章とHPを表示する
- **THEN** アセンブリと所属ユニットの紋章は設定色、残HPバーと残HP円弧、所属紋章は同じ不透明の設定RGBをそのまま使い、明度と彩度、透明度による別トーンを作らず、新規とCPUは設定した陣営別の既定を使い、明示保存した色は保持し、HP比率と位相色、攻撃と回復の色は変わらない

### Requirement: REQ-052 - 視点に基づく所有マーク

WHEN 盤面のユニットを表示するとき、画面はマス左下のP1とE1などの文字に代えて、視点の陣営と不変IDが一致する自軍にだけ小さい所属アセンブリの実際の紋章を描き、敵と不正な視点へは描かず、中央のユニット紋章と手番枠へ重ねず、設定色を透過させず、点滅を加えてはならない(SHALL NOT)。

#### Scenario: REQ-052-S01 - 所有の判断

- **GIVEN** 同じ名前と紋章、色の両陣営と異なるまたは不正な視点
- **WHEN** 所有マークを判定する
- **THEN** PLAYER視点では正しいPLAYER枠だけ、ENEMY視点では正しいENEMY枠だけに表示し、不正な視点と陣営不整合のIDには表示せず、名前と色で判断しない

#### Scenario: REQ-052-S02 - 同色時の実表示

- **GIVEN** 同色と同紋章の両陣営、手番とホバー、最小と基準の画面
- **WHEN** 両方の視点から静止と移動を表示する
- **THEN** 自軍だけに同じ設定色の小さい所属アセンブリ紋章が出て、位相と紋章、HP、フォーカスを覆わず、移動者に追随して隣接セルと盤端にも収まる
