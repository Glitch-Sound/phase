# 差分仕様

## ADDED Requirements

### Requirement: REQ-058 - 撃破の効果音

WHEN 人またはCPUの攻撃による実HP減少で対象が0HPとなり盤面から消えるとき、画面は既存の攻撃音に短く遅れて本人提供の撃破音を1回だけ鳴らし、立ち上がりを保ったまま長い余韻を滑らかに消し、次手とRESULTへの遷移で即断せず、戦闘と演出の進行を待たせてはならない(SHALL NOT)。

#### Scenario: REQ-058-S01 - 実撃破と余韻

- **GIVEN** 人またはCPUによる実攻撃で、対象が最後のユニットである場合を含む
- **WHEN** 実HPが0になり消滅結果を表示する
- **THEN** 攻撃音に続いて撃破音が1回だけ始まり、冒頭の音量を保持した後に設定した時間で連続的に消え、既存の次手またはRESULTへ余韻を引き継ぎ、進行を遅らせない

#### Scenario: REQ-058-S02 - 非撃破と取消の境界

- **GIVEN** 非致死、実減少ゼロ、回復とその他の技、予測、取消、同じ撃破の再表示または明示的な戦闘退出
- **WHEN** 音の表示状態を更新する
- **THEN** 新しい撃破だけに音が対応し、同じ消滅には重複発火せず、退出と停止では保留と残響を止め、再戦へ古い音を持ち越さない

## MODIFIED Requirements

### Requirement: REQ-057 - 提供素材と音量の管理

画面は本人提供の原本を変更せず保持し、再生はring_rotate1、ring_rotate2、attack、heal、defeatedだけに限定し、移動と撃破は控えめに、攻撃と回復は既存の音量と素材、発音条件を維持して一元管理し、同種の音を耳障りに重ねず、選択音、BGMと追加の音量UI、戦闘と保存の変更を追加してはならない(SHALL NOT)。

#### Scenario: REQ-057-S01 - 音源の読込と再生境界

- **GIVEN** 本人が置いた原音と通常のゲーム保存と設定
- **WHEN** 連続した選択、移動と行動を再生する
- **THEN** 旧音の原本も保持しながら再生対象は移動用2音、攻撃、回復と撃破だけとなり、設定した音量と同時発音の上限を守り、原音と通常保存、設定を変更せず選択音とBGMを鳴らさない

#### Scenario: REQ-057-S02 - 実プレイの聴感

- **GIVEN** 音声出力が有効なGodotの戦闘
- **WHEN** 有効選択、移動、攻撃と回復を実際に聞く
- **THEN** 選択は無音で、移動は各マスの2音が等間隔で控えめに交互に鳴り、攻撃と回復は従来のまま区別でき、撃破は攻撃に続いて余韻が自然に消え、不要な連続音がない
