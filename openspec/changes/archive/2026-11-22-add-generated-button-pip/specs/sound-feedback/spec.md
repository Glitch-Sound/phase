# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-054 - 手動選択の音

WHEN 人がマウスまたはキーなどで有効なボタンを実際に押下または確定するとき、画面は短い控えめな生成音を1操作1回鳴らし、ホバー、フォーカス移動、無効ボタン、盤面選択と経路予測、CPUと内部更新では鳴らしてはならない(SHALL NOT)。

#### Scenario: REQ-054-S01 - 成立した手動入力だけの選択音

- **GIVEN** 静的ボタン、動的な候補、トグルとプルダウン
- **WHEN** マウスまたはキーで有効なボタンを押下または確定する
- **THEN** 1操作につき短い生成音が1回だけ鳴り、画面遷移と候補の作り直し、共通接続の再確認でも二重再生しない

#### Scenario: REQ-054-S02 - 非成立の入力と内部更新

- **GIVEN** 無効ボタン、ホバーとフォーカス、盤面と予測、CPUと内部更新
- **WHEN** 押下の成立を伴わず状態を更新する
- **THEN** 生成音は鳴らず、選択値の内部変更と同じ押下通知の再送でも新しい入力なしには再生しない

### Requirement: REQ-057 - 提供素材と音量の管理

画面は本人提供の原本を変更せず保持し、再生はring_rotate1、ring_rotate2、attack、heal、defeatedとコード生成の短いボタン音だけに限定し、移動と撃破は控えめに、攻撃と回復は既存の音量と素材、発音条件を維持して一元管理し、同種の音を耳障りに重ねず、select.oggの再生、BGMと追加の音量UI、戦闘と保存の変更を追加してはならない(SHALL NOT)。

#### Scenario: REQ-057-S01 - 音源の読込と再生境界

- **GIVEN** 本人が置いた原音と通常のゲーム保存と設定
- **WHEN** 連続した選択、移動と行動を再生する
- **THEN** 旧音の原本も保持しながら再生対象は移動用2音、攻撃、回復と撃破、外部素材を使わず一度生成して再利用する短い滑らかなサイン波のボタン音だけとなり、設定した音量と同時発音の上限を守り、原音と通常保存、設定を変更せずselect.oggとBGMを鳴らさない

#### Scenario: REQ-057-S02 - 実プレイの聴感

- **GIVEN** 音声出力が有効なGodotの戦闘
- **WHEN** 有効選択、移動、攻撃と回復を実際に聞く
- **THEN** ボタンだけ短い控えめな生成音となり、盤面の選択は無音で、移動は各マスの2音が等間隔で控えめに交互に鳴り、攻撃と回復は従来のまま区別でき、撃破は攻撃に続いて余韻が自然に消え、不要な連続音がない
