# 差分仕様

## MODIFIED Requirements

### Requirement: REQ-015 - 収集

WHEN 通常モードの戦闘が終了するとき、各戦闘で一度だけ0から2件の未開放ARMS、GEAR、SKILLをランダム取得し、新規装備の5値を各10以上の10刻みで合計100の各126通りから選び、MUTANT取得で本体と非NORMAL変異を開放し、既開放候補を再抽選しなければならない(SHALL)。

#### Scenario: REQ-015-S01 - ドロップ境界

- **GIVEN** 固定シードの乱数と初期所持品
- **WHEN** 繰り返し戦利品を生成する
- **THEN** 各回0から2件、新規配分は10以上の10刻みで合計100、各種類の候補集合は重複のない126通り、変異は通常以外で本体と共に開放される

#### Scenario: REQ-015-S02 - 重複と変異

- **GIVEN** 本体開放済み、変異未開放の候補
- **WHEN** 候補を取得する
- **THEN** 新変異だけを開放し、両方既開放の再取得を拒否する

#### Scenario: REQ-015-S03 - 同じ結果の再表示

- **GIVEN** 戦利品を受け取った戦闘結果
- **WHEN** 同じRESULTを再表示する
- **THEN** 開放一覧、戦利品表示、乱数の状態が変わらず、戦闘以外では戦利品を取得しない

## ADDED Requirements

### Requirement: REQ-041 - 一時的な全解放

WHERE デバッグビルドである場合、利用者はBUILDからARMSとGEAR各126通り、全スキルと全変異を使用できる一時モードへ入り、通常データの保存、読込と戦利品、設定へ影響させず、DEBUG / NOT SAVEDを識別でき、終了時に元の通常状態へ戻れなければならない(SHALL)。

#### Scenario: REQ-041-S01 - デバッグだけの入口

- **GIVEN** デバッグまたはリリースの実行環境と通常のBUILD
- **WHEN** 全解放の入口と開始を確認する
- **THEN** デバッグでは明示的に開始でき、リリースでは入口を表示せず直接の開始も拒否し、起動直後は通常状態のままである

#### Scenario: REQ-041-S02 - 新規の全カタログ

- **GIVEN** 通常の構成と所持品
- **WHEN** 一時モードへ入る
- **THEN** 新規の一時データでARMSとGEAR各126通り、NORMALを含む120変異と全16スキルを使用でき、元の通常データを変更せず、装備の共有と重複しない最大3スキルを維持する

#### Scenario: REQ-041-S03 - 保存と戦利品の分離

- **GIVEN** 全解放で編集した構成と戦闘結果、通常のセーブと設定
- **WHEN** 保存、読込、戦利品と色設定を操作する
- **THEN** 通常セーブへの保存と読込は操作と実処理で拒否し、戦利品は発生せず乱数も進めず、色の適用は一時的とし、通常データと保存先、設定ファイルを変更しない

#### Scenario: REQ-041-S04 - 終了と再開始

- **GIVEN** 一時モードで構成とステージ、配色を変更し、戦闘または再スタートを行った状態
- **WHEN** BUILDで一時モードを終了するかアプリを終了する
- **THEN** 元の通常の所持品と構成、ステージと表示設定へ戻り、一時取得品を持ち込まず、再スタートだけでは一時モードを維持し、再度入ると新しい一時データになる

#### Scenario: REQ-041-S05 - 表示と装備の試行

- **GIVEN** 全解放のBUILDと戦闘、最小から拡大の画面
- **WHEN** 装備と変異、スキルを選び、開始と戻る操作を行う
- **THEN** DEBUG / NOT SAVEDを識別でき、126種と120変異の先頭と末尾まで選べ、数値とプレビュー、対象と戦闘へ反映し、終了とメニュー、既存のフォーカスとクリックを妨げない
