# 提案

## 目的

開発中の利用者が少ない装備配分を収集し、すべての装備とスキルを通常データへ影響させずに試せるようにする。
ニューゲーム前提で新規戦利品を10刻みへ絞り、デバッグビルドだけに一時的な全解放モードを用意する。

## 変更内容

- 新規ARMSとGEARの戦利品を各値10以上の10刻み、合計100の各126種から選ぶ。
- 初期装備も新しい配分にそろえ、変異の共有開放とスキルの3枠、戦闘式を維持する。
- デバッグ時のBUILDに全解放の入口を追加し、新規の一時データへ126種ずつ、全スキルと全変異を解放する。
- 通常の保存と読込、戦利品を一時データと分離し、DEBUG / NOT SAVEDを表示して終了時に元の通常状態へ戻す。
- リリースでは入口と実行を利用不可とし、実行環境の判定を検証する。

## 対象外

- BUILDの大規模再設計と検索、装備の新しい命名。
- 戦闘式、装備枠と変異の個別所有への変更。
- 旧データの変換と移行、互換性を維持する追加処理。
- 実セーブと設定の削除や上書き、pushと公開、追加アプリ。

## 対象の仕様

### 新規

なし。

### 変更

- build-collection: 10刻みの戦利品と、通常データを保護するデバッグ全解放を定める。

## 影響

ニューゲームの装備カタログと戦利品候補、BUILDの最小限のモード操作と保存境界に影響する。
通常の実セーブと設定を変更しない検証用の保存先を使う。

## 未決事項

なし。
